太灵活的模型，
怎么驯服？

第 9 讲拿到了 $f_\alpha(x)=\sum_i\alpha_ik(x_i,x)$ 与 $\widehat y_{\mathrm{train}}=K\alpha$，但也留下两个紧接的问题：模型太容易穿过每个训练点时，怎么加正则化；什么样的相似度函数才配当 kernel 用。这一讲先补完 kernel 方法（ridge 化 + 合法性判据），再换一套完全不同的非线性工具箱——按邻居投票的 kNN、按阈值切空间的树、把许多树平均起来的森林。

💬 本讲核心问题：kernel 模型可以精确穿过所有训练点（包括噪声），$K$ 还可能不可逆——正则化怎么加、解还存在吗？另一方面，随便写一个相似度函数就能当 kernel 吗？不用 kernel 的方法又靠什么获得非线性？
一句话答案：把 ridge 的 $\lambda\lVert w\rVert^2$ 换算到样本坐标就是 $\lambda\alpha^\top K\alpha$，最优解永远是 $\alpha_0=(K+\lambda I)^{-1}y$——只要 $\lambda>0$，这个矩阵一定正定可逆；谱上看它把标签沿 Gram 特征方向乘上收缩因子 $\mu_i/(\mu_i+\lambda)$。合法性判据是对称 + 对任意有限输入集合 PSD，闭包性质让我们安全组合 kernel。工具箱路线则是：kNN 靠邻域投票、树靠轴对齐切分、森林靠去相关平均把方差压到 $\rho\sigma_T^2$ 的下限。

📌 今天讲什么

从"强行穿过每个点"的失败开始：ridge 化的目标与 $\alpha^\top K\alpha$ → 奇异 $K$ 下的闭式解与解集 → 谱收缩直觉 → $\sigma$ 与 $\lambda$ 双旋钮 → 合法性判据与 PSD 检验 → 组合 kernel 的闭包规则 → 换工具箱：kNN 手算、树与 Gini、森林方差公式 → 四种方法横向对比。

🔥 为什么重要

$\alpha^\top K\alpha$ 不是新发明的惩罚，它恰好就是特征空间权重 $w$ 的平方长度——写错成 $\lVert\alpha\rVert^2$ 是最常见的实现 bug。valid kernel 判据把"看起来像相似度"升级成可证明的合法性。而 kernel / kNN / 树 / 森林是四种不同归纳偏好的非线性方案，选型时必须同时看表达力、样本规模、预测成本与 bias-variance。

🧭 主线逻辑（整讲五步）

① 病：无正则的 kernel 回归会穿过噪声（§1）。 ② 药：ridge 目标搬到样本坐标，正则项变成 $\alpha^\top K\alpha$（§2）。 ③ 解：$\alpha_0=(K+\lambda I)^{-1}y$ 永远存在；奇异只带来表示不唯一（§3–§5）。 ④ 律：谱收缩因子 + $\sigma,\lambda$ 双旋钮 + 合法性判据与闭包（§6–§9）。 ⑤ 替：kNN / 树 / 森林——另一套非线性工具箱（§10–§13）。

§1从穿过每个点的失败开始 核心

不加正则化的 kernel regression 可以写成 $\min_{\alpha}\lVert y-K\alpha\rVert_2^2$。若 $K$ 可逆，取 $\alpha=K^{-1}y$ 会使 $K\alpha=y$——训练误差为零。但训练误差为零只说明模型穿过所有观测点；若标签包含噪声，模型会把噪声一起学进去。

插值 interpolation · first mentioned: §1

是什么：模型在训练点上的预测恰好等于标签：$\widehat y_i=y_i$ 对所有 $i$ 成立。

白话：曲线把每个训练点都"踩死"——一个都不放过。

干嘛用：本讲把它当作病症而不是目标：穿过噪声点意味着高方差。

怎么算：$\alpha=K^{-1}y$（$K$ 可逆时）；下面的互动把 $\lambda$ 拉到极小就能看到这种 behavior。

为什么重要 + 连接：例如真实趋势接近 $y=x$，但观测点为 $(0,0),(1,1),(2,10)$——强制穿过会把最后一个异常观测当成真实结构。我们需要在"贴近数据"和"函数不要太复杂"之间权衡，这正是 §2 的目标函数要形式化的。

互动：拖动 $\lambda$，看曲线从"踩死每个点"到"平滑跟随趋势"

图里的机制：曲线由 $\widehat f(x)=\sum_i\alpha_ik_\sigma(x_i,x)$、$\alpha=(K+\lambda I)^{-1}y$ 现算（RBF、固定 $\sigma$）；虚线是真实趋势 $y=x$，其中一个点被抬高成异常。$\lambda$ 很小时曲线尖峰穿过异常点；$\lambda$ 增大后小特征值方向先被压平（§4 会解释为什么是"先小后大"）。训练误差与曲线起伏程度都由当前 $\lambda$ 现算显示。

§2Kernel ridge 的目标：正则项是 $\alpha^\top K\alpha$ 核心

要解决的是：既保留第 9 讲的 kernel 预测，又像普通 ridge regression 一样惩罚过于复杂的函数。最容易混淆的是正则项——在 $w$ 参数下它是 $\lVert w\rVert^2$，换成 $\alpha$ 后并不是 $\lVert\alpha\rVert^2$，而是 $\alpha^\top K\alpha$。

Kernel ridge 回归 kernel ridge regression · first mentioned: §2

是什么：特征空间 ridge 目标的样本坐标版本： $$\min_{w}\ \lVert y-\Phi w\rVert_2^2+\lambda\lVert w\rVert_2^2\qquad\Longrightarrow\qquad J(\alpha)=\lVert y-K\alpha\rVert_2^2+\lambda\,\alpha^\top K\alpha.$$

白话：还是"贴近数据 + 别太复杂"两句老话，只是复杂度改用样本系数的"加权长度"来计量。

干嘛用：给无限灵活的 kernel 模型装上平滑刹车。

怎么算：代入 $w=\Phi^\top\alpha$：拟合项里 $\Phi w=\Phi\Phi^\top\alpha=K\alpha$；正则项见下方推导。

为什么重要 + 连接：未知量从 $p$ 维 $w$ 换成 $n$ 维 $\alpha$，求出后新点仍用 $f_\alpha(x)=k_x^\top\alpha$ 预测；$\lambda$ 的谱意义在 §4 揭晓。

正则项的三行推导（不是新发明，只是搬家）

由 representer argument 可写 $w=\Phi^\top\alpha$。于是 $$\lVert w\rVert_2^2=\lVert\Phi^\top\alpha\rVert_2^2=(\Phi^\top\alpha)^\top(\Phi^\top\alpha)=\alpha^\top\Phi\Phi^\top\alpha=\alpha^\top K\alpha.$$

第二行使用 $\lVert u\rVert_2^2=u^\top u$，第三行使用 $(\Phi^\top\alpha)^\top=\alpha^\top\Phi$。所以 $\alpha^\top K\alpha$ 恰好就是原特征空间权重 $w$ 的平方长度，不能凭直觉改成 $\lVert\alpha\rVert_2^2$。

核范数正则 kernel-norm regularization αᵀKα · first mentioned: §2

是什么：$\alpha^\top K\alpha=\lVert\Phi^\top\alpha\rVert_2^2=\lVert w\rVert_2^2$，即特征空间权重的平方范数在样本坐标下的写法。

白话：不是"系数向量本身的长度"，而是"系数组合出的函数的长度"。

干嘛用：衡量 kernel 函数的复杂度，是 ridge 刹车的具体实现。

怎么算：数值上 $\alpha^\top K\alpha$ 与 $\lVert\Phi^\top\alpha\rVert^2$ 逐位相等（下面的互动现场对账）。

为什么重要 + 连接：写错成 $\lVert\alpha\rVert^2$ 会得到完全不同的解；它也解释了 §3 中"K 看不见的方向不受惩罚"的现象。

互动：滑动系数 $\alpha$，对账 $\alpha^\top K\alpha$ 与 $\lVert w\rVert^2$（并看它与 $\lVert\alpha\rVert^2$ 差多少）

两个约定，先说清楚

① 截距 $b=0$：本讲公式默认无单独截距。若需要，用 $J(\alpha,b)=\lVert y-b\mathbf 1-K\alpha\rVert^2+\lambda\alpha^\top K\alpha$，$b$ 通常不正则化，可通过中心化或增广正规方程求解。② $\lambda$ 的尺度：本讲用未除以 $n$ 的平方损失；若数据项写成 $\frac1n\lVert y-K\alpha\rVert^2$，闭式解中会出现 $K+n\lambda I$——只是尺度约定不同。另注意 $\lambda$（正则系数）与损失记号 $\ell$、树数 $B$、邻居数 $k$ 各不相干，后两者到 §11/§13 再登场。

§3闭式解：$K$ 奇异时也要说严谨 核心

先把二次目标展开，求梯度，看清楚驻点条件到底是什么；再说明标准公式为什么给出一个全局最优解，以及奇异时"全部解"长什么样。

梯度、驻点与代表解

合法 kernel 产生的 $K$ 对称且 PSD。展开目标： $$J(\alpha)=y^\top y-2y^\top K\alpha+\alpha^\top K^2\alpha+\lambda\alpha^\top K\alpha,$$ $$\nabla_\alpha J(\alpha)=-2Ky+2K^2\alpha+2\lambda K\alpha=2K\bigl((K+\lambda I)\alpha-y\bigr).$$

三个求导规则：$K=K^\top$ 所以 $\nabla(y^\top K\alpha)=Ky$；$K^2$ 也对称所以 $\nabla(\alpha^\top K^2\alpha)=2K^2\alpha$；同理 $\nabla(\alpha^\top K\alpha)=2K\alpha$。真正的驻点条件是 $K\bigl((K+\lambda I)\alpha-y\bigr)=0$，而不是直接要求括号为零——$K$ 奇异时不能"约掉 $K$"：$Kq=0$ 只说明 $q\in\ker(K)$，不一定 $q=0$。

但由于 $K\succeq0$，设特征值 $\mu_i\ge0$，则 $K+\lambda I$ 的特征值为 $\mu_i+\lambda>0$——无论 $K$ 是否奇异，$K+\lambda I$ 都正定可逆。定义 $$\alpha_0=(K+\lambda I)^{-1}y.$$ 我们不是从驻点条件"约掉 $K$"，而是主动选择让括号本身等于零的解；它当然满足驻点条件。又因为 $J$ 是凸二次函数（Hessian $2K(K+\lambda I)$ 在特征方向上取值 $2\mu_i(\mu_i+\lambda)\ge0$），$\alpha_0$ 是全局最小解。

代表解 representative solution α₀ · first mentioned: §3

是什么：$\alpha_0=(K+\lambda I)^{-1}y$——总能计算、且总是全局最小的那个解。

白话：解可能有一族，$\alpha_0$ 是其中"最好算的代表"。

干嘛用：kernel ridge 的标准实现就是它。

怎么算：解线性系统 $(K+\lambda I)\alpha_0=y$，无需显式求逆。

为什么重要 + 连接：$\lambda>0$ 时它永远存在——"$K$ 奇异不能用闭式解"是误区（§13）；全部解见右侧的零空间卡片。

零空间 null space ker(K) · first mentioned: §3

是什么：$\ker(K)=\{v:Kv=0\}$。若 $v\in\ker(K)$，则 $K(\alpha_0+v)=K\alpha_0$ 且 $(\alpha_0+v)^\top K(\alpha_0+v)=\alpha_0^\top K\alpha_0$，所以 $J(\alpha_0+v)=J(\alpha_0)$——全部最小解正是 $\alpha_0+\ker(K)$。

白话：$K$ "看不见"的方向，加减多少都不改变拟合和惩罚。

干嘛用：刻画奇异时解的不唯一程度。

怎么算：把 $d=\alpha-\alpha_0$ 写到 $K$ 的特征向量基中，每个坐标满足 $\mu_i(\mu_i+\lambda)d_i=0$；因 $\mu_i+\lambda>0$，只有 $\mu_i=0$ 的方向可以保留。

为什么重要 + 连接：且 $\lVert\Phi^\top v\rVert^2=v^\top Kv=0\Rightarrow\Phi^\top v=0$，于是 $\Phi^\top(\alpha_0+v)=\Phi^\top\alpha_0$——不唯一的是表示，函数本身不变：特征空间目标关于 $w$ 强凸、最优 $w$ 唯一，冗余只在 $\alpha$ 表示层。

互动：奇异 K 的完整手算——并亲眼看"解集是一条线，预测却纹丝不动"

对账（讲义 §5 与综合题 1）：$K=\begin{bmatrix}1&1\\1&1\end{bmatrix}$ 秩为 1，$v=(1,-1)^\top\in\ker(K)$。例 A：$y=(1,3),\lambda=1$ 时 $K+\lambda I=\begin{bmatrix}2&1\\1&2\end{bmatrix}$，$\alpha_0=(-\tfrac13,\tfrac53)^\top$，$K\alpha_0=(\tfrac43,\tfrac43)^\top$；例 B：$y=(2,2),\lambda=2$ 时 $K+2I=\begin{bmatrix}3&1\\1&3\end{bmatrix}$，$\alpha_0=(\tfrac12,\tfrac12)^\top$，$K\alpha_0=(1,1)^\top$——标签 $(2,2)$ 被收缩到 $(1,1)$。点按钮载入后，面板里的每个数（含逆矩阵）都由当前滑杆现算。拖动 $t$：解沿 $\alpha_0+t(1,-1)$ 滑动，$K\alpha$ 与 $J$ 数值不动。

§4谱直觉：每个方向被乘上 $\mu_i/(\mu_i+\lambda)$ 核心

设 $U$ 的列 $u_i$ 是 $K$ 的正交特征向量、$\mu_i\ge0$ 为对应特征值。把标签换到这组坐标：$\beta=U^\top y$，即 $\beta_i=u_i^\top y$ 是标签沿第 $i$ 个 Gram 特征方向的分量。

三行推出收缩因子

由 $K+\lambda I=U\operatorname{diag}(\mu_i+\lambda)U^\top$（正交矩阵 $U^{-1}=U^\top$，求逆只需取对角元倒数）： $$\alpha_0=U\operatorname{diag}\!\Big(\frac1{\mu_i+\lambda}\Big)U^\top y,\qquad \widehat y=K\alpha_0=U\operatorname{diag}\!\Big(\frac{\mu_i}{\mu_i+\lambda}\Big)U^\top y.$$

每个标签坐标 $\beta_i$ 被独立地乘上 $s_i=\mu_i/(\mu_i+\lambda)$。$\mu_i\gg\lambda$ 则 $s_i\approx1$（基本保留）；$\mu_i\ll\lambda$ 则 $s_i\approx0$（强烈压缩）；$\mu_i=0$ 则 $s_i=0$（训练特征无法表达该方向）。所以 $\lambda$ 不是把所有系数同样缩小，而是在 Gram 谱方向上做平滑：小特征值方向通常对应训练特征难以稳定表达的方向，ridge 优先压低它们。

谱收缩因子 spectral shrinkage factor · first mentioned: §4

是什么：$s_i=\dfrac{\mu_i}{\mu_i+\lambda}$——第 $i$ 个 Gram 特征方向上标签分量的保留比例。

白话：数据"说得响"的方向留下，"说得含糊"的方向压掉；$\lambda$ 是分界的门槛。

干嘛用：解释 ridge 为什么平滑、为什么先压小特征值方向。

怎么算：算出 $K$ 的特征值即可读出每个方向的 $s_i$（下方条形图现算）。

为什么重要 + 连接：它把 §1 的现象定量化——$\lambda\to0$ 时全部 $s_i\to1$（趋近穿过每点），$\lambda$ 大时只有大 $\mu_i$ 方向幸存；也预告了 §5 中 $\lambda$ 与 $\sigma$ 的分工。

互动：拖动 $\lambda$，看收缩因子按特征值从大到小依次"熄灯"

§5RBF bandwidth 与正则化的双重控制 核心

$\sigma$ 与 $\lambda$ 控制不同层面的复杂度：$\sigma$ 决定"两个点多远还算相似"，改变函数类的局部性；$\lambda$ 决定允许模型多努力地贴合训练标签，改变正则化强度。两者都是平滑旋钮，但作用在不同层面，不能当成同一个超参数。

小 bandwidth：$K$ 接近单位阵

当训练点间距远大于 $\sigma$ 时 $k_\sigma(x_i,x_j)\approx0\ (i\ne j)$、对角线仍为 $1$，所以 $K\approx I$。每个点几乎只影响自己：模型非常局部，训练误差容易降低，但方差较高。

大 bandwidth：$K$ 接近全 $1$ 矩阵

当 $\sigma$ 远大于样本间距离时 $k_\sigma(x_i,x_j)\approx1$，即 $K\approx\mathbf 1\mathbf 1^\top$。模型难以区分不同训练点：函数更平滑、更全局，也更可能欠拟合。

互动（上）：$\sigma$ 如何改写 $K$ 的谱（相距 1 的两点相似度现算）

互动（下）：$\sigma\times\lambda$ 联合控制整条回归曲线

数值对账（讲义 §6）：取一维点 $x=0$、$z=1$。$\sigma=0.5$ 时 $k_{0.5}(0,1)=e^{-2}\approx0.1353$；$\sigma=2$ 时 $k_2(0,1)=e^{-1/8}\approx0.8825$——同样相距 1 的两点，在大 bandwidth 下被视为高度相似。把上图 $\sigma$ 滑到 0.5 和 2 即可逐位核对（数值现算）。实践中应联合选择 $(\lambda,\sigma)$，用 validation / cross-validation，不能在 test set 上挑。

§6什么是 valid kernel 核心

要判定的是函数 $k(x,z)$ 能否在所有数据集上被解释为某个特征空间内积——不是"这个相似度看起来合不合理"，也不只是当前训练集的一个矩阵。

valid kernel valid kernel · first mentioned: §6

是什么：$k:\mathcal X\times\mathcal X\to\mathbb R$ 是 valid kernel，当且仅当满足两条：① 对称性 $k(x,z)=k(z,x)$ 对所有 $x,z$；② 对任意有限输入集合产生 PSD Gram matrix——任意 $n$、任意 $x_1,\ldots,x_n$、任意 $a\in\mathbb R^n$ 都有 $a^\top Ka\ge0$（其中 $K_{ij}=k(x_i,x_j)$）。

白话：发给 kernel 的两块牌照——左右看齐（对称），且随便挑多少个点、随便怎么加权，组合特征的"长度平方"都不能是负的。

干嘛用：把"像相似度"升级为可证明的内积解释，保住 kernel trick 的几何与优化性质。

怎么算 / 怎么证：容易的一边：若 $k(x,z)=\langle\phi(x),\phi(z)\rangle$ 则 $$a^\top Ka=\sum_{i,j}a_ia_j\langle\phi(x_i),\phi(x_j)\rangle=\Big\lVert\sum_ia_i\phi(x_i)\Big\rVert^2\ge0$$ （内积的线性性把双重求和收成组合向量与自身的内积）。反过来，对称 + PSD 的函数会诱导某个 Hilbert space 中的特征映射——这是 kernel trick 拥有严格几何解释的原因。

为什么重要 + 连接：注意量词——"任意输入集合"不是形式主义：对一批数据算出一个 PSD 矩阵只能说明该批数据没有反例，不能替代函数级证明（§13 误区 3）；§7 的检验方法与 §8 的闭包规则正是为了一次性覆盖所有有限集合。

PSD 与 feature map 为何等价（读法）

上面的双向结论合起来：$k$ 有特征映射 $\Rightarrow$ 所有 Gram matrix PSD（平方长度非负）；反之对称 + 全 PSD $\Rightarrow$ 存在特征映射（RKHS 构造，课程不展开证明）。所以 "valid" 不是额外技术条件，而是"真实内积"的精确代数刻画。

§7如何检验 PSD 核心

三种方法：① 直接构造 feature map（如 $k(x,z)=x^\top Mz$、$M\succeq0$ 时写 $M=B^\top B$，得 $\phi(x)=Bx$）；② 找反例向量（对某组输入构造的 $K$ 存在 $a$ 使 $a^\top Ka<0$，则一定不是——否定只需一个反例）；③ 检查小矩阵的特征值或主子式（对具体实对称矩阵，PSD $\iff$ 所有特征值非负 $\iff$ 所有主子式非负；注意半正定要看全部主子式，不能只看顺序主子式）。

一个两点检验（讲义 §8）

考虑 $K(a)=\begin{bmatrix}1&a\\a&1\end{bmatrix}$，特征值 $1+a$ 与 $1-a$，所以 $K(a)\succeq0\iff-1\le a\le1$。这也符合内积直觉：若两个特征向量范数都为 $1$，它们的内积不能超过 Cauchy–Schwarz 给出的范围 $[-1,1]$。综合题 2 的变体 $K(a)=\begin{bmatrix}2&a\\a&2\end{bmatrix}$ 特征值 $2\pm a$，PSD $\iff-2\le a\le2$（行列式条件 $4-a^2\ge0$）。

互动：滑动 $a$（或直接转夹角），看合法性边界与 Cauchy–Schwarz 几何

右图几何：两个单位特征向量夹角 $\theta$、内积 $a=\cos\theta$。$|a|\le1$ 时几何存在（绿色）；$|a|>1$ 时"两个单位向量的内积超出了 Cauchy–Schwarz 范围"——不存在任何实特征向量组能实现这个矩阵，最小特征值为负、随机测试向量很快会撞出 $a^\top Ka<0$。把 $a$ 滑出 $\pm1$（矩阵 1）或 $\pm2$（矩阵 2）即可看到状态翻转。

§8闭包性质：安全组合 kernel 的规则 核心

设 $k_1,k_2$ 都是 valid kernels。以下操作的结果仍然是 valid kernel——每条规则都一次性覆盖所有有限输入集合，这正是它们比"逐个数据集检查"可靠的原因。

① 非负加权和

$k=c_1k_1+c_2k_2$（$c_1,c_2\ge0$）：$a^\top Ka=c_1a^\top K_1a+c_2a^\top K_2a\ge0$。负权重一般不保 PSD。

② 逐点乘积

$k=k_1k_2$：对应 Hadamard 积 $K=K_1\circ K_2$，Schur 乘积定理保证两个 PSD 矩阵的逐元素乘积仍 PSD；特征角度看 $\phi=\phi_1\otimes\phi_2$（tensor product）。

③ 输入变换

$k(x,z)=k_1(g(x),g(z))$：先做特征工程 $g$，再套 kernel。

④ 外积型

$k(x,z)=h(x)h(z)$：Gram matrix 为 $hh^\top$，秩至多 $1$，自动 PSD。

⑤ 极限：若一列 valid kernels $k_m$ 逐点收敛到有限极限 $k$，则 $k$ 仍 valid——有限 Gram matrix 的二次型逐点收敛，非负数列的极限仍非负。不能随便做：差 $k_1-k_2$ 一般不是 valid kernel；对 kernel 做任意非线性变换也不一定保持 PSD。组合 kernel 应依赖已知闭包规则，而不是"看起来像相似度"。

闭包性质 closure properties · first mentioned: §8

是什么：把 valid kernels 组合成新 valid kernel 的整套代数规则（非负和、逐点积、输入变换、外积、逐点极限）。

白话：合法 kernel 的"运算交通规则"——绿灯操作放心做，红灯操作（差、任意非线性）别碰。

干嘛用：不用重新构造特征映射就能派生新 kernel。

怎么算：按规则组合后，Gram matrix 的 PSD 由规则自动继承（下方互动现场验证）。

为什么重要 + 连接：它把 §6 的"任意有限集合"量词一次性兑现；Schur 定理是乘积规则的理论支柱。

互动：组合规则实验室——加、乘安全，减会翻车（特征值现算）

实验室设置：$k_1$ 为 $\sigma{=}0.5$ 的 RBF、$k_2$ 为 $\sigma{=}1.5$ 的 RBF，对当前 6 个输入点（可随机重抽）分别构造 Gram matrix，组合后用 Jacobi 旋转现场算特征值并画条形图。选"差"通常会出现负特征值（红色）——这就是"减法不保 PSD"的直接证据；偶然不出现负值也只说明这批点没暴露反例，函数层面依然非法。

§9三个持证上岗的 kernel 拓展

它们都能通过 §6 的两条检验——前两个已在第 9 讲出场，第三个是新面孔。

Brownian kernel Brownian kernel min(x,z) · first mentioned: §9

是什么：在 $[0,\infty)$ 上 $k(x,z)=\min(x,z)$。令 $\phi(x)(u)=\mathbf 1\{0\le u\le x\}$（指示函数），则在 $L^2$ 内积下 $$\langle\phi(x),\phi(z)\rangle=\int_0^\infty\mathbf 1\{u\le x\}\mathbf 1\{u\le z\}\,du=\min(x,z).$$

白话：把每个点 $x$ 变成"从 0 铺到 $x$ 的一条地毯"，两张地毯重叠的长度就是 $\min(x,z)$。

干嘛用：布朗运动协方差；也示范 feature map 可以是函数而非有限维向量。

怎么算：直接取两个坐标的较小者。

为什么重要 + 连接：提醒我们特征空间的"坐标"可以是一整条函数（$L^2$），与 RBF 的无限维特征空间相呼应；合法性由上述显式构造直接给出（§7 方法 ①）。

另外两张老牌照：多项式 kernel $k(x,z)=(c+x^\top z)^m$（$c\ge0$，有限维多项式 feature map，适合有限阶交互——第 9 讲 §8 已手算过它的 $\sqrt2$ 缩放）；Gaussian RBF $k_\sigma(x,z)=\exp(-\lVert x-z\rVert^2/2\sigma^2)$（无限维、非常平滑，第 9 讲 §9）。外积型 $h(x)h(z)$ 也是即查即得的合法例子（秩至多 1）。

§10k 近邻：把计算推迟到预测时刻 核心

kNN 不显式拟合参数：把训练集保存下来，预测时计算查询点到每个训练点的距离，取最近的 $k$ 个标签投票（回归则取平均或距离加权平均）。

k 近邻 k-nearest neighbors (kNN) · first mentioned: §10

是什么：非参数的惰性方法：$\operatorname{dist}(x,x_i)$ 全算一遍，选 $k$ 个最小者，返回多数类（或邻居均值）。

白话：不学任何东西，考试时翻笔记找最像的几条，照抄它们的答案。

干嘛用：基线模型、低维非线性分类/回归。

怎么算：距离 → 排序 → 取前 $k$ → 投票。记号提醒：这里的 $k$ 是邻居数（整数），与核函数 $k(x,z)$ 撞字母但毫无关系；$d$ 是特征维数。

为什么重要 + 连接：归纳偏好是"邻近输入有相似输出"；小 $k$ 边界局部、bias 低 variance 高，大 $k$ 相反——与 $\lambda$、$\sigma$ 一样是平滑旋钮，但作用于距离空间。

互动：滑动查询点与 $k$，重做讲义手算（A–E 五点）

讲义手算：训练点 A(0,−1)、B(1,−1)、C(2,+1)、D(3,+1)、E(10,−1)，查询 $x_q=2.4$，距离依次为 $2.4,1.4,0.4,0.6,7.6$（现算显示在上图）。$k=1$：最近邻 C，预测 $+1$；$k=3$：最近三个标签 $(+1,+1,-1)$，仍 $+1$；$k=5$：负类占多数，预测翻转为 $-1$——同一数据，$k$ 改变结论。

特征尺度与成本：若一个特征取值 $[0,1]$、另一个 $[0,10^6]$，Euclidean 距离几乎完全由后者决定——kNN 前通常要 standardization 或选更合理的度量。朴素 kNN 训练只需存储 $O(nd)$；单查询 $O(nd)$，$m$ 个查询 $O(mnd)$；低维可用 KD-tree 加速，高维中距离集中会削弱这些结构的效果。

§11决策树：递归切分 + Gini/entropy 收益 核心

分类树的内部节点检查 $x_j\le t$ 是否成立；叶节点输出类别概率或多数类。二维中每次切分产生一条轴对齐边界，多次切分把空间拼成矩形区域。生长是贪心的：每步选 impurity decrease 最大的切分，不保证全局最优树。

决策树 decision tree · first mentioned: §11

是什么：内部节点做 $x_j\le t$ 测试、叶节点给预测的递归划分模型。

白话：一本"if–then"问答手册：一路回答是非题，走到叶子得到答案。

干嘛用：可解释的非线性分类/回归；森林的基学习器。

怎么算：贪心生长——遍历候选 $(j,t)$，按加权 impurity 最小（等价 decrease 最大）切分，递归到停止条件。

为什么重要 + 连接：归纳偏好是"轴对齐、分段常数"；深度控制复杂度——浅树 bias 高 variance 低，深树相反（§12 与森林连接）；特征缩放改变 kNN 却通常不改变树（阈值排序不变）。

Gini 不纯度 Gini impurity · first mentioned: §11

是什么：$G(S)=1-\sum_{c=1}^Cp_c^2$，$p_c$ 为节点内类别比例。节点纯则 $G=0$。

白话：从节点里随机抽两个样本，标签不一致的概率。

干嘛用：给"这堆标签有多乱"定价，供切分比较。

怎么算：手算见下方例：父节点 $(7+,3-)$：$G=1-0.7^2-0.3^2=0.42$。

为什么重要 + 连接：与 entropy 强调相近的纯化方向，数值尺度不同；选择切分时最大化 decrease 而非节点 impurity（§14 误区 6）。

信息增益 information gain / impurity decrease · first mentioned: §11

是什么：切分后加权 impurity 的下降量：$\Delta I=I(S)-\big(\tfrac{|S_L|}{|S|}I(S_L)+\tfrac{|S_R|}{|S|}I(S_R)\big)$；$I$ 取 entropy $H(S)=-\sum p_c\log_2p_c$（约定 $0\log0=0$；二分类五五开时 $H=1$ bit）时称为 information gain。

白话：这一刀下去，标签堆"变纯了多少"。

干嘛用：贪心生长的选刀标准。

怎么算：讲义例：切分 $(5+,0-)/(2+,3-)$：$G(S_L)=0$、$G(S_R)=1-\tfrac{4}{25}-\tfrac{9}{25}=\tfrac{12}{25}=0.48$，加权 $=\tfrac5{10}\cdot0+\tfrac5{10}\cdot0.48=0.24$，$\Delta G=0.42-0.24=0.18$。

为什么重要 + 连接：综合题 3 用它比较两个候选切分（A 优）；下方互动把 $\Delta(t)$ 整条曲线画出来。

互动：滑动阈值 $t$，看 Gini/entropy 收益曲线与最优切分（父节点 7+/3−）

数据与对账：10 个一维点按 $x$ 升序，标签 $+++++\,++---$（7 正 3 负）。把 $t$ 放在 $3.4$ 与 $4.2$ 之间得到左 $(5+,0-)$、右 $(2+,3-)$：Gini 加权 $0.24$、$\Delta G=0.42-0.24=0.18$（讲义手算逐位一致）。收益曲线是分段常数（阈值跨过样本才变化），由公式对每个候选区间现算；Gini 与 entropy 尺度不同但峰值位置通常一致。深度控制复杂度：平衡树深度约 $O(\log n)$、单次预测 $O(D)$、高效实现训练量级约 $O(dn\log n)$。

§12随机森林：平均高方差的树 核心

通过两类随机性制造不同的树：每棵树用训练集的 bootstrap sample；每个节点只在随机抽取的特征子集中找切分。分类时 $B$ 棵树多数投票，回归时取平均。

Bootstrap 样本 bootstrap sample · first mentioned: §12

是什么：从训练集中有放回抽 $n$ 次得到的样本集（有重复、有遗漏）。

白话：每棵树拿一份"抄写有误的笔记"，错得各不相同。

干嘛用：让每棵树看到不同样本，制造树间差异。

怎么算：$n$ 次独立有放回抽样；配合节点级特征子抽样进一步降低树间相关性。

为什么重要 + 连接：差异是平均能降方差的前提；它与特征子抽样共同压低下面的相关系数 $\rho$。

随机森林 random forest · first mentioned: §12

是什么：$B$ 棵"bootstrap + 特征子抽样"训练的深树的平均（回归）或投票（分类）。

白话：问一屋子背景各异的人，把答案平均。

干嘛用：开箱即用的强非线性基线；主要收益是降 variance。

怎么算：for $b=1..B$：抽 bootstrap → 长深树（节点只搜随机特征子集）→ 平均/投票。成本约 $O(B\,m_{\mathrm{try}}\,n\log n)$，单点预测 $O(BD)$，可按树并行。

为什么重要 + 连接：bias 不会因平均自动消失（各树期望相同时平均不变）；对照 §11 单树的 bias-variance，森林把方差压向下面的 $\rho\sigma_T^2$ 下限。

方差公式：相关性留下一条下限

设每棵树在固定输入 $x$ 处的预测误差 $E_b$ 满足 $\operatorname{Var}(E_b)=\sigma_T^2$、$\operatorname{Cov}(E_b,E_{b'})=\rho\sigma_T^2\ (b\ne b')$。记号提醒：这里的 $\sigma_T^2$ 是树误差方差，与 RBF 的 bandwidth $\sigma$（§5）撞字母、毫无关系；$\rho$ 是相关系数。森林平均 $\overline T_B=\frac1B\sum_bT_b$ 的方差为 $$\operatorname{Var}(\overline T_B)=\frac1{B^2}\bigl[B\sigma_T^2+B(B-1)\rho\sigma_T^2\bigr]=\sigma_T^2\Bigl(\rho+\frac{1-\rho}{B}\Bigr).$$

第一项来自 $B$ 个方差项；第二项来自 $B(B-1)$ 个有序协方差对；除以 $B^2$ 因为取了平均。整理后：相关部分 $\rho\sigma_T^2$ 不随树数消失，不相关部分 $(1-\rho)\sigma_T^2/B$ 才按 $1/B$ 衰减。$B\to\infty$ 时方差趋于 $\rho\sigma_T^2$——只加树不能突破这条下限，随机特征子抽样的价值正是降低 $\rho$。综合题 5：$\sigma_T^2=1,\rho=0.2,B=25$ 时 $\operatorname{Var}=0.2+0.8/25=0.232$，极限 $0.2$；若完全独立（$\rho=0$）同样 25 棵树可到 $1/25=0.04$。

互动：$\rho$ 与 $B$ 怎么共同决定方差（对照独立极限）

§13常见误区 核心

每一条都先给出"听起来对"的说法，再给真相。

❌

误区 1：$K$ 奇异时不能使用 kernel ridge 闭式解。

✓ 真相：只要 $\lambda>0$，$K+\lambda I$ 一定正定可逆。奇异性导致的是 $\alpha$ 表示不唯一（§3 的 $\alpha_0+\ker K$），而不是预测函数不存在。

❌

误区 2：对称函数就是 valid kernel。

✓ 真相：还必须对任意有限输入集合产生 PSD Gram matrix（§6）。

❌

误区 3：在一批数据上检查 $K\succeq0$ 就证明了 kernel 合法。

✓ 真相：这只验证了当前有限矩阵；§8 互动里"差"组合偶尔不含负特征值也是同理——没有反例 ≠ 函数级证明。

❌

误区 4：RBF bandwidth 越小越好。

✓ 真相：小 $\sigma$ 局部且高方差，大 $\sigma$ 全局且高 bias；应与 $\lambda$ 一起用验证集选（§5）。

❌

误区 5：kNN 没有训练，所以没有模型复杂度。

✓ 真相：kNN 把训练集本身当作模型；小 $k$ 能形成非常复杂的边界，且预测与存储成本都不低（§10）。

❌

误区 6：Gini 和 entropy 越大越好。

✓ 真相：对节点本身，impurity 越小越纯；选择切分时要最大化 impurity decrease，而不是切分后的 impurity（§11）。

❌

误区 7：随机森林消除了单棵树的所有问题。

✓ 真相：森林主要降低 variance；$\rho\sigma_T^2$ 下限仍在（§12），bias、数据泄漏、标签噪声和无信息特征不会因投票自动消失。

§14收束：第 10 讲真正要带走的东西 核心

kernel、kNN、tree 与 forest 不是同一种非线性方法的不同包装——它们把四种不同的归纳偏好写进了模型。

四件兵器的归纳偏好（示意图）

kernel ridge 用隐式特征空间 + 正则化定义平滑函数；kNN 假设局部邻域共享标签；树用轴对齐规则递归划分空间；森林用去相关树的平均降低方差。选型要同时看表达能力、样本规模、预测成本、可解释性和 bias-variance。

核心问题 → 答案回顾

正则化怎么加？把 $\lambda\lVert w\rVert^2$ 搬到样本坐标：$\lambda\alpha^\top K\alpha$（它就是 $\lVert w\rVert^2$，不是 $\lVert\alpha\rVert^2$）。解还存在吗？$\alpha_0=(K+\lambda I)^{-1}y$ 只要 $\lambda>0$ 就永远成立；$K$ 奇异只带来 $\alpha_0+\ker K$ 的表示冗余，函数不变；谱上看每个标签分量被乘 $\mu_i/(\mu_i+\lambda)$。什么函数配当 kernel？对称 + 任意有限集合 PSD；用闭包规则安全组合。不用 kernel 的非线性？kNN 靠邻域、树靠轴对齐切分、森林靠去相关平均（方差下限 $\rho\sigma_T^2$）。

最重要的五个公式

$$J(\alpha)=\lVert y-K\alpha\rVert_2^2+\lambda\alpha^\top K\alpha \quad\text{（kernel ridge 目标：正则项就是 ‖w‖²）}$$ $$\alpha_0=(K+\lambda I)^{-1}y \quad\text{（λ>0 时永远存在；全部解为 α₀+ker K）}$$ $$\widehat y=U\operatorname{diag}\Big(\frac{\mu_i}{\mu_i+\lambda}\Big)U^\top y \quad\text{（谱收缩：小特征值方向先被压）}$$ $$k(x,z)=k(z,x),\quad a^\top Ka\ge0\ \forall\text{ 有限集合} \quad\text{（valid kernel 两块牌照）}$$ $$\operatorname{Var}(\overline T_B)=\sigma_T^2\Big(\rho+\frac{1-\rho}{B}\Big)\to\rho\sigma_T^2 \quad\text{（森林方差：加树不够，还要降 ρ）}$$
