用无限复杂的特征，
却从不真正
构造它们？

第 8 讲的 soft-margin SVM 已经给出线性分类器的全部零件；非线性仍然缺一块拼图。这一讲回答一个问题：能不能使用非常复杂、甚至无限维的非线性特征，同时避免显式构造这些特征？答案是可以——前提是训练和预测只通过特征向量之间的内积使用这些特征。本讲把 feature map、样本张成空间、Gram matrix 与 kernel trick 连成一条可以手算、可以推导的主线。

💬 本讲核心问题：高维（甚至无限维）特征能给模型带来非线性表达力，但显式构造它们在计算上不可行。有没有办法只享受内积、不支付构造代价？
一句话答案：可以。两条观察保证解向量 $w$ 只住在 $n$ 个训练特征张成的子空间里（梯度走不出去 + 正则化最优解主动留在里面），于是 $w=\Phi^\top\alpha$ 把未知量换成 $n$ 个系数；代入预测后公式里只剩特征内积，把每个内积换成一个核函数 $k(x,z)=\phi(x)^\top\phi(z)$，就得到 kernel trick：用 $n\times n$ 的 Gram matrix 换掉 $n\times p$ 的显式特征矩阵。

📌 今天讲什么

从“圆形边界怎么变直”出发：特征映射 → 特征数量爆炸 → 梯度住在样本 span 中 → 正则化最优解也住在 span 中（representer theorem）→ 重参数化 $w=\Phi^\top\alpha$ → 核函数与核化模型 → Gram matrix 与 $\widehat y=K\alpha$ → kernelization 三步 → 多项式核 / RBF 核 → PSD → 收益与代价。

🔥 为什么重要

线性模型 + 特征映射是“受控的非线性”：表达力来自 $\phi$，理论（凸性、几何）来自线性。kernel trick 让你可以把 $\phi$ 推到无限维而计算量只依赖样本数 $n$。它是第 10 讲 kernel ridge / valid kernel 判据、以及此后一切“按样本相似度工作”的方法的地基。

🧭 主线逻辑（整讲五步）

① 变直：加非线性特征，弯的边界在特征空间里是直的（§1）。 ② 爆炸：显式构造特征的数量与内存不可行（§2）。 ③ 两条观察：梯度与正则化最优解都住在训练特征的 span 中（§3–§4）。 ④ 换变量：$w=\Phi^\top\alpha$，预测只剩内积（§5）。 ⑤ 收进矩阵：$K=\Phi\Phi^\top$，$\widehat y=K\alpha$，用 $k$ 替换一切内积（§6–§7）。
📍 位置：分类 II / soft-margin（L8）→ kernel trick（L9） → kernel ridge 与 valid kernel（L10） 🧩 前置：向量内积、矩阵乘法维度、正交分解、链式法则求梯度 🎯 产出：一套能手算 $K$、能推导 $w=\Phi^\top\alpha$、能解释 bandwidth 与 PSD的核方法语言

§1非线性边界可以来自线性模型 核心

考虑二维分类：圆内为正类，圆外为负类。原始输入上的线性模型 $f(x)=w_1x_1+w_2x_2+b$ 只能产生直线边界，画不出圆。但只要把“到原点的距离信息”加进特征，同一个线性机器立刻会画圆——这一节先把“弯的变直”这件事亲手算一遍。

特征映射 feature map · first mentioned: §1

是什么：把原始输入 $x\in\mathcal X$ 变换成特征向量的函数 $\phi:\mathcal X\to\mathbb R^p$（更一般地映射到某个内积空间 $\mathcal H$）。本讲的圆例子取 $$\phi(x)=\begin{bmatrix}1&x_1&x_2&x_1^2&x_1x_2&x_2^2\end{bmatrix}^\top\in\mathbb R^6,$$ 即所有次数 $\le 2$ 的单项式（带常数坐标 $1$）。

白话：给每个点重新“报户口”——不光报坐标，还报坐标的平方、乘积这些衍生信息。

干嘛用：让线性模型产生非线性决策边界；表达力全部来自 $\phi$ 的选择。

怎么算：代入坐标即可。例如 $x=(2,3)^\top$ 时 $\phi(x)=(1,2,3,4,6,9)^\top$。

为什么重要 + 连接：模型在 $\phi(x)$ 上线性、在 $x$ 上非线性——这是“受控非线性”的统一姿势。$\phi$ 的维数 $p$ 可以远大于输入维数 $d$，这正是 §2 要付出的代价、也是 §5 kernel trick 要绕开的对象。

特征矩阵 feature matrix · first mentioned: §1

是什么：把 $n$ 个样本的特征向量逐行堆叠： $$\Phi=\begin{bmatrix}\phi(x_1)^\top\\ \vdots\\ \phi(x_n)^\top\end{bmatrix}\in\mathbb R^{n\times p},\qquad w\in\mathbb R^p,\qquad \alpha\in\mathbb R^n.$$ $\Phi$ 的第 $i$ 行是 $\phi(x_i)^\top$。

白话：一张“每行一个样本、每列一个特征”的大表。

干嘛用：把逐样本公式压缩成一次矩阵乘法，方便检查维度。

怎么算：本讲始终用两条恒等式 $w=\Phi^\top\alpha$ 与 $K=\Phi\Phi^\top$；维度检查 $\underbrace{\Phi^\top}_{p\times n}\underbrace{\alpha}_{n\times1}=\underbrace{w}_{p\times1}$，$\underbrace{\Phi}_{n\times p}\underbrace{\Phi^\top}_{p\times n}=\underbrace{K}_{n\times n}$。

为什么重要 + 连接：注意两个“维度”的区别——原始输入 $x$ 有 $d$ 个坐标，特征向量 $\phi(x)$ 有 $p$ 个坐标。$\Phi$ 是有限维记号；若特征空间无限维，就把 $\Phi\Phi^\top$ 理解为“逐对计算内积”得到的 $n\times n$ Gram matrix（§6），而不是真的创建无限宽矩阵。

圆的例子：一行就画出来

取 $w=(4,0,0,-1,0,-1)^\top$，则 $$f(x)=w^\top\phi(x)=4-x_1^2-x_2^2.$$ 决策边界 $f(x)=0$ 等价于 $x_1^2+x_2^2=4$，即半径为 $2$ 的圆。分类时真正要做的只是比较 $f(x)$ 的符号：$f(x)>0$ 判为圆内（正类），$f(x)<0$ 判为圆外（负类）。

记号提醒（先声明，避免混淆）：本讲用 $\ell(y,s)$（小写 ell）表示逐样本损失函数，与数字 $1$、字母 $l$ 无关；样本下标 $i$ 与输入维数 $d$、特征维数 $p$ 各司其职。另外本讲 $k(x,z)$ 是标量的 kernel、$K$ 是 $n\times n$ 矩阵、$k_x$ 是 $n\times 1$ 列向量（§6 定义的“相似度清单”）——三个“k”会在 §5–§6 先后登场，到时再逐一区分。

§2为什么不直接把所有特征都算出来 核心

问题在于特征数量会迅速膨胀。对 $d$ 维输入，所有总次数不超过 $m$ 的单项式数量为 $$p=\binom{d+m}{m}.$$ 也就是说“加特征”的代价随 $m$ 呈组合式增长，而不是线性增长。

§3第一条观察：梯度始终在样本特征的 span 中 核心

这一节回答一个很实际的问题：特征空间可能有 $p$ 个坐标、甚至无限维，但训练集只有 $n$ 个样本——优化时真的需要在整个特征空间里到处寻找吗？答案是：从 $w_0=0$ 出发，经验损失的梯度每一步都只由这 $n$ 个训练样本的特征向量拼出来。

张成子空间 span · first mentioned: §3

是什么：训练特征向量所有线性组合构成的集合 $$S=\operatorname{span}\{\phi(x_1),\ldots,\phi(x_n)\}=\Big\{\textstyle\sum_{i=1}^n a_i\phi(x_i)\ :\ a\in\mathbb R^n\Big\}\subseteq\mathbb R^p.$$

白话：只允许用训练样本的特征方向“搭积木”，能搭出来的整个平面/超平面。

干嘛用：把“整个 $p$ 维空间”的搜索缩小到“至多 $n$ 个生成方向”的子空间。

怎么算：判断 $v\in S$ 只需看能否写出 $v=\sum_i a_i\phi(x_i)$；本讲更实用的判据是梯度公式本身（下方推导）。

为什么重要 + 连接：当 $p\gg n$ 时 $S$ 只是特征空间里极薄的一片；§4 将证明正则化最优解也住在这里，于是 $w$ 只需 $n$ 个系数（§5）。

推导：链式法则给出 $\nabla_wL(w)\in S$

考虑逐样本损失 $$L(w)=\frac1n\sum_{i=1}^n \ell\!\left(y_i,\,w^\top\phi(x_i)\right),\qquad s_i(w)=w^\top\phi(x_i).$$ 这里 $w,\phi(x_i)\in\mathbb R^p$，所以 $s_i(w)$ 是标量。损失对 $w$ 的依赖只有一条路径 $w\to s_i\to\ell$，逐段使用链式法则： $$\nabla_w\ell(y_i,s_i(w))=\frac{\partial \ell(y_i,s)}{\partial s}\bigg|_{s=s_i(w)}\ \nabla_ws_i(w),\qquad \nabla_ws_i(w)=\phi(x_i),$$ 所以 $$\nabla_wL(w)=\frac1n\sum_{i=1}^n c_i(w)\,\phi(x_i),\qquad c_i(w)=\frac{\partial \ell(y_i,s)}{\partial s}\bigg|_{s=w^\top\phi(x_i)}.$$

人话：$c_i(w)$ 只是“预测稍微改变时，单样本损失变化多快”的标量；关键不是它的具体形式，而是它是标量——所以每一项 $c_i(w)\phi(x_i)$ 都是训练特征的数乘，梯度只能沿训练特征的方向叠加。

再往前一步（归纳）：从 $w_0=0\in S$ 开始做梯度下降 $w_{t+1}=w_t-\eta_t\nabla_wL(w_t)$。若 $w_t\in S$，则减号右边两项都在 $S$ 中，因此 $w_{t+1}\in S$；由归纳法 $w_t\in S$ 对所有 $t\ge0$ 成立。训练轨迹从不离开 $S$。

§4第二条观察：最优解可以选在这个 span 中 核心

证明思路是把任意 $w$ 拆成“训练数据看得见”和“训练数据完全看不见”两部分，再看正则项如何惩罚后者。

正交分解 orthogonal decomposition · first mentioned: §4

是什么：任取 $w\in\mathbb R^p$，唯一地写成 $$w=w_\parallel+w_\perp,\qquad w_\parallel\in S,\quad w_\perp\in S^\perp,$$ 其中 $S^\perp$ 是与 $S$ 中所有向量正交的方向集合。

白话：把 $w$ 拆成“训练数据看得见的平行部分”和“完全看不见的垂直部分”。

干嘛用：证明垂直部分对训练预测毫无贡献，只会增加范数。

怎么算：$w_\parallel$ 是 $w$ 在 $S$ 上的投影（一维 span 时 $w_\parallel=(w^\top u)u$，$u$ 为单位方向），$w_\perp=w-w_\parallel$。

为什么重要 + 连接：因为每个 $\phi(x_i)\in S$，所以 $w_\perp^\top\phi(x_i)=0$，于是所有训练预测满足 $w^\top\phi(x_i)=w_\parallel^\top\phi(x_i)$。$w_\perp$ 不改变任何一个训练点的预测——下面的正则项正是要在这些“数据看不见”的方向上额外收费。

加正则化后，结论更强（representer theorem 的核心）

只依赖训练预测的经验损失满足 $L(w)=L(w_\parallel)$。考虑 $$J(w)=L(w)+\lambda\lVert w\rVert_2^2,\qquad \lambda>0.$$ 由勾股定理 $\lVert w\rVert_2^2=\lVert w_\parallel\rVert_2^2+\lVert w_\perp\rVert_2^2$，所以 $$J(w)-J(w_\parallel)=\lambda\lVert w_\perp\rVert_2^2\ \ge\ 0,$$ 且只要 $w_\perp\ne0$ 就严格大于零。因此带平方范数正则化的最优解必须满足 $w_\perp=0$，即 $w\in S$。

Representer 定理 representer theorem · first mentioned: §4

是什么：当经验损失只通过训练点上的预测值进入目标、复杂度项是特征空间（或 RKHS）范数的平方且 $\lambda>0$ 时，最优解可以写成 $w=\sum_i\alpha_i\phi(x_i)$。

白话：与其在 $p$ 个特征坐标里大海捞针，不如直接找 $n$ 个“每个训练样本贡献多少”的系数。

干嘛用：把未知量从 $w\in\mathbb R^p$ 换成 $\alpha\in\mathbb R^n$，这是 kernel 方法的理论通行证。

怎么算 / 怎么用：先正交分解、再比较 $J(w)$ 与 $J(w_\parallel)$（上面的两行证明）；$\alpha$ 的具体数值由训练问题决定（第 10 讲会解 kernel ridge）。

为什么重要 + 连接：注意边界条件——对任意目标函数或任意正则项不能直接套用；没有正则项时最小值未必唯一（“数据看不见”的方向不受惩罚）。它只保证 $w$ 可由训练特征组合，还没省掉 $\phi(x)$——那是 §5 的事。

下一步 →现在 $w$ 有了 $n$ 个系数的表示。下一节把它写成矩阵形式 $w=\Phi^\top\alpha$ 并代入预测——高维特征将第一次成对地消失在内积里。

§5从 $w$ 到 $\alpha$：$w=\Phi^\top\alpha$ 与核函数 核心

这一节把未知量从特征坐标中的 $w\in\mathbb R^p$，换成“每个训练样本贡献多少”的 $\alpha\in\mathbb R^n$。这常被称为从 primal（原始）表示转到 kernel / 样本表示；这里只是用 representer 结论重参数化，并不是又解了一个新的优化问题。

一条等号链，四个等号各有任务

因为 $w\in S$，按 span 的定义存在系数 $\alpha_1,\ldots,\alpha_n$ 使 $w=\sum_{i=1}^n\alpha_i\phi(x_i)$，按 $\Phi$ 的定义这正是 $w=\Phi^\top\alpha$。对新输入 $x$，预测为 $$\begin{aligned} f_\alpha(x)&=w^\top\phi(x) &&\text{（原来的线性预测）}\\ &=(\Phi^\top\alpha)^\top\phi(x) &&\text{（代入 } w=\Phi^\top\alpha\text{）}\\ &=\alpha^\top\Phi\phi(x) &&\text{（}(AB)^\top=B^\top A^\top\text{）}\\ &=\sum_{i=1}^n\alpha_i\,\phi(x_i)^\top\phi(x) &&\text{（逐分量展开）} \end{aligned}$$

维度闭合：$\alpha^\top$ 是 $1\times n$，$\Phi$ 是 $n\times p$，$\phi(x)$ 是 $p\times1$，最终得到一个标量预测。最后一行只包含特征向量的内积。

核函数 kernel function · first mentioned: §5

是什么：$$k(x,z)=\phi(x)^\top\phi(z),$$ 即两个点特征内积的直接记号——不一定知道或写出 $\phi$ 本身。

白话：一个“相似度打分器”：先各自升维再点积的结果，一步算出。

干嘛用：把“高维空间的几何”压缩成一次标量函数计算。

怎么算：例如 $k(x,z)=(1+x^\top z)^2$、$k_\sigma(x,z)=\exp(-\lVert x-z\rVert^2/2\sigma^2)$（§8–§9）。

为什么重要 + 连接：kernel 的本质正是隐式特征内积——我们不一定知道 $\phi$，但几何解释仍来自特征空间；合法性判据（PSD）在 §10。

核化模型 kernelized model · first mentioned: §5

是什么：$$f_\alpha(x)=\sum_{i=1}^n\alpha_i\,k(x_i,x).$$ 把核函数代入重参数化预测后的模型。

白话：新点的预测 = 各训练点按“像不像”加权投票，票重是 $\alpha_i$。

干嘛用：$p\gg n$ 时这不是记号游戏：预测只需 $n$ 个 kernel 值，不必写出 $\phi(x)$ 的每个坐标。

怎么算：对每个训练点算 $k(x_i,x)$，乘 $\alpha_i$，求和（下面的互动逐步演示）。

为什么重要 + 连接：$\alpha_i$ 是训练点 $x_i$ 对预测的贡献权重；§6 把训练点之间的内积收进 Gram matrix，§7 给出完整的替换操作规程。

两个约定，先说清楚

① 截距 $b=0$：本讲的 $f_\alpha$ 没有单独截距项。若 $\phi(x)$ 含常数坐标 $1$（如 §1 的圆特征），截距已含在 $w^\top\phi(x)$ 中；若不含而需要显式截距，应写 $f_{\alpha,b}(x)=b+\sum_i\alpha_ik(x_i,x)$，且通常不对 $b$ 施加平方范数正则化。② 三个“k”：$k(x,z)$ 标量函数、$K\in\mathbb R^{n\times n}$ 矩阵、$k_x\in\mathbb R^n$ 列向量（§6 定义的“相似度清单”）——大小写与下标各表身份，不要混写。

§6Gram matrix 与训练预测 核心

目标：把 $n$ 个训练点的预测同时写成一次矩阵乘法。

Gram 矩阵 Gram matrix · first mentioned: §6

是什么：训练样本两两之间的特征内积组成的矩阵 $$K=\Phi\Phi^\top\in\mathbb R^{n\times n},\qquad K_{ij}=\phi(x_i)^\top\phi(x_j)=k(x_i,x_j).$$

白话：一张“相似度地图”——第 $(i,j)$ 格是样本 $i$ 与样本 $j$ 的特征内积。

干嘛用：训练阶段所有“训练点之间”的核值一次收齐，$\widehat y=K\alpha$。

怎么算：手算时先算原始内积 $x_i^\top x_j$ 再代入 kernel（§7 互动逐步演示）。对称性 $K_{ij}=K_{ji}$ 让行列两种读法数值相同。

为什么重要 + 连接：RBF 时对角线 $K_{ii}=1$、样本成块时出现深色块；但它必须 PSD 才是合法 Gram matrix（§10）。

核向量 kernel vector · first mentioned: §6

是什么：对新输入 $x$，收集它与所有训练点的核值： $$k_x=\begin{bmatrix}k(x_1,x)\\ \vdots\\ k(x_n,x)\end{bmatrix}\in\mathbb R^n,\qquad f_\alpha(x)=k_x^\top\alpha.$$

白话：新点的“相似度清单”：跟每个训练点各像几分。

干嘛用：预测阶段的全部工作量——算 $n$ 个数再加权求和。

怎么算：逐点代入 kernel；注意 $k_x$ 与 $K$ 的第 $j$ 行（写成列向量时 $K_{j,:}^\top$）在 $x=x_j$ 时重合。

为什么重要 + 连接：训练/预测两条公式 $$\widehat y_{\mathrm{train}}=K\alpha,\qquad f_\alpha(x)=k_x^\top\alpha$$ 分别用 $K$ 与 $k_x$，正好对应“训练阶段 / 预测阶段”两件事。

下标方向别凭感觉：第 $j$ 个训练点的 kernel vector 是 $K$ 的第 $j$ 行；预测 $$f_\alpha(x_j)=\sum_{i=1}^n\alpha_ik(x_i,x_j)=\sum_{i=1}^nK_{ji}\alpha_i,$$ 第二个等号用 $K_{ji}=k(x_j,x_i)=k(x_i,x_j)$ 的对称性。右侧正是 $K\alpha$ 的第 $j$ 个分量，所以 $\widehat y=K\alpha$。对称性只是让两种写法数值相同，行/列的语义来自定义。

下一步 →零件齐了：span 观察、重参数化、$K$ 与 $k_x$。下一节把 kernel trick 压缩成三步操作规程，并检查凸性有没有丢。

§7Kernelization 的三步与凸性 核心

三步的目标不是“把公式里的 $\phi$ 字样换掉”，而是确保训练目标和预测公式中只剩内积——只有这样，才能用 $k$ 代替高维特征计算。

Step Ⅰ 限制并重参数化

把 $w$ 限制在样本 span 中并改写为 $$w=\Phi^\top\alpha.$$ 依据是 §3–§4 的两条观察。

Step Ⅱ 识别所有内积

代入后清点：公式里出现的高维对象只剩成对内积 $$\phi(x_i)^\top\phi(x_j).$$ 预测、训练目标都在此列。

Step Ⅲ 用核函数替换

$$\phi(x_i)^\top\phi(x_j)\ \longrightarrow\ k(x_i,x_j).$$ 从此 $\phi$ 不再出现，计算只经过 $k$。

核化 kernelization · first mentioned: §7

是什么：把一个“只通过内积使用特征”的算法/目标改写成只含 kernel 值的形式的整套流程（上面三步）。

白话：给算法做一次“内积替换手术”，手术后再也看不见高维向量。

干嘛用：让 §2 的三个愿望同时兑现：表达力来自 $\phi$（隐式）、不构造 $\Phi$、凸性保留。

怎么算：例如平方损失变为 $$L(\alpha)=\frac1n\lVert y-K\alpha\rVert_2^2,\qquad \Phi w=\Phi(\Phi^\top\alpha)=(\Phi\Phi^\top)\alpha=K\alpha.$$

为什么重要 + 连接：前提“只通过内积使用特征”不可破坏——若算法需要 $\phi(x)$ 的单个坐标（如 $L_1$ 正则 $\lVert w\rVert_1$），就无法核化。

凸性没有丢

若 $K$ 对称，平方损失的梯度与 Hessian 为 $$\nabla_\alpha L(\alpha)=\frac2nK(K\alpha-y),\qquad \nabla_\alpha^2L(\alpha)=\frac2nK^2,$$ 且对任意 $v\in\mathbb R^n$， $$v^\top K^2v=(Kv)^\top(Kv)=\lVert Kv\rVert_2^2\ \ge\ 0,$$ 所以平方损失关于 $\alpha$ 仍是凸函数。更一般地：只要每个 $\ell(y_i,\cdot)$ 凸、预测 $K_{i,:}\alpha$ 对 $\alpha$ 仿射，kernelized 经验损失就仍凸。

§8Polynomial kernel：系数缩放不能漏 拓展

常用的 $m$ 次非齐次多项式 kernel 是 $$k(x,z)=(c+x^\top z)^m,\qquad c\ge0.$$ 它看起来朴素，但对应的特征映射里藏着 $\sqrt2$ 因子——漏掉它们是最常见的手算错误。

多项式核 polynomial kernel · first mentioned: §8

是什么：$k(x,z)=(c+x^\top z)^m$；以 $d=2$、$c=1$、$m=2$ 为例 $$k(x,z)=(1+x_1z_1+x_2z_2)^2=1+2x_1z_1+2x_2z_2+x_1^2z_1^2+2x_1x_2z_1z_2+x_2^2z_2^2.$$

白话：先把内积加一，再取 $m$ 次幂——一次幂运算同时算出所有交叉项的总内积。

干嘛用：隐式使用全部次数 $\le m$ 的单项式特征（共 $\binom{d+m}{m}$ 个，见 §2）。

怎么算：精确匹配该 kernel 的特征映射是 $$\phi(x)=\begin{bmatrix}1&\sqrt2x_1&\sqrt2x_2&x_1^2&\sqrt2x_1x_2&x_2^2\end{bmatrix}^\top,$$ 直接验证 $\phi(x)^\top\phi(z)=(1+x^\top z)^2$。

为什么重要 + 连接：常见错误是把特征写成 $(1,x_1,x_2,x_1^2,x_1x_2,x_2^2)^\top$ 就声称内积等于 $(1+x^\top z)^2$——这组特征能表达同一类二次多项式，但缺 $\sqrt2$ 缩放时内积并不等于这个特定 kernel（下面的互动专门对这笔账）。计算上：显式构造需 $p=\binom{d+m}{m}$ 维，而 $x^\top z$ 只要 $O(d)$，再取 $m$ 次幂即可。

下一步 →多项式核的世界仍是有限维。下一节的高斯 RBF 对应无限维特征空间，却只用一次指数计算——参数 $\sigma$ 就是它的“视野旋钮”。

§9RBF kernel：把“近”变成相似度 拓展

Gaussian RBF kernel 写作 $$k_\sigma(x,z)=\exp\!\left(-\frac{\lVert x-z\rVert_2^2}{2\sigma^2}\right),\qquad \sigma>0,$$ 它满足 $k_\sigma(x,x)=1$；当 $\lVert x-z\rVert_2$ 很大时，$k_\sigma(x,z)$ 接近 $0$。

RBF 核 / 高斯核 radial basis function kernel · first mentioned: §9

是什么：$k_\sigma(x,z)=\exp(-\lVert x-z\rVert_2^2/2\sigma^2)$，以距离为自变量的径向基函数。

白话：“离得近就像（接近 1），离得远就不像（接近 0）”的打分器。

干嘛用：在核化模型里，每个训练点都变成一个以 $x_i$ 为中心的局部基函数：$\alpha_i>0$ 时在附近向上推，$\alpha_i<0$ 时向下压。

怎么算：代入距离与 $\sigma$ 一步算出；很多库写 $k(x,z)=\exp(-\gamma\lVert x-z\rVert^2)$，关系是 $\gamma=1/(2\sigma^2)$。

为什么重要 + 连接：RBF 对应无限维特征空间——kernel trick 的意义不是列出无限多个特征，而是用一次有限的函数计算得到它们的总内积。

带宽 bandwidth · first mentioned: §9

是什么：RBF 中的尺度参数 $\sigma$（等价参数 $\gamma=1/2\sigma^2$）。

白话：每个训练点的“影响半径”：$\sigma$ 小→只管脚下一亩地；$\sigma$ 大→隔着老远也发声。

干嘛用：控制模型的局部 / 全局程度，是最重要的单个超参数。

怎么算：读图标尺：取 $r=\sigma$，则无论 $\sigma$ 多大都有 $k_\sigma=e^{-1/2}\approx0.607$——改变 $\sigma$ 本质上是水平拉伸 / 压缩同一条钟形曲线。

为什么重要 + 连接：$\sigma$ 小→基函数局部、函数灵活、方差与过拟合风险高；$\sigma$ 大→影响范围广、函数平滑全局。不能只凭训练拟合程度判断好坏，必须用 validation / cross-validation 选。

下一步 →任何 kernel 都必须回答一个合法性问题：它算出来的 $K$ 凭什么总能当“内积表”用？下一节证明 Gram matrix 一定是 PSD。

§10为什么 Gram matrix 一定是 PSD 拓展

要证明的不是“矩阵元素都非负”。PSD 的定义是：任取系数 $a$，二次型 $a^\top Ka$ 都不能为负。把 $K=\Phi\Phi^\top$ 代进去，这个二次型会变成一个向量长度的平方。

半正定 positive semidefinite (PSD) · first mentioned: §10

是什么：对任意 $a\in\mathbb R^n$ 都有 $a^\top Ka\ge0$，记作 $K\succeq0$。

白话：随便怎么给样本加权组合，组合特征的“长度平方”都不可能是负数。

干嘛用：合法 Gram matrix 的判定标准；也是凸性的来源。

怎么算 / 怎么证：由 $K=\Phi\Phi^\top$， $$a^\top Ka=a^\top\Phi\Phi^\top a=(\Phi^\top a)^\top(\Phi^\top a)=\lVert\Phi^\top a\rVert_2^2\ \ge\ 0.$$ 第二个等号只是重新加括号并使用 $a^\top\Phi=(\Phi^\top a)^\top$；最后一项是欧氏范数平方，不可能为负。

为什么重要 + 连接：三层意义——几何上 $K$ 真是某组向量的两两内积；谱上所有特征值非负；优化上 $\alpha^\top K\alpha$ 是凸二次型。若 $K$ 奇异不表示 kernel 非法，只说明 $\phi(x_i)$ 线性相关或 $\alpha$ 表示不唯一（§12 误区 2）。第 10 讲把它提升为 valid kernel 的判据：一个函数要对任意有限输入集合产生 PSD Gram matrix。

§11Kernel trick 的收益与代价 拓展

kernel 方法避免显式存储 $\Phi\in\mathbb R^{n\times p}$，但必须处理 $K\in\mathbb R^{n\times n}$：朴素构造并存储 $K$ 需要 $n^2$ 个 kernel 值和 $O(n^2)$ 内存；直接求解稠密线性系统通常需要 $O(n^3)$ 时间。

§12常见误区 核心

每一条都先给出“听起来对”的说法，再给真相。建议先自己想一遍再看下去。

❌

误区 1：kernel 与 feature map 无关，选 kernel 就是选一个相似度函数。

✓ 真相：kernel 的本质正是隐式特征内积 $k(x,z)=\phi(x)^\top\phi(z)$。我们不一定知道或写出 $\phi$，但几何解释仍来自特征空间——PSD、凸性、带宽的直觉全部建立在这上面。

❌

误区 2：$w=\Phi^\top\alpha$ 的表示一定唯一，所以 $\alpha$ 就是“真正的参数”。

✓ 真相：若训练特征线性相关，$\Phi^\top$ 有非平凡零空间，不同的 $\alpha$ 可能给出同一个 $w$。唯一性不是 kernel trick 成立的必要条件。

❌

误区 3：kernel trick 总会减少计算。

✓ 真相：它减少的是对巨大特征维度 $p$ 的显式计算，代价是 $n\times n$ 的 $K$。当 $n$ 很大时这个代价可能更严重（§11 的天平亲测）。

❌

误区 4：RBF bandwidth 越小越精确，所以越小越好。

✓ 真相：小 $\sigma$ 让模型更局部，通常降低训练误差，但也提高方差和过拟合风险。带宽必须通过 validation 或 cross-validation 选择。

❌

误区 5：对称矩阵就是 Gram matrix。

✓ 真相：还不够。Gram matrix 必须 PSD——§10 的互动里 $\rho=2$ 的矩阵对称、元素非负，却有负特征值。第 10 讲会系统学习 valid kernel 的对称性与 PSD 条件。

§13收束：第 9 讲真正要带走的东西 核心

kernel trick 没有消灭复杂特征，而是把它们隐藏在内积计算中：用样本维度 $n$ 上的 Gram matrix 换掉了特征维度 $p$ 上的显式表示。

核心问题 → 答案回顾

能不能使用非常复杂、甚至无限维的非线性特征，同时避免显式构造它们？能——只要训练和预测只通过特征向量之间的内积使用这些特征：梯度与正则化最优解都住在训练特征的 span 中（$w=\Phi^\top\alpha$），预测与训练预测分别化为 $f_\alpha(x)=k_x^\top\alpha$ 与 $\widehat y=K\alpha$，于是每个内积都可以换成一次核函数计算。

最重要的五个公式

$$w=\Phi^\top\alpha \quad\text{（representer：解向量住在样本 span 中，}\alpha\in\mathbb R^n\text{）}$$ $$f_\alpha(x)=\sum_{i=1}^n\alpha_i\,k(x_i,x)=k_x^\top\alpha \quad\text{（核化模型：预测只剩内积）}$$ $$K=\Phi\Phi^\top,\quad K_{ij}=k(x_i,x_j),\quad \widehat y=K\alpha \quad\text{（Gram matrix：训练一次收齐）}$$ $$a^\top Ka=\lVert\Phi^\top a\rVert_2^2\ge0 \quad\text{（PSD：内积表的合法性）}$$ $$k_\sigma(x,z)=\exp\!\Big(-\tfrac{\lVert x-z\rVert_2^2}{2\sigma^2}\Big),\quad \gamma=\tfrac1{2\sigma^2} \quad\text{（RBF：无限维特征的一次式计算）}$$
