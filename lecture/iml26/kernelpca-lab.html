数据是弯的，
投影是直的，
怎么办？

第 16 讲的 PCA 只会做正交投影到线性子空间：卷起来的 Swiss roll 被压扁后不同层互相重叠。这一讲走两条非线性路线：kernel PCA——把数据先送进隐式特征空间，在那里做“线性” PCA，全程只用 kernel 值；autoencoder——用带瓶颈的网络同时学习编码与解码。本讲把中心化 Gram matrix、$\sqrt{\lambda}$ 归一化、新点投影，以及“线性 autoencoder 学到的正是 PCA 子空间”这些可手算的细节串成一条主线。

💬 本讲核心问题：当数据的低维结构是弯曲的，为什么普通 PCA 必然失败？在看不到 $\phi(x)$ 的前提下，怎么正确地中心化、归一化、并把新点投进去？另一条路——autoencoder——又分别在线性与非线性时学到了什么？
一句话答案：PCA 失败不是数值问题而是函数类太简单——线性映射只能产生平面坐标。kernel PCA 把 PCA 的目标搬到特征空间：方向写成训练特征的组合 $u=\sum_i\alpha_i\tilde\phi_i$，一切内积换成 kernel 值，问题归结为中心化 Gram matrix $K_c=HKH$ 的特征分解；坐标是 $z_r(x_i)=\sqrt{\lambda_r}\,v_{ir}$（系数必须除以 $\sqrt{\lambda_r}$ 而不是 $\lambda_r$），新点用同一套训练均值做四项中心化后投影。autoencoder 用瓶颈施加压缩：线性 + 平方重构 + 中心化数据时，最优重建子空间与 PCA 前 $k$ 维完全相同；非线性激活才换来拟合弯曲流形的能力（和一整套新代价）。

📌 今天讲什么

Swiss roll 诊断 → 在特征空间里写同一个 PCA 目标 → representer 形式把方向换成 $n$ 个系数 → 双中心化 $K_c=HKH$ → 三点手算例 → $\sqrt\lambda$ 归一化与训练坐标 → 新点的四项中心化投影 → RBF 带宽两极 → 换路线：autoencoder 瓶颈与重构损失 → 线性情形 = PCA 子空间 → 非线性能力与评估陷阱。

🔥 为什么重要

真实数据（图像、基因表达、传感器）的低维结构常常是弯曲流形。kernel PCA 给出“把第 9–10 讲的 kernel 工具直接接到第 16 讲的 PCA 上”的标准范式；autoencoder 则是现代自监督表示学习的原型。两者互补：前者可审计、有闭式解；后者可扩展到 mini-batch 与大数据。

🧭 主线逻辑（整讲五步）

① 病：线性投影压弯为平，卷层重叠（§1–§2）。 ② 搬：把 PCA 目标搬进特征空间，方向用系数表示（§3）。 ③ 算：双中心化 $K_c$、特征分解、$\sqrt\lambda$ 归一化（§4–§5）。 ④ 用：训练坐标与样本外投影共用训练均值（§6–§7）。 ⑤ 替：autoencoder——线性时回到 PCA 子空间，非线性时弯曲展开（§8–§10）。

§1从 Swiss roll 诊断线性 PCA 核心

把一张二维纸卷成三维 Swiss roll：每个样本在观测空间是 $x_i\in\mathbb R^3$，但在纸面上的内在自由度仍接近二维。普通 PCA 只能选一个二维平面做正交投影——卷起来的不同层可能互相重叠，于是原本在纸面上相距很远的点会在投影中靠近。

Swiss roll Swiss roll · first mentioned: §1

是什么：把二维平面卷成三维螺旋得到的经典数据集；点 $(t\cos t,\ h,\ t\sin t)$ 由内在坐标 $(t,h)$ 生成。

白话：一张卷起来的地毯——本身是平的，但住在三维世界里。

干嘛用：检验降维方法能否“展开”弯曲结构。

怎么算：参数 $t$ 沿卷曲方向、$h$ 沿高度；颜色按 $t$ 着色即可看出展开是否成功（下方互动）。

为什么重要 + 连接：PCA 在它上面的失败不是数值错误，而是函数类太简单——线性映射 $f(x)=W^\top x$ 只能产生平面坐标，不能把弯曲纸面展开。

流形 manifold · first mentioned: §1

是什么：局部看似低维、整体可能弯曲的结构；Swiss roll 是二维流形嵌入三维的例子。

白话：地球表面——局部像平面，整体是个球。

干嘛用：给“高维数据其实只有几个自由度”提供几何语言。

怎么算：无显式公式；通过降维方法寻找内在坐标。

为什么重要 + 连接：本讲标题“非线性降维”的目标就是恢复流形坐标——kernel PCA 靠特征空间把它“拉直”，autoencoder 靠非线性编码把它“展开”。

非线性降维 nonlinear dimensionality reduction · first mentioned: §1

是什么：用非线性映射获得低维表示的方法族；本讲的两条路线是 kernel PCA 与 autoencoder。

白话：不再用直尺量弯路——先想办法把路抻直，或者学会“看形状抄近路”。

干嘛用：可视化、去冗余、为聚类/下游任务准备特征。

怎么算：kernel 路线 = 特征空间线性 PCA（§2–§7）；网络路线 = 瓶颈重构（§8–§10）。

为什么重要 + 连接：第 16 讲的 PCA 是它的线性特例；选路线时要同时看样本量、kernel/架构先验与计算预算。

互动：旋转 Swiss roll，再看线性 PCA 把它压成什么样

怎么读图：颜色 = 纸面内在坐标 $t$（卷曲方向）。左图旋转视角可以亲眼确认“卷”；右图是线性 PCA 前两个主成分平面上的投影——颜色大面积混杂，因为卷层被压到了一起。面板里“PCA 最近邻的平均 $|\Delta t|$”由当前数据现算：它远大于纸面上相邻点的 $|\Delta t|$，这就是“相距很远的点在投影中靠近”的定量版本。展开需要非线性（§2 起步）。

§2把同一个 PCA 目标搬进特征空间 核心

要解决的不是“再发明一种 PCA”，而是把普通 PCA 的同一个问题搬到非线性特征空间：仍想找一个单位方向，使样本投影后的平方坐标尽量大；困难只是特征向量 $\phi(x)$ 可能维度极高、甚至写不出来。

同一条目标，两个世界

第 16 讲的一维 PCA 是 $\max_{\lVert w\rVert_2=1}\sum_i(w^\top x_i)^2$。给定特征映射 $\phi:\mathcal X\to\mathcal H$（可以是很高维的 Hilbert space），保留中心化原则： $$\bar\phi=\frac1n\sum_i\phi(x_i),\qquad \tilde\phi_i=\phi(x_i)-\bar\phi,\qquad \max_{\lVert u\rVert_{\mathcal H}=1}\sum_{i=1}^n\langle u,\tilde\phi_i\rangle_{\mathcal H}^2.$$

把 $C_\phi=\frac1n\sum_i\tilde\phi_i\otimes\tilde\phi_i$ 看成特征空间里的协方差算子，这个最大化就是在找 $C_\phi$ 的最大特征方向——但我们不需要写出 $C_\phi$ 的矩阵，kernel trick 的目的正是绕开这个可能无限维的对象：只要求内积 $k(x,x')=\langle\phi(x),\phi(x')\rangle_{\mathcal H}$（线性、多项式 $(x^\top x'+c)^p$、RBF $\exp(-\lVert x-x'\rVert^2/2\sigma^2)$ 等）。

互动：同心环——线性方向重叠，加一个 $\lVert x\rVert^2$ 特征就分开

图的意思：原空间两个同心环在任何线性方向上的投影都重叠（左/中）；但“到中心的距离平方”$\lVert x\rVert^2$ 本身就是一个现成的非线性特征——两个环在这个坐标上完全分开（右）。kernel PCA 做的事，就是自动且隐式地使用一整族这样的非线性特征（$\phi$ 的所有坐标），而不必手工挑出 $\lVert x\rVert^2$。可分性数值（类间均值差 / 类内标准差）由当前随机环现算。

§3Representer 形式：方向换成 $n$ 个系数 核心

要找 $u\in\mathcal H$，但最终只解一个 $n\times n$ 矩阵的特征值问题。为什么只需要考虑训练样本张成的方向？把任意 $u$ 分解为 $u=u_\parallel+u_\perp$（$u_\parallel\in\operatorname{span}\{\tilde\phi_1,\ldots,\tilde\phi_n\}$，$u_\perp$ 与每个 $\tilde\phi_i$ 正交），则 $\langle u,\tilde\phi_i\rangle=\langle u_\parallel,\tilde\phi_i\rangle$——$u_\perp$ 不改变任何训练点的投影，却占用单位范数预算，所以最优方向可以取在训练特征的张成空间内。

中心化 Gram 矩阵 centered Gram matrix · first mentioned: §3

是什么：$K_c\in\mathbb R^{n\times n}$，$(K_c)_{ij}=\langle\tilde\phi_i,\tilde\phi_j\rangle_{\mathcal H}$——中心化训练特征的两两内积（§4 给出仅用 kernel 值的计算）。

白话：去掉均值之后的“谁和谁像”表格。

干嘛用：kernel PCA 的全部计算对象——特征分解就是对它做的。

怎么算：由 $K_c v_r=\lambda_r v_r$（$\lambda_1\ge\lambda_2\ge\cdots\ge0$）得到方向系数；第 $j$ 个训练点的投影坐标为 $\langle u,\tilde\phi_j\rangle=\sum_i\alpha_i\langle\tilde\phi_i,\tilde\phi_j\rangle=(K_c\alpha)_j$。

为什么重要 + 连接：$v_r$ 活在样本索引空间 $\mathbb R^n$、$u_r$ 才活在特征空间 $\mathcal H$，两者不要混成同一个向量；若写成协方差算子的特征方程 $C_\phi u=\gamma u$，则 $K_c\alpha=n\gamma\alpha$——$K_c$ 的特征值与“平均协方差”能量相差一个 $n$ 的约定，本讲直接对 $K_c$ 分解并沿用此约定。

归一化系数 normalization α_r = v_r/√λ_r · first mentioned: §3

是什么：特征空间方向 $u_r=\sum_i\alpha_{ir}\tilde\phi_i$ 要有单位范数，必须取 $\alpha_r=\dfrac{v_r}{\sqrt{\lambda_r}}$（$\lambda_r>0$）。

白话：特征向量 $v_r$ 是单位长的，但它组合出的 $u_r$ 不是——差一个 $\sqrt{\lambda_r}$ 的刻度。

干嘛用：保证坐标尺度正确，训练坐标才能写成 $z_r(x_i)=(K_c\alpha_r)_i=\sqrt{\lambda_r}\,v_{ir}$。

怎么算：四步验证 $\lVert u_r\rVert_{\mathcal H}^2=\alpha_r^\top K_c\alpha_r=\frac1{\lambda_r}v_r^\top(\lambda_rv_r)=v_r^\top v_r=1$（依次用：范数=Gram 二次型、代入 $\alpha_r$、特征方程、$v_r$ 单位化）。

为什么重要 + 连接：分母是 $\sqrt{\lambda_r}$ 不是 $\lambda_r$——只记住“分解 $K_c$”而忘了范数约束，坐标会被特征值额外缩放，可视化和新点投影全用错尺度（下方互动现场对账三种缩放）。

互动：三种缩放的对照——只有 $v/\sqrt\lambda$ 给出单位范数

数据：三点例（§5 会完整手算）$x=(-1,0,1)$、$k(x,x')=(xx'+1)^2$，其 $K_c$ 的最大特征对为 $\lambda_1=4$、$v_1=(1,0,-1)^\top/\sqrt2$。正确缩放给出 $\lVert u_1\rVert^2=\alpha^\top K_c\alpha=1$；另外两种缩放分别把它变成 $1/\lambda_1=0.25$ 与 $\lambda_1=4$——训练坐标 $z_1(x_i)$ 也随之整体缩放（面板数值现算）。$\lambda=0$ 的方向 $v/\sqrt\lambda$ 无法定义，实现中直接丢弃。

§4kernel centering：双中心化，不是减一个常数 核心

要计算 $\langle\phi(x_i)-\bar\phi,\phi(x_j)-\bar\phi\rangle$，但看不到 $\phi(x_i)$，只能查询 $K_{ij}=k(x_i,x_j)$——必须把“在特征空间减均值”完全改写成 $K$ 的运算。

中心矩阵 centering matrix H · first mentioned: §4

是什么：$H=I_n-\frac1n\mathbf 1\mathbf 1^\top$（$\mathbf 1$ 为全一向量），中心化 Gram 矩阵由 $K_c=HKH$ 给出。

白话：一台“每行每列都减掉自己均值”的机器，左乘管行、右乘管列。

干嘛用：在不接触 $\phi$ 的前提下实现特征空间中心化。

怎么算：元素级展开是四项：$(K_c)_{ij}=K_{ij}-\frac1n\sum_\ell K_{i\ell}-\frac1n\sum_\ell K_{\ell j}+\frac1{n^2}\sum_{\ell,m}K_{\ell m}$——原值、行均值、列均值、总体均值。

为什么重要 + 连接：这四项正好对应内积展开 $\langle\phi_i-\bar\phi,\phi_j-\bar\phi\rangle$ 的四项；结果满足 $K_c\mathbf 1=0$ 且 $\mathbf 1^\top K_c=0$（每行每列均值为零）。不能把每个元素减同一个常数——不同训练点与“平均训练点”的相似度通常不同。

互动：亲眼看 $K$ 变 $K_c$——行/列均值归零（数据可换、可随机）

检查什么：右下数值面板列出 $K$ 的行均值向量与总体均值，以及 $K_c$ 的行均值——应全部为 0.00（现算，含浮点残差量级 $10^{-16}$）。三点多项式模式下 $\sigma$ 滑杆无效（kernel 固定为 $(xx'+1)^2$）；RBF 模式与随机按钮把 6 个输入点重抽。热图用发散色标：蓝正、红负、零为白——中心化后红蓝必然按行列平衡。

§5worked example：三点的完整手算 核心

取一维训练点 $x_1=-1,\ x_2=0,\ x_3=1$，二次多项式 kernel $k(x,x')=(xx'+1)^2$。逐项计算得 $K=\begin{pmatrix}4&1&0\\1&1&1\\0&1&4\end{pmatrix}$（例：$k(x_1,x_1)=((-1)(-1)+1)^2=4$）。

互动：六步点亮整个推导（所有数值由页面内公式现算）

讲义对账：$n=3$ 时 $H=I_3-\frac13\mathbf 1\mathbf 1^\top$，双中心化得 $K_c=\begin{pmatrix}19/9&-2/9&-17/9\\-2/9&4/9&-2/9\\-17/9&-2/9&19/9\end{pmatrix}$（每行每列和为零）；非零特征值 $4$ 与 $2/3$（$\operatorname{tr}K_c=\frac{42}9=4+\frac23$ 自检）；$\lambda_1=4$ 的单位特征向量 $v_1=(1,0,-1)^\top/\sqrt2$，于是 $\alpha_1=v_1/\sqrt4=(1,0,-1)^\top/(2\sqrt2)$，且 $\alpha_1^\top K_c\alpha_1=1$。训练坐标 $z_1(x_i)=\sqrt{\lambda_1}\,v_{i1}=(\sqrt2,0,-\sqrt2)$。点“下一步”逐步核对每个数。

§6out-of-sample projection：把新点投进已学的方向 核心

训练阶段已经学到方向 $u_j$。给一个从未参与特征分解的新点 $x$，要算 $z_j(x)=\langle u_j,\phi(x)-\bar\phi\rangle_{\mathcal H}$——其中 $\bar\phi$ 始终是训练集均值：不能使用包含新点的新均值，否则每来一个样本，已经学好的坐标系都会改变。

样本外投影 out-of-sample projection · first mentioned: §6

是什么：把新点投到已学得的 kernel 主方向：$z_j(x)=\alpha_j^\top k_c(x)=\dfrac{v_j^\top k_c(x)}{\sqrt{\lambda_j}}$。

白话：老坐标系列一张“新访客登记表”——用训练时的均值口径给新点定坐标。

干嘛用：kernel PCA 训练完成后对任意新数据可用。

怎么算：先算中心化 kernel 向量（右侧卡片），再与 $\alpha_j$ 点积、除以 $\sqrt{\lambda_j}$。

为什么重要 + 连接：需要新点与所有训练点的 kernel 值，存储和计算都与 $n$ 有关——这解释了为什么 kernel PCA 训练后不能像普通 PCA 那样只保存一个固定的 $d\times k$ 投影矩阵。

中心化 kernel 向量 centered kernel vector k_c(x) · first mentioned: §6

是什么：$k_c(x)=k_X(x)-m_{\mathrm{row}}-\big(\frac1n\mathbf 1^\top k_X(x)\big)\mathbf 1+\bar k\,\mathbf 1$，其中 $k_X(x)_i=k(x_i,x)$、$m_{{\mathrm{row}},i}=\frac1n\sum_\ell K_{i\ell}$、$\bar k=\frac1{n^2}\sum_{\ell,m}K_{\ell m}$。

白话：四项登记——原始相似度、训练行均值、新点与全体训练点的平均相似度、训练总体均值。

干嘛用：新点版的“减均值”，与训练中心化同一口径。

怎么算：它就是 $\langle\tilde\phi_i,\phi(x)-\bar\phi\rangle$ 逐项展开——与 $K_c=HKH$ 的四项完全平行。

为什么重要 + 连接：每一项都必须用训练阶段保存的行均值与总体均值，不能对当前 batch 重新中心化；默认 $\lambda_j>0$，零特征值方向无法定义、应丢弃。

互动：滑动新点 $x_\star$，逐步算 $k_c(x_\star)$ 与 $z_1(x_\star)$（曲线现算）

讲义对账（$x_\star=2$）：$k_X=(1,1,9)^\top$；行均值 $(5/3,1,5/3)^\top$；总体均值 $13/9$；新向量均值 $11/3$；四项相减得 $k_c(x_\star)=(-26/9,-20/9,46/9)^\top$；$z_1=\alpha_1^\top k_c=\frac1{2\sqrt2}(-\frac{26}9-\frac{46}9)=-2\sqrt2\approx-2.828$。若省略中心化、或把 $\alpha_1$ 错写成 $v_1/\lambda_1$，坐标的数值和尺度都会变——面板里的每个数随滑杆现算，可与这行手算逐位核对。

§7为什么能表达非线性：RBF 的带宽两极 核心

在原空间中，弯曲结构可能没有一个好的线性方向；在特征空间中，合适的 $\phi$ 可以把原空间的非线性关系变成线性变化。kernel PCA 的完整流程是：选正定 kernel → 算 $K$ 并双中心化 → 分解 $K_c$ → 用 $\alpha_r=v_r/\sqrt{\lambda_r}$ 算坐标 → 可视化或接下游任务。它适用于样本量中等、kernel 先验可信的场景。

互动：$\sigma$ 的两个极端——谱形态现场翻转

读图：RBF kernel 可以在同心圆等问题上提供弯曲相似性，但带宽 $\sigma$ 过小会让每个点只像自己——$K\approx I$、谱几乎全为 1、任何方向都没有方差结构；过大又会让所有点几乎一样——$K\approx\mathbf 1\mathbf 1^\top$、只剩一个主导特征值。特征值由 Jacobi 旋转对当前 6 个点现算；$k(0,1)$ 的数值随 $\sigma$ 现算显示。两种极端都让 kernel PCA 失去分辨力——带宽要用验证目标选，这与第 9–10 讲的教训一致。

§8Autoencoder：用瓶颈学编码和解码 核心

换一条路线：不再借助特征空间，而是让神经网络自己学一个压缩—解压的流程，在中间设置 bottleneck，训练目标是让输出重建输入。

自编码器 autoencoder · first mentioned: §8

是什么：近似 identity function 但中间带瓶颈的网络： $$z=f_{\mathrm{enc}}(x;\theta_{\mathrm{enc}})\in\mathbb R^k,\qquad \hat x=f_{\mathrm{dec}}(z;\theta_{\mathrm{dec}})\in\mathbb R^d,\qquad k\ll d,$$ 目标 $\min\frac1n\sum_i\ell(x_i,\hat x_i)$；连续数据常用平方重构 $\ell=\lVert x_i-\hat x_i\rVert_2^2$。

白话：把一句话压缩成暗号再让同伴还原——暗号必须抓住要点。

干嘛用：无标签学表示、去噪、可视化。

怎么算：mini-batch SGD + backprop；一次更新 = encoder 前向 → decoder 前向 → loss → 反传 → 学习率 $\eta$ 更新。与 PCA 的特征分解不同，非线性情形通常没有闭式全局解。

为什么重要 + 连接：若输入是 $[0,1]$ 像素并把每像素当 Bernoulli 目标，有时用 binary cross-entropy——这改变了重建目标，不能与平方误差结论混用。

编码器 encoder / decoder · first mentioned: §8

是什么：编码器把 $x\in\mathbb R^d$ 映到 $z\in\mathbb R^k$；解码器把 $z$ 映回 $\hat x\in\mathbb R^d$。两者串联构成自编码器。

白话：一个打包、一个拆包；拆装之后还能认出原物，说明包装抓住了本质。

干嘛用：$z$ 就是学到的低维表示。

怎么算：可以任意非线性（多层 + 激活）；线性特例在 §9 精确求解。

为什么重要 + 连接：即使重建映射固定，编码/解码的因子分解也不唯一——任意可逆 $R\in\mathbb R^{k\times k}$ 都满足 $(BA)=(BR^{-1})(RA)$，latent 坐标随之改变。

瓶颈 bottleneck · first mentioned: §8

是什么：维度远低于输入的中间层（$k\ll d$），对可传递信息施加硬约束。

白话：独木桥——想过桥就得扔掉行李里不重要的东西。

干嘛用：制造压缩压力，逼网络保留数据中“最值钱”的变化方向。

怎么算：$k$ 是超参数：过小丢信息，过大压缩压力弱、甚至记忆训练样本。

为什么重要 + 连接：线性情形下它把重建问题限制为“保留哪 $k$ 个正交变化方向”——§9 将证明最优选择恰好是 PCA 的前 $k$ 维。

互动：瓶颈结构 + 重构误差随 $k$ 的阶梯（数据可随机）

图的意思：左侧是 $d\to k\to d$ 的瓶颈示意（encoder/decoder 标注）；右侧对一组各向异性的二维数据画“重构误差 vs $k$”阶梯——线性自编码器的误差正是 $\sum_{j>k}\sigma_j^2$（保留前 $k$ 个奇异方向），数据由当前随机种子现算。二维里 $k=1$ 通常已把误差压到第二方差那么小；$k=2$ 恒为零（无损）。

§9线性 autoencoder 学到的正是 PCA 子空间 核心

要证明的不是“网络参数等于 PCA 特征向量”，而是一个更精确的结论：在特定条件下，线性 autoencoder 最终重建数据所用的 $k$ 维子空间，与 PCA 的前 $k$ 维主子空间相同；encoder、decoder 的具体参数与 latent 坐标仍可能不同。

先来一个零误差的手算例

取第 16 讲的四个点 $x_i\in\mathbb R^2$，都在方向 $w=\frac1{\sqrt2}(1,1)^\top$ 的直线上。一维线性 encoder/decoder： $$z=w^\top x,\qquad \hat x=wz=ww^\top x.$$ 对 $x=(2,2)^\top$：$z=\frac4{\sqrt2}=2\sqrt2$，$\hat x=2\sqrt2\cdot\frac1{\sqrt2}(1,1)^\top=(2,2)^\top$——零重构误差。瓶颈维度为 1 却保留了全部数据，因为数据本来就在一维线性子空间上。

低秩重建 rank-k reconstruction · first mentioned: §9

是什么：线性 encoder/decoder 记为 $z=Ax,\ \hat x=BAx$（$A\in\mathbb R^{k\times d}$、$B\in\mathbb R^{d\times k}$），整体重建矩阵 $M=BA$ 满足 $\operatorname{rank}(M)\le k$。对中心化数据 $X_c$： $$\min_{A,B}\sum_i\lVert x_i-BAx_i\rVert^2=\min_{M:\operatorname{rank}M\le k}\lVert X_c-MX_c\rVert_F^2,$$ 由截断 SVD 的最佳低秩近似，最优 $M^\star=U_kU_k^\top$，误差 $=\sum_{j>k}\sigma_j^2$。

白话：线性网络能做的所有事，就是“挑 $k$ 个正交方向保留、其余归零”——最优挑法正是方差最大的那 $k$ 个。

干嘛用：把“线性 AE 等价于 PCA”从口号变成可检验的命题。

怎么算：选别的 $k$ 维子空间会把至少一部分更大的奇异值能量丢掉，误差不可能更小。

为什么重要 + 连接：等价的三个前提——中心化数据（或带合适 bias）、线性激活、平方重构损失；“等价”的对象是最优重建子空间而非唯一坐标：$A,B$ 分解不唯一（$(BR^{-1})(RA)$），若 $\lambda_k=\lambda_{k+1}$ 连最优子空间本身也不唯一。

互动：拖动 $k$，看点云被投影到前 $k$ 个主方向（误差对账现算）

对账逻辑：实心点是中心化数据，空心点是 $M=U_kU_k^\top$ 的重建，连线即被丢掉的分量。面板同时显示 $\lVert X_c-U_kU_k^\top X_c\rVert_F^2$ 与 $\sum_{j>k}\sigma_j^2$（由当前数据的 2×2 协方差特征分解现算）——两数逐位一致。$k=0$ 全部塌到原点；$k=2$ 无损。若输入未中心化，须把均值加回解码结果，否则零均值结论不能直接套用。

§10非线性 autoencoder：新能力与新代价 核心

若 encoder、decoder 含非线性激活，多层网络可以学习弯曲的编码—解码映射，例如把 Swiss roll 的三维坐标映射到纸面的二维坐标、再从二维坐标重建卷曲形状。

能力

表示灵活（能贴合弯曲流形）；可处理图像等大数据；可用 mini-batch 训练，扩展性远好于 $O(n^2)$ 的 kernel 方法。

代价

非凸优化、初始化与学习率敏感、超参数多、可解释性弱；网络够强时可能记忆训练样本而不是学到稳定结构。

去噪自编码器 denoising autoencoder · first mentioned: §10

是什么：给输入加噪声、要求从带噪版本重建干净输入的训练变体；与 sparse、contractive、weight-decay 一样，都是在规定“什么样的表示才算好”。

白话：故意把字迹弄糊再让它认——逼它学会字的骨架而不是墨点。

干嘛用：防止记忆训练集、学到更稳健的特征。

怎么算：$\min\frac1n\sum_i\lVert x_i-f_{\mathrm{dec}}(f_{\mathrm{enc}}(\tilde x_i))\rVert^2$，$\tilde x_i$ 为加噪版本。

为什么重要 + 连接：“能重建 Swiss roll”不等于“latent 坐标就是纸面真值”——任何对 latent 的可逆重参数化（甚至局部折叠）都可能保持相近误差；只有额外约束才规定了我们希望表示具有的性质。

评估陷阱（目标 × 指标 × 注意事项）

目标可观察指标需要注意
压缩验证集重建误差、码率低误差不等于可解释
邻域探索邻域保持、稳定性局部指标可能扭曲全局距离
下游分类独立验证集性能不能把无标签重构误差当监督最优
去噪干净数据上的重建训练/测试噪声分布要一致

两条路线的成本对照：kernel PCA 的新点嵌入依赖与所有训练点的 kernel 值、受 $n^2$ 内存限制，但特征分解直接；autoencoder 对新点只需一次 encoder 前向、可 mini-batch，但要操心优化与模型选择。非线性 autoencoder 的二维散点图应解释为“对重建目标有用的坐标”，而不是未经验证的流形真值。

§11限制与谱聚类的边界 拓展

kernel PCA 的账本与邻居：它跟哪些“听起来一样”的方法其实不是一回事。

pre-image 问题 pre-image problem · first mentioned: §11

是什么：特征空间中的低维点没有简单的原空间逆映射，寻找原空间代表点称为 pre-image problem。

白话：能把数据投影到好坐标，却画不出“这个坐标对应哪张原图”。

干嘛用：去噪、生成时需要回到输入空间。

怎么算：无闭式解，常用近似迭代或优化。

为什么重要 + 连接：与 $O(n^2)$ 存储、逐训练点求 kernel 一起构成 kernel PCA 的三大实用限制。

谱聚类 spectral clustering · first mentioned: §11

是什么：先构造相似度图，对（归一化或未归一化）图 Laplacian 取特征向量，通常对行归一化后的谱嵌入跑 $k$-means。

白话：把“谁和谁连边”变成图，再沿图的特征向量切团伙。

干嘛用：非凸形状的簇（如同心环）。

怎么算：图 → Laplacian → 特征向量 → 行归一化 → $k$-means。

为什么重要 + 连接：与 “kernel PCA + $k$-means”“kernel $k$-means” 有共同的“相似度 → 谱表示 → 分组”直觉但不是同一个算法——矩阵、归一化与目标都不同（下方三卡对照）。

kernel PCA + $k$-means

先对中心化 Gram matrix 做 kernel PCA，再在保留的 kernel-PC 坐标上跑普通欧氏 $k$-means；结果依赖保留了多少个主成分。

kernel $k$-means

直接把 $k$-means 的距离目标写成 kernel 内积、按 kernel 距离更新分组——不等价于任意截断 kernel-PCA 坐标上的 $k$-means。

spectral clustering

矩阵是图 Laplacian 而非 Gram matrix，归一化与优化目标都不同；报告结果应写清用了哪个矩阵、保留多少维、最后的分组步骤，不能只称“kernel 聚类”。

更大的家族：LLE、MDS、t-SNE、UMAP 等其他非线性嵌入方法保留的结构不同——有的强调局部邻域，有的强调距离或拓扑；不能把所有二维图都解释成“保留了原空间的全部几何”。

§12一个完整的工作流 拓展

假设有 $10000$ 张无标签、每张展平为 $x_i\in\mathbb R^{4096}$ 的细胞显微图像。一个可审计的流程是：

  1. 根据图像强度和批次效应决定中心化、标准化或归一化；
  2. 用 PCA 检查主要线性变化，并视计算资源把表示压到中等维度；
  3. 比较二维 PCA 与非线性 embedding，记录 kernel 参数或网络随机种子；
  4. 若用 autoencoder，划分训练/验证样本、监控验证重建误差，避免只看训练误差；
  5. 对低维编码做聚类，检查簇内代表图像而非只看散点颜色；
  6. 用邻域保持、重建、稳定性和领域知识共同解释结果。

这条流程把第 15、16、18 讲连接起来：$k$-means 选离散原型，PCA 选线性子空间，kernel PCA / autoencoder 选非线性表示。没有标签时，必须明确自己希望保留的是重构细节、局部邻域、全局距离还是下游任务信息。

§13常见误区 核心

每一条都先给出“听起来对”的说法，再给真相。

❌

误区 1：kernel PCA 一定比 PCA 好。

✓ 真相：kernel 和超参数选错时可能更差，且计算更贵（§7 的两个极端）。

❌

误区 2：中心化只要把 $K$ 的每个元素减去一个常数。

✓ 真相：正确操作是 $K_c=HKH$，同时处理行均值、列均值和总体均值（§4）。

❌

误区 3：kernel PCA 的系数是 $v_r/\lambda_r$。

✓ 真相：单位特征空间方向需要 $\alpha_r=v_r/\sqrt{\lambda_r}$（§3 的三缩放对照）。

❌

误区 4：新点直接用 $k(x_i,x)$ 投影即可。

✓ 真相：必须使用与训练均值一致的中心化 kernel 向量（§6 的四项公式）。

❌

误区 5：autoencoder 重建好就代表学到语义。

✓ 真相：重建目标可能鼓励低层细节或训练集记忆（§10 的评估表）。

❌

误区 6：线性 autoencoder 比 PCA 更有表达力。

✓ 真相：对中心化数据（或含适当 bias）、相同瓶颈、线性激活和平方损失，最优重建子空间就是 PCA 子空间；灵活性来自非线性和架构（§9）。

❌

误区 7：二维非线性图上的所有距离都可信。

✓ 真相：很多方法优先保留局部邻域，全局距离可能失真（§11 的 t-SNE/UMAP 家族）。

❌

误区 8：无标签 autoencoder 是普通监督学习。

✓ 真相：输入自身作为目标，更准确地说是非监督 / 自监督式重建（§8）。

§14收束：第 18 讲真正要带走的东西 核心

PCA 失败是因为函数类太简单；两条路线分别在隐式特征空间和神经网络里找回弯曲结构。

两条路线的收束链

上排：kernel PCA 五步；下排：autoencoder 三步——线性时回到 PCA 子空间，非线性时展开弯曲流形。左端是第 16 讲，右端是第 19 讲。

核心问题 → 答案回顾

弯曲数据为什么让 PCA 失败？线性映射只能产生平面坐标，卷层被压到一起。看不到 $\phi$ 怎么做 PCA？方向限制在训练特征张成空间内（$u=\sum\alpha_i\tilde\phi_i$），一切内积换成 kernel 值，最终只解 $K_c=HKH$ 的特征分解；坐标 $z_r(x_i)=\sqrt{\lambda_r}v_{ir}$（系数除以 $\sqrt{\lambda_r}$）；新点用训练均值做四项中心化后投影 $z_r(x)=v_r^\top k_c(x)/\sqrt{\lambda_r}$。autoencoder 学到什么？线性 + 中心化 + 平方损失时：最优重建子空间 = PCA 前 $k$ 维（误差 $\sum_{j>k}\sigma_j^2$）；非线性时能展开弯曲流形，但 latent 坐标不是自动的流形真值，需要额外约束与谨慎评估。

最重要的五个公式

$$K_c=HKH,\qquad H=I_n-\tfrac1n\mathbf 1\mathbf 1^\top \quad\text{（双中心化：行、列、总体三均值一次到位）}$$ $$K_cv_r=\lambda_r v_r\ \Longrightarrow\ u_r=\textstyle\sum_i\alpha_{ir}\tilde\phi_i,\quad \alpha_r=\frac{v_r}{\sqrt{\lambda_r}} \quad\text{（系数归一化）}$$ $$z_r(x_i)=\sqrt{\lambda_r}\,v_{ir} \quad\text{（训练坐标）}$$ $$k_c(x)=k_X(x)-m_{\mathrm{row}}-\big(\tfrac1n\mathbf 1^\top k_X(x)\big)\mathbf 1+\bar k\,\mathbf 1,\qquad z_r(x)=\frac{v_r^\top k_c(x)}{\sqrt{\lambda_r}} \quad\text{（样本外投影）}$$ $$\min_{\operatorname{rank}M\le k}\lVert X_c-MX_c\rVert_F^2=\sum_{j>k}\sigma_j^2 \quad\text{（线性 AE = PCA 子空间）}$$
