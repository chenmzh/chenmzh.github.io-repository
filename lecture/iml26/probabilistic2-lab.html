第 19 讲学会了给数据建分布 $p(x)$ 并做最大似然。这一讲把概率视角接到分类上：面对一张手写数字图，你可以问“给定这张图，它是 7 的概率多少”（学 $P(Y\mid X)$），也可以问“先抽中 7，再长出这样一张图的概率多少”（学 $P(Y)$ 与 $P(X\mid Y)$）。两条路线都能分类，但表达的结构假设、能顺手做到的事、难在哪里，全都不一样。

💬 本讲核心问题：对分类，到底在学 $P(Y\mid X)$ 还是整个 $P(X,Y)$？logistic 回归为什么恰好是“对条件模型做 MLE”？生成式模型多花了建模 $P(X\mid Y)$ 的力气，换来了什么？学到分布之后，“最优预测”又由什么决定？
一句话答案：两个恒等式 $p(x,y)=p(x)p(y\mid x)=p(y)p(x\mid y)$ 都正确，差别在你愿意为哪一半写简单模型。判别式（logistic）只解释标签概率，其负对数似然恰好就是 logistic loss；生成式（Gaussian Naive Bayes）为每类建一团高斯云再用 Bayes 公式反推后验，顺带获得采样与异常检测能力，代价是必须解释输入分布。预测端殊途同归：给定损失，逐点最小化条件期望损失——平方损失给条件均值，0-1 损失给后验最大的类。

📌 今天讲什么

两种问法 → 条件模型与 logistic（sigmoid 手算）→ logistic MLE = logistic loss（margin 推导）→ 联合分解与“似然可分” → 生成式路线与 Bayes 公式 → GNB 建模故事与二维例子 → GNB 的 MLE 与一维手算（后验 0.9999）→ 边界形状三级跳（线性/受限二次/QDA）→ Bayes 最优预测（平方与 0-1）→ 数值稳定与综合工作台。

🔥 为什么重要

“判别还是生成”是概率建模里最持久的一条路线分岔：它决定你为什么能用 logistic loss（它是 MLE 不是拍脑袋）、为什么朴素贝叶斯敢用“特征给定类别后独立”这种强假设、以及什么时候值得为 $P(X\mid Y)$ 付出建模代价。Bayes 最优预测则把“学分布”与“做决策”干净地分开——第 21 讲的非对称损失直接沿用本讲的后验。

§0课程地图：两条路线汇到同一个决策

第 19 讲把“函数视角”换成“分布视角”；本讲让两条建模路线（判别/生成）都通向 $P(Y\mid X)$，再交给损失去决定动作；第 21 讲继续用这些后验处理更精细的决策问题。节点可点击。

概念地图：核心环节构成主线（判别支线上排、生成支线中排、决策收束）；拓展环节是数值技巧与综合工作台。灰色节点是前后讲次。

§1一张图片，两种问法 核心

看一张手写数字图片 $x$，要判断它是 $0,1,\ldots,9$ 中的哪个。第一种想法：给我这张图 $x$，它是数字 $y$ 的概率是多少？也就是 $P(Y\mid X=x)$。第二种想法：先选一个数字 $y$，再想这个数字通常会长成什么样的图 $x$，也就是 $P(Y)$ 和 $P(X\mid Y)$。两种方式都能得到分类概率，但它们讲的是不同的故事。

判别式模型 discriminative model · first mentioned: §1

是什么：直接建模条件分布 $p(y\mid x;\theta)$ 的模型族；联合由 $p(x,y)=p(x)\,p(y\mid x)$ 拼出。

白话：只学“看到考题后怎么打分”，不学考题本身怎么出。

干嘛用：预测标签；0-1 损失下 $\hat y(x)=\arg\max_y \hat p(y\mid x)$。

怎么算：对条件似然 $\prod_i p(y_i\mid x_i;\theta)$ 做 MLE（§2–§3 的 logistic 就是实例）。

为什么重要 + 连接：它不解释 $x$ 的密度——只关心分类时这是优势（少一件事可错）；概率分类器还比硬分类器多出不确定性信息（$\hat p=0.9$ 与 $\hat p=0.51$ 都预测 $+1$，但可信度完全不同）。

生成式模型 generative model · first mentioned: §1

是什么：建模 $p(y;\pi)$ 与 $p(x\mid y;\eta_y)$，从而得到联合 $p(x,y)=p(y)\,p(x\mid y)$；分类时用 Bayes 公式反推 $p(y\mid x)$。

白话：先讲“标签怎么抽、每个标签长什么样”，再倒过来回答“这张图最像谁生的”。

干嘛用：分类之外还能采样、异常检测、缺失值推断、解释类别形状。

怎么算：分别对先验和“每类自己的输入分布”做 MLE（§6–§7 的 GNB 全流程）。

为什么重要 + 连接：“生成”不是预测时随机掷标签，而是训练时建立了 $x$ 的生成故事；代价是必须解释 $P(X\mid Y)$——高维（如自然图像）时很难，错了会拖累分类（§12 误区）。

叙事决定分解：食物成分 $x\to$ 是否健康 $y$、血样 $x\to$ 能否驾驶 $y$，读起来“$x$ 先出现、$y$ 是后果”，适合 $p(x)p(y\mid x)$；手写数字“先决定 $y=7$、再写出一张带倾斜粗细的 7”、疾病诊断“先有病 $y$、再表现症状 $x$”，适合 $p(y)p(x\mid y)$。数学上两条恒等式都成立——选择哪种分解，就是选择哪种结构假设（§12 误区 2）。

§2logistic 条件模型：从分数到概率 核心

二分类里，标签 $y\in\{-1,+1\}$、特征 $x\in\mathbb R^d$、参数 $w\in\mathbb R^d$。为保持推导简洁，本讲先固定截距 $b=0$（一般形式为 $p(y\mid x;w,b)=\big(1+\exp\{-y(w^\top x+b)\}\big)^{-1}$，边界相应为 $w^\top x+b=0$）。

logistic 模型 logistic model · first mentioned: §2

是什么：$p(y\mid x;w)=\dfrac{1}{1+\exp(-y\langle w,x\rangle)}$——把线性分数 $\langle w,x\rangle$ 经 sigmoid 压成合法概率。

白话：一根数轴上的“信心旋钮”：分数越大越笃定 $+1$，越负越笃定 $-1$，零则五五开。

干嘛用：给每个输入输出带不确定性的类别概率。

怎么算：算 $\langle w,x\rangle$ 再代入 sigmoid。$\langle w,x\rangle$ 很大 → $p(y{=}{+}1\mid x)$ 接近 1；很负 → 接近 0；等于 0 → 恰为 $\tfrac12$。

为什么重要 + 连接：它给的不只是边界 $\langle w,x\rangle=0$（本讲 $b=0$ 特例下是一条直线/超平面），还有边界两侧的概率变化；§3 将证明对它做 MLE 恰好得到 logistic loss。

互动：拖动 $w$ 与 $x$，读出概率（曲线现算）

讲义手算对账（$w=2$）：$x=1$ 时 $\langle w,x\rangle=2$，$p(y{=}{+}1\mid x)=\frac1{1+e^{-2}}\approx0.881$；$x=-1$ 时 $\langle w,x\rangle=-2$，$p\approx0.119$；$x=0$ 时 $p=0.5$。把滑杆设为 $(w{=}2,x{=}1)$ 等组合即可逐位核对（面板数值现算）。

§3logistic MLE：logistic loss 的出身 核心

要求解的量是 $\hat w\in\mathbb R^d$：给定带标签数据后，哪个权重让观测标签的条件概率最大？把输入当作给定条件、只建模标签且各标签在给定输入下互相独立，条件似然是 $\prod_i p(y_i\mid x_i;w)$。

四行推导（margin 记 $m_i=y_i\langle w,x_i\rangle$）

$$\hat w=\arg\max_w\sum_i\log\Big(\frac{1}{1+\exp(-y_i\langle w,x_i\rangle)}\Big)=\arg\min_w\sum_i-\log\Big(\frac{1}{1+e^{-m_i}}\Big)=\arg\min_w\sum_i\log\big(1+e^{-m_i}\big).$$

第三步只用 $-\log(1/a)=\log a$。所以 logistic regression = 对 logistic 条件分布做最大似然估计。每个样本在惩罚什么：margin 很大（标签方向与模型分数一致）损失趋零；margin 为负（推错一侧）损失随 $|m|$ 迅速增大（下方曲线现算）。与生成模型比较时记住：logistic 只需解释标签概率，不必同时解释 $x$ 在输入空间的分布。

logistic 损失 logistic loss · first mentioned: §3

是什么：$\ell(m)=\log(1+e^{-m})$，$m=y\langle w,x\rangle$ 为 margin；它是 logistic 条件模型的负对数似然。

白话：对“分数方向与标签是否一致、差多远”的软惩罚。

干嘛用：logistic regression 的训练目标。

怎么算：$m=2\Rightarrow\ell=0.127$；$m=-1\Rightarrow\ell=1.313$；$m\to+\infty\Rightarrow0$，$m\to-\infty$ 线性爆炸。

为什么重要 + 连接：第 8 讲讲过 soft-margin SVM 消元后精确得到 hinge loss——本讲给出 logistic 版的对应物；两者都是“把某个概率/几何假设推到底”的结果，而非拍脑袋的规定。

互动：滑动 margin 看单点损失；四个样本的总损失现算（可随机）

§4拼出联合分布：MLE 为什么可以分开算 核心

条件模型能比较同一个 $x$ 下的标签，但没说这个 $x$ 本身常不常见。由 $p(x,y)=p(y\mid x)\,p(x)$：已有 $p(y\mid x;\theta_y)$，再给输入建边缘模型 $p(x;\theta_x)$，就得到“由判别式拼出来的”联合 $p(x,y;\theta_x,\theta_y)$——$\theta_x$ 管输入分布、$\theta_y$ 管分类规则。

似然可分 likelihood separation · first mentioned: §4

是什么：若 $p(x,y;\theta_x,\theta_y)=p(x;\theta_x)\,p(y\mid x;\theta_y)$ 且参数空间是乘积 $\Theta_x\times\Theta_y$，则联合 log-likelihood 恰好拆成 $\ell(\theta_x,\theta_y)=A(\theta_x)+B(\theta_y)$，其中 $A=\sum_i\log p(x_i;\theta_x)$、$B=\sum_i\log p(y_i\mid x_i;\theta_y)$。

白话：两口子各管各的账，各自把自家账 max 掉，总和自然最大。

干嘛用：证明拟合输入模型不会改变条件分类器的 MLE，反之亦然。

怎么算：$\hat\theta_x=\arg\max A(\theta_x)$、$\hat\theta_y=\arg\max B(\theta_y)$ 分开解（下方互动用两个一维二次目标演示）。

为什么重要 + 连接：原因不是“它们没关系”这种模糊说法，而是目标具有可加形式且参数不耦合；条件是两部分不共享参数、无耦合正则——否则不能拆。这也解释了为什么只关心分类时可以完全不拟合 $p(x)$。

互动：两个旋钮各转各的——$A(\theta_x)+B(\theta_y)$ 的最大值在各自最优处同时取到

演示设定：$A(\theta_x)=\sum_i(u_i-\theta_x)^2$（4 个“输入样本” $u$ 的平方误差，最优在均值 $\bar u$）、$B(\theta_y)=\sum_i(v_i-\theta_y)^2$（4 个“标签侧量” $v$，最优在 $\bar v$）。三个条形分别显示 $A$、$B$ 与总和——无论先转哪个旋钮，另一项纹丝不动；联合最优 = 两个各自最优（数值现算）。若把两参数用一个共享参数 $\theta$ 绑住（“耦合”开关的反例），可加性立刻失效——这正是“共享参数不能拆”的几何。

§5生成式路线：先抽 $y$，再长出 $x$ 核心

换的不是概率定理，而是要参数化的部分：直接为类别先验与类条件输入分布建模，再用 Bayes 公式反推分类所需的后验。联合分布写成 $p(x,y)=p(y)\,p(x\mid y)$——先决定 $y=7$，再生成一张带倾斜、粗细、风格变化的 7。

类别先验 class prior · first mentioned: §5

是什么：$p(y)$——抽到每个类别的概率；二分类即 $\pi$ 与 $1-\pi$。

白话：开考之前各类别的基础出场率。

干嘛用：与类条件密度相乘给出未归一化后验分数。

怎么算：MLE 就是频率 $\hat\pi_y=\operatorname{Count}(Y=y)/n$。

为什么重要 + 连接：分类比较分子即可；但报告“患病概率”或算风险必须完成归一化。先验改变会让后验 0.5 的边界移动（下方互动）——罕见病之所以要小心，就是先验在拉扯。

类条件密度 class-conditional density · first mentioned: §5

是什么：$p(x\mid y)$——给定类别后输入的分布，例如“数字 7 的图片长什么样”。

白话：每个类别自己的画像师。

干嘛用：生成故事的核心；与先验相乘构成联合。

怎么算：GNB 用对角协方差高斯（§6）；预测时算 $s_y(x)=\pi_y\,\mathcal N(x;\mu_y,\Sigma_y)$ 再归一化 $s_y/\sum_c s_c$。

为什么重要 + 连接：它是生成式的额外账单——高维时很难建对，错了会拖累分类（§12 误区 1）。

Bayes 规则 Bayes rule · first mentioned: §5

是什么：$p(y\mid x)=\dfrac{p(y)\,p(x\mid y)}{p(x)}$，其中 $p(x)=\sum_c p(c)\,p(x\mid c)$ 是总证据。

白话：把“先有类再成像”的故事倒放成“见到像猜类”。

干嘛用：从生成模型取回分类所需的后验。

怎么算：离散类别时分子逐类相乘、分母求和归一。

为什么重要 + 连接：三块各有职责——先验与类条件给出未归一化分数，分母把它们变成和为 1 的后验；第 9 讲的 posterior 语言在这里落地成算法。

互动：只动先验 $\pi$，看后验 0.5 的边界怎么移动

图的意思：两类一维高斯（$\mu_-=-1,\sigma_-=0.7$；$\mu_+=2,\sigma_+=1$）固定不动，只滑动 $\pi$。加权密度 $\pi_y\mathcal N$ 的交点、以及后验曲线 $p(y{=}{+}1\mid x)$ 过 0.5 的位置，都随先验移动（边界坐标由网格+线性插值现算）。$\pi\to1$ 时负类几乎不可能、边界冲向左端——这就是“先验也能改变决策”的直接可视化。

§6Gaussian Naive Bayes：每个类别一团云 核心

GNB 是一个生成式分类模型，假设 $Y\sim\operatorname{Categorical}(\pi)$、$X\mid Y=y\sim\mathcal N(\mu_y,\Sigma_y)$ 且 $\Sigma_y$ 为对角矩阵。

Gaussian Naive Bayes Gaussian Naive Bayes · first mentioned: §6

是什么：先验 $\pi_y$ + 每类对角协方差高斯的生成式分类器；预测比较 $s_y(x)=\pi_y\mathcal N(x;\mu_y,\Sigma_y)$ 再归一化。

白话：每类画一团轴对齐的椭圆云，看新点更像掉进哪团云、再乘上类别出场率。

干嘛用：快速生成式基线；文本/表格数据上常用变体。

怎么算：对角协方差让密度分解为 $\prod_j\mathcal N(x_j;\mu_{yj},\sigma_{yj}^2)$；MLE 见 §7。

为什么重要 + 连接：参数量从每类约 $\tfrac{d(d+1)}2$ 个协方差参数降到 $d$ 个方差——省，但特征高度相关时密度会错（下方条件独立卡片与 §8 的边界层级）。

条件独立 conditional independence (naive assumption) · first mentioned: §6

是什么：给定类别后各特征彼此独立：$p(x\mid y)=\prod_j p(x_j\mid y)$，对应 $\Sigma_y$ 对角。

白话：“知道是 7 之后，笔画倾斜度和粗细互不影响”——一个大胆但常够用的假设。

干嘛用：把联合密度拆成一维密度的乘积。

怎么算：它删掉的是 $x_jx_k$ 相关项，没有删掉每个特征自身的均值方差。

为什么重要 + 连接：注意 naive ≠ “特征独立于标签”，也 ≠ “所有类共享协方差”——这两个混淆分别对应 §12 误区与 §8 的层级表。

互动：二维 GNB——拖动测试食物，读两类分数与后验（讲义参数）

讲义参数：$X\mid Y{=}{+}1\sim\mathcal N([2,1],\operatorname{diag}[1,1])$（健康），$X\mid Y{=}{-}1\sim\mathcal N([5,4],\operatorname{diag}[1,2])$（不健康），先验各 0.5。默认测试点 $[4,3]$：健康类马氏距离平方 $=4$、不健康类 $=0.75$——离负类云更近，后验 $\hat P(+1\mid x)\approx0.052$（面板现算）。预测比较的是 $\pi_y\mathcal N$ 加权分数，不只是“离均值近”；虚线椭圆是各类 1σ/2σ 等密度线（对角协方差 → 轴对齐）。

§7GNB 的 MLE 与一维手算 核心

先验 $\hat\pi_y=\operatorname{Count}(Y=y)/n$；每个类别单独拟合一团高斯：$\hat\mu_y=\frac1{n_y}\sum_{i:y_i=y}x_i$，$\hat\Sigma_y=\frac1{n_y}\sum_{i:y_i=y}(x_i-\hat\mu_y)(x_i-\hat\mu_y)^\top$，GNB 再把非对角元清零（等价于逐坐标一维方差 MLE）。

为什么除以 $n_y$ 而不是 $n_y-1$：这里在最大化给定参数族下的似然，Gaussian MLE 的二阶矩用有效样本数 $n_y$；$n_y-1$ 是无偏样本协方差的频率学修正，不是 MLE。若某类样本很少，方差估计不稳，实用中常用平滑或方差下限避免极端自信。

互动：四点数据 → 参数 → $x_\star=4$ 的完整后验（数值全部现算，可随机）

讲义对账（默认数据 $1,2\to-1$；$5,7\to+1$）：$\hat\pi_\pm=0.5$；$\hat\mu_-=1.5,\hat\mu_+=6$；$\hat\sigma_-^2=0.25,\hat\sigma_+^2=1$。对新点 $x_\star=4$：$\mathcal N(4;1.5,0.25)=2.9734\times10^{-6}$（离负类均值 5 个标准差），$s_-=1.4867\times10^{-6}$；$\mathcal N(4;6,1)=0.053991$，$s_+=0.0269955$；归一化 $\hat P(+1\mid x=4)\approx0.999945$、$\hat P(-1\mid x)\approx0.000055$——0-1 损失下预测 $+1$ 且相当自信。诊断点：负类方差那么小只是两个样本碰巧接近；若它来自抽样噪声，这个 0.9999 就是过度自信。

§8决策边界：直线还是曲线？ 核心

要求输入空间里哪些 $x$ 让两类同样可信。为避免连乘下溢、也为了看清形状，先取每一类的 log 分数：$g_y(x)=\log\pi_y-\tfrac12\log|\Sigma_y|-\tfrac12(x-\mu_y)^\top\Sigma_y^{-1}(x-\mu_y)+\text{常数}$；边界即 $g_{+1}(x)=g_{-1}(x)$。

log-score log-score · first mentioned: §8

是什么：$g_y(x)=\log\big(\pi_y\mathcal N(x;\mu_y,\Sigma_y)\big)$——去掉各类公共常数后的对数未归一化后验。

白话：把连乘变成连加的“对数账本”，比谁大不用算分母。

干嘛用：比较类别、推导边界形状。

怎么算：还原后验要用 $p(y\mid x)=\exp\big(g_y-\operatorname*{logsumexp}_c g_c\big)$，不能把 $g_y$ 本身当概率（§11 的数值版）。

为什么重要 + 连接：log-score 适合比较与推导，归一化后验才适合解释概率或代入风险——两种用途别混。

决策边界 decision boundary · first mentioned: §8

是什么：两个动作条件风险相等的输入集合；概率分类里即两类后验相等处 $p(y{=}{+}1\mid x)=p(y{=}{-}1\mid x)$。

白话：模型拿主意时的分水岭。

干嘛用：可视化分类器的几何。

怎么算：共享协方差时比较两类 $g_y$，二次项 $x^\top\Sigma^{-1}x$ 相消 → 线性（LDA 风格）；各类自己的对角 $\Sigma_y$ → 留下 $x_1^2,\ldots,x_d^2$ 轴对齐二次项（GNB 的受限二次边界）；完整各类协方差 → 还有 $x_jx_k$ 交叉项（一般 QDA）。logistic 的边界 $\langle w,x\rangle=0$ 恒为线性。

为什么重要 + 连接：边界形状不是背诵题，而是“两类 log-density 相减后哪些 $x$ 项留下”的推论——这个判据也适用于多类（任意两类分界面由两个 score 相等给出）。

互动：切协方差层级，看边界从直线弯成二次曲线（热图与边界现算）

三级层级（讲义表格）：共享对角 $\Sigma$ → 受限线性（共享协方差 LDA 的特例）；类别特异对角 → GNB 的轴对齐二次边界；类别特异完整矩阵 → 一般 QDA（含交叉项）。所以 “Naive” 限制的是每类协方差的非对角元，不等于“所有类共享同一协方差”；Gaussian Bayes 分类器与 LDA/QDA 有亲缘，但 GNB ≠ 完整 QDA。热图颜色 = 当前模型下 $p(y{=}{+}1\mid x)$（$40\times26$ 网格现算），白线 = 后验 0.5 边界（逐行线性插值）。

§9Bayes 最优预测：从分布到动作 核心

若知道真实分布 $P$，对任意损失 $\ell(a,y)$，最优预测是 $f^*(x)=\arg\min_a\mathbb E[\ell(a,Y)\mid X=x]$。最优动作只依赖条件分布 $P(Y\mid X=x)$——即使你通过生成模型学的是 $P(X,Y)$，预测时也终将转成 $P(Y\mid X)$。

平方损失 → 条件均值

$\mathbb E[(a-Y)^2\mid x]=a^2-2a\,\mathbb E[Y\mid x]+\mathbb E[Y^2\mid x]$，求导得 $f^*(x)=\mathbb E[Y\mid X=x]$。分解视角：$=\underbrace{(a-m(x))^2}_{\text{偏离条件均值的代价}}+\underbrace{\operatorname{Var}(Y\mid x)}_{\text{选对均值也消不掉的噪声}}$——第二项与动作无关，最小化只需第一项为零；但 Bayes 最优 ≠ 消除条件不确定性，要风险或区间仍需完整条件分布。

0-1 损失 → 后验最大

条件风险 $\mathbb E[\mathbf 1[a\ne Y]\mid x]=1-P(Y=a\mid x)$，最小化它即最大化后验：$y^*(x)=\arg\max_y P(Y=y\mid x)$。二分类的边界就是两类后验相等处——与 §8 的几何完全一致。

Bayes 最优预测 Bayes optimal predictor · first mentioned: §9

是什么：在真实分布下逐点最小化条件期望损失的预测规则 $f^*(x)=\arg\min_a\mathbb E[\ell(a,Y)\mid X=x]$。

白话：如果真知道上帝骰子怎么掷，每道题都选期望损失最小的答案。

干嘛用：一切预测规则的理论下界与设计模板。

怎么算：平方损失 → 条件均值；0-1 损失 → 后验 argmax（下方互动两种都可视化）。

为什么重要 + 连接：它把“学分布”与“做决策”解耦——第 21 讲把损失换成非对称矩阵时，用同一个后验重新比较动作风险即可，不用重新训练模型。

条件风险 conditional risk · first mentioned: §9

是什么：固定 $x$ 后动作 $a$ 的期望损失 $R(a\mid x)=\mathbb E[\ell(a,Y)\mid X=x]$。

白话：在这一点上，选这个动作平均要付多少钱。

干嘛用：预测 = 逐点选条件风险最小的动作。

怎么算：0-1 损失下 $R(+1\mid x)=P(Y{=}{-}1\mid x)$。讲义小例：后验 0.7/0.3 → 选 $+1$、风险 0.3；后验 0.51/0.49 → 仍选 $+1$、风险 0.49——“同样预测 $+1$”背后的可信度可以差很远。

为什么重要 + 连接：把 §7 的 GNB 后验代入：$x_\star=4$ 时 $R(+1\mid x)\approx0.000055$、$R(-1\mid x)\approx0.999945$——$+1$ 不只是分数大，而是有明确的风险优势。

互动：左拖后验看 0-1 风险决策；右拖动作看平方损失的偏差+噪声

§10综合工作台：随机数据 → GNB 全流程 拓展

把 §5–§8 串成一台机器：随机生成两类二维数据，现场做 MNB 的 MLE（先验、均值、对角方差），画后验热图与 0.5 边界，并统计训练准确率。

观察什么：参数表给出 $\hat\pi_y$、$\hat\mu_y$、$\hat\sigma_{yj}^2$（全部按 §7 公式现算，分母 $n_y$）；边界形状由两类对角方差是否接近决定——差别大时明显弯曲。训练准确率 = 按当前模型重新预测训练标签的正确比例。数据每类 25 点、各类中心与扩散随机，连点几次会看到边界与准确率的真实波动。

§11logsumexp：别让 $\exp$ 下溢 拓展

§8 的 log-score 还原后验时，$g_y$ 常是几百上千的负数——直接 $\exp(g_y)$ 会得到 0，归一化变成 $\tfrac00$。正确做法是先减去最大值再做 log-sum-exp。

logsumexp log-sum-exp trick · first mentioned: §11

是什么：$\operatorname*{logsumexp}_c g_c=\log\sum_c e^{g_c}=g_{\max}+\log\sum_c e^{g_c-g_{\max}}$；后验 $p(y\mid x)=\exp\big(g_y-\operatorname*{logsumexp}_c g_c\big)$。

白话：先把最大分数提到指数外，剩下的指数都在 0 附近——不溢出也不下溢。

干嘛用：任何“对数分数 → 概率”的实现（GNB、softmax、HMM…）。

怎么算：两类时等价于 $p_1=1/(1+e^{g_2-g_1})$——差值进指数，量级立刻可控。

为什么重要 + 连接：它保证 §8 的“log-score 比较”能安全地换算回 §9 需要的后验；直接法与稳定法的对照见下方互动。

互动：把两个 log-score 拖到 $-700$ 量级，看直接法翻车、稳定法稳住

默认对账：$g_1=-750$、$g_2=-751$。直接法：$e^{-700}\approx0$（双精度下溢），归一化 $0/(0+0)=\texttt{NaN}$；稳定法：差值 $g_2-g_1=-1$，$p_1=1/(1+e^{-1})\approx0.731$。把滑杆拉回小区间（如 $-5$ 附近）两种方法一致——logsumexp 不是新数学，是把同一条公式算得出来。

§12常见误区 核心

每一条都先给出“听起来对”的说法，再给真相。

❌

误区 1：生成式模型一定更好，因为它建模了更多东西。

✓ 真相：生成式要建 $P(X\mid Y)$，高维复杂输入（如自然图像）时很难建对，一个错误的 $P(X\mid Y)$ 会拖累分类；判别式只针对 $P(Y\mid X)$，只关心预测时往往更稳。生成式在数据少、结构假设正确、需要采样/异常检测时更有价值。

❌

误区 2：$P(Y\mid X)$ 和 $P(X\mid Y)$ 只是写法不同，可以互相换。

✓ 真相：作为恒等式可以换；作为模型假设很不同——$p(y\mid x)$ 用 logistic 简单，不代表 $p(x\mid y)$ 用高斯也简单。选分解就是选结构假设（§1）。

❌

误区 3：“naive” 就是特征彼此独立。

✓ 真相：是给定类别后特征条件独立（$\Sigma_y$ 对角）；它也不等于“所有类共享协方差”（§6、§8 层级表）。

❌

误区 4：GNB 的方差估计除以 $n_y-1$。

✓ 真相：MLE 除以 $n_y$；$n_y-1$ 是无偏修正，不是最大似然（§7）。

❌

误区 5：logistic loss 是人为规定的合理损失。

✓ 真相：它是对 logistic 条件模型做 MLE 推导出来的负对数似然——换模型族就换损失（§3，对照第 8 讲 hinge 的来历）。

❌

误区 6：“生成式”指预测时会随机生成一个标签。

✓ 真相：它指训练时建立了 $x$ 的生成故事；预测照样是确定性的后验比较（§5–§6）。

❌

误区 7：预测对了就说明概率可信。

✓ 真相：0.7 与 0.51 都预测 $+1$，条件风险差 0.19（§9）；一维 GNB 的 0.9999 可能只是小方差样本的过度自信（§7 诊断点）。

§13收束：第 20 讲真正要带走的东西 核心

本讲的中心不是“logistic vs GNB 谁赢”，而是：同一个联合分布可以有不同分解；不同分解对应不同的建模假设；不同假设决定模型擅长什么、难在哪里。

核心问题 → 答案回顾

在学 $P(Y\mid X)$ 还是 $P(X,Y)$？判别式学前者（logistic），生成式学 $P(Y)P(X\mid Y)$ 再用 Bayes 反推后者到前者。logistic loss 哪来的？对 logistic 条件模型做 MLE，负对数似然逐项就是 $\log(1+e^{-m_i})$。联合的 MLE 能拆开算吗？参数乘积空间 + 可加目标时可拆（$A(\theta_x)+B(\theta_y)$）；共享参数或耦合正则则不行。GNB 全流程？频率先验 + 每类高斯均值/对角方差（除以 $n_y$）→ $\pi_y\mathcal N$ 打分 → 归一化后验；边界形状由协方差共享层级决定。学到分布之后怎么预测？给定损失逐点最小化条件期望损失：平方 → 条件均值，0-1 → 后验 argmax。

最重要的五个公式

$$p(x,y)=p(x)\,p(y\mid x)=p(y)\,p(x\mid y) \quad\text{（两种分解，两种结构假设）}$$ $$p(y\mid x;w)=\frac{1}{1+\exp(-y\langle w,x\rangle)}\ \Longrightarrow\ \hat w=\arg\min_w\sum_i\log\big(1+e^{-y_i\langle w,x_i\rangle}\big) \quad\text{（logistic MLE = logistic loss）}$$ $$p(y\mid x)=\frac{p(y)\,p(x\mid y)}{\sum_c p(c)\,p(x\mid c)} \quad\text{（Bayes 规则：分子比较、分母归一）}$$ $$\hat\pi_y=\frac{n_y}{n},\qquad \hat\mu_y=\frac1{n_y}\sum_{i:y_i=y}x_i,\qquad \hat\sigma_{yj}^2=\frac1{n_y}\sum_{i:y_i=y}(x_{ij}-\hat\mu_{yj})^2 \quad\text{（GNB 的 MLE）}$$ $$f^*(x)=\arg\min_a\mathbb E[\ell(a,Y)\mid X=x] \quad\text{（平方损失→E[Y|x]，0-1 损失→argmax P(y|x)）}$$
