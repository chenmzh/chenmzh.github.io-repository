没有 Critic，怎样用组内结果学习？

上一章的 DPO 把一份固定偏好数据变成直接优化目标，省掉了在线 rollout。但推理训练常常没有现成的 chosen/rejected：模型今天刚学会一种新解法，明天就应该亲自多试几次，再从结果里继续学习。本章重新打开在线循环，并追问：若不训练 Critic，谁来判断一次回答“比预期好多少”？

CHAPTER 16 · ONLINE

同题组内在线更新：当前策略多次采样

每轮用采样策略生成一组回答，现场评分，再让高于同组平均的回答更可能、低于平均的回答更少出现。

两条路线真正不同的是训练证据的生成时机：固定偏好路线复用已有比较；在线组内路线每轮从当前附近的策略分布重新采样，因此能跟着模型的新能力与新错误移动。

Group Relative Policy Optimization（GRPO，组相对策略优化）是一种在线策略优化方法：对同一个 prompt 采样 $G$ 条回答，用组内奖励构造优势，再沿用 PPO 风格的概率比值、裁剪与参考策略约束更新 policy。这里“group relative”不是把整个 batch 混在一起排名，而是只在共享同一个 prompt的回答之间做对照。

GRPO 回顾 PPO，但不重新讲一遍 PPO。Chapter 09 已经解释过“旧策略数据不能被新策略无限利用”，Chapter 14 已经解释过对齐中的 reference policy 与 KL。这里真正新增的是一件事：advantage 不再由 Critic 预测，而由同题样本的组内统计量构造。

真正要观察的是两个粒度：结果验证器通常只给整段回答一个奖励，但策略更新仍要修改回答中逐 token 的条件概率；因此一个回答级优势会广播到它的所有有效 token。

这也暴露了本章的边界：若只知道最终答案对错，我们不能可靠地断言某一个中间 token 究竟对最终结果贡献了多少。Chapter 18 才会正式讨论步骤级的过程奖励；本章坚持使用 outcome-level（结果级） 信号。

03同一道题多答，不是为了立刻选最好，而是为了制造基线

“同题”是组内比较成立的控制变量

若把一道简单算术题的 1 分与一道竞赛题的 0 分直接比较，差异同时混入题目难度与回答质量。GRPO 把 prompt 固定，让组内差别更多来自策略对同一条件的不同采样。

04组内相对优势：先减本组平均，再统一本组尺度

GRPO 不训练一个网络猜 baseline，而是让这一组已经发生的结果临时提供 baseline。它省掉 Critic，却没有省掉“奖励减基线”的思想。

group-relative advantage（组内相对优势）回答：“第 $i$ 条回答比同题组的平均结果高或低多少个组内标准差？”先定义组均值：

$$\bar r_j=\frac{1}{G}\sum_{i=1}^{G}r_{j,i}$$

再定义本讲义数值例采用的总体标准差：

$$s_j=\sqrt{\frac{1}{G}\sum_{i=1}^{G}(r_{j,i}-\bar r_j)^2}$$

最后做 group-wise normalization（组内标准化）：

$$\hat A_{j,i}=\frac{r_{j,i}-\bar r_j}{s_j+\varepsilon_{\mathrm{num}}}$$

$\varepsilon_{\mathrm{num}}$ 只是防止分母为 0 的极小数，不是后面 PPO clip 的裁剪宽度。不同代码库可能用总体标准差、带 Bessel 校正的样本标准差，或只减均值；它们改变数值尺度，但不改变“高于组均值为正、低于组均值为负”的核心方向。复现实验时必须核对实现口径。

四条二值奖励，逐步手算

沿用 $[1,1,0,0]$。第一步，均值为：

$$\bar r=\frac{1+1+0+0}{4}=0.5$$

第二步，每个奖励离均值都是 $0.5$，所以：

$$s=\sqrt{\frac{(0.5)^2+(0.5)^2+(-0.5)^2+(-0.5)^2}{4}}=0.5$$

第三步，代入优势：

$$\hat A=\left[\frac{1-0.5}{0.5},\frac{1-0.5}{0.5},\frac{0-0.5}{0.5},\frac{0-0.5}{0.5}\right]=[+1,+1,-1,-1]$$

容易想错

“GRPO 没有 Critic，所以不需要 baseline。” 不对。GRPO 仍然要把奖励与某个基准比较，只是把一个可训练的 $V_\phi$ 换成同题有限样本的 $\bar r_j$。组均值是临时样本基线，不是真实价值函数，也不会预测未采样前缀的长期价值。

Insight 02

GRPO 省掉的是 Critic 网络，不是比较基线

Critic 用参数跨许多状态学习预期回报；组均值只在当前 prompt 的当前采样组内现场计算。前者增加模型与训练成本，后者增加同题 rollout 成本。

显存压力被削减，并不意味着信息免费：GRPO 用更多采样换掉了一个价值模型。
