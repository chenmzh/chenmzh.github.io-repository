08实验二：四个分量都没变，为什么“最佳视频”会换人？

视觉生成的评审常同时关心 prompt alignment（提示词对齐）、画面质量、时序一致性和运动/物理可信度。先保留 reward vector，再观察标量化权重怎样改变决策。

Question
候选 A 与 B 的四项原始评分固定不动，只调整 reward vector 的权重，训练目标会不会选出相反胜者？
Prediction
A 的画质与对齐更高，B 的时序与物理更高；强调前两项会选 A，强调后两项会选 B。
Experiment
先保持四项等权，复算 A 的 0.5875 与 B 的 0.6000；再分别输入原始权重 $(0.4,0.3,0.15,0.15)$ 和 $(0.1,0.1,0.4,0.4)$，观察归一化加权总分。
Observation
等权时，A 得 0.588，B 得 0.600，B 以 0.013 分领先。
Interpretation
A 在画质与对齐领先，B 在时序与物理领先；总分不是“客观质量”，而是当前权重表达的取舍。
Limitation
四项分数来自固定教学样例，假定各评审已校准到可比较的 $[0,1]$ 区间；真实 reward model 会有噪声、尺度差异、相关性和分布外误判。

Insight 05

标量 reward 会决定胜者，也会隐藏为什么获胜

相同的 0.60 总分可能来自高画质低运动，也可能来自普通画质高时序。训练只读总分时，这两种失败会被压成一个数字；调权重则可能让梯度方向整体翻转。

先记录 reward vector、各维尺度与权重，再汇报 scalar return；否则无法判断模型究竟改善了哪一项。

10总分上升仍可能变坏：本章只先看见三种局部裂缝

三类任务一旦被压成单一训练信号，就可能在未被重视的维度上退化。本节只标出接口处的风险，不提前展开下一章的系统分类。

AUDIO

答对了，但不适合听

只奖励内容可能得到语义正确却迟缓、机械或带爆音的回复；只压低延迟又可能催生抢答和截断。

EMBODIED

塑形分高，但任务没完成

距离奖励能帮助探索，也可能鼓励在目标附近徘徊；碰撞、可见性与真正交互成功需要分别核验。

VISUAL

单帧漂亮，但视频不再运动

只推画质或偏好分，生成器可能偏向清晰的静态片段；加入 motion、temporal 与 physics 分量才暴露冲突。

11检查你的理解：能否先写过程，再选择奖励？

每题都要求从 state、action、trajectory、reward timing 中找依据。只回答“都能用 PPO”不算完成。

1. 十秒音频为什么可能对应 6000 个 codec action？
在教学近似中，动作数是时长 × codec 帧率 × 每帧码本 token 数。用 $10\times75\times8$ 得 6000。真实模型可能并行码本、按 chunk 生成或只优化文本策略，因此要同时声明动作粒度。
2. 把 $\gamma$ 从 0.999 调到 1，音频奖励延迟是否被彻底解决？
没有。数值衰减消失了，但完整回复只有一个终点分数时，仍无法判断数千个动作中哪一帧、哪段停顿或哪条推理造成结果。衰减与定位是两个问题。
3. AI2-THOR 用目标距离给奖励，为什么策略仍属于部分可观测？
距离来自环境 metadata，奖励函数和成功判定可读取；策略 observation 只有第一人称 RGB。奖励能利用隐藏状态计算训练信号，不等于策略在决策时看到了隐藏状态。
4. 四个具身实验都用 PPO，为什么不能直接比较回报高低？
它们的 observation、action、horizon、奖励尺度与任务成功条件不同：连续机械臂、离散键鼠、不同 Unity 任务和室内视觉导航不是同一个实验协议。回报只在各自契约里有意义。
5. 扩散生成中，$s_t$、$a_t$ 和 $\tau$ 分别是什么？
$s_t=(x_t,t,c)$ 是当前潜变量、时间步与条件；$a_t=x_{t-1}$ 是采样得到的下一潜变量；$\tau=(x_T,\ldots,x_0)$ 是完整去噪链。最终图片只是 $x_0$ 解码后的轨迹终点。
6. 为什么去噪轨迹的 log-prob 能把终点 advantage 传给每一步？
轨迹概率是各步转移概率之积，所以轨迹 log-prob 是各步 log-prob 之和。REINFORCE 梯度把终点 advantage 乘到这项和上，每一步 transition 都收到更新；但同一 advantage 广播全链，精确归因仍困难。
7. 候选评分向量没变，调权重为何会改变赢家？
标量奖励是 $R_{\mathbf w}=\mathbf w^\top\mathbf r$。A 强在画质与对齐，B 强在时序与物理；改变 $\mathbf w$ 就改变“好结果”的定义，因此加权总分和梯度方向都可能翻转。
