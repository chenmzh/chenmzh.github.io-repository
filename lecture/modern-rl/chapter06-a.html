Chapter 06 · From a Q table to a trainable value function

当价值表大到写不下，怎么办？

上一章已经给出一步 Q-learning target：$r_t+\gamma\max_{a'}\hat Q(s_{t+1},a')$。在 4×4 网格里，我们可以给每个 $(s,a)$ 留一格；可飞船状态是连续实数，游戏状态是像素画面，下一次观测几乎不会与上一次逐项相同。此时需要保留的不是那张表，而是从经验修正动作价值预测的机制。

本章核心问题：怎样让一组共享参数代替写不下的 Q 表，又怎样避免“相关数据 + 自举目标 + 参数共享”把神经网络训练变成自己追自己的震荡？

01网格里的 64 个数字，到了连续世界会变成多少？

表格 Q-learning 隐含了一个强前提：每个状态都能命名、反复访问，并对应表中的固定一行。

4×4 网格有 16 个状态、4 个动作，只需保存 $16\times4=64$ 个 Q 值。LunarLander 的状态却包含位置、速度、角度、角速度和支架接触信息，其中 6 个量是连续实数。即使粗暴地把每个连续量只切成 50 桶：

$$\underbrace{50^6}_{15{,}625{,}000{,}000\ \text{个离散状态}}\times\underbrace{4}_{\text{离散动作}}=62{,}500{,}000{,}000\ \text{个格子}$$

这还没解决真正的问题：落点横坐标从 0.1200 变到 0.1201，就可能掉进另一桶；两个几乎相同的状态仍要各自从零积累经验。像素输入更极端，四帧 $84\times84$ 灰度画面共有 28,224 个像素位置，逐行建表已经失去意义。

PIXELS

游戏：先理解画面

$s\in\{0,\ldots,255\}^{28224}$

网络还要从局部像素变化中提取位置与运动线索。

真正要观察的不是三个数字谁更大，而是表格方法只会记住“这一行”；连续量和像素任务却要求从见过的状态推断没见过但相似的状态。

容易想错

“状态太多，所以 Q-learning 的 TD target 也失效了。” 不是。失效的是逐格存储 $Q(s,a)$ 的表示方式；“用一步奖励和下一状态价值修正当前动作价值”的目标仍然保留。

02不要保存所有行，让一组参数按需生成一行

function approximation（函数逼近）是用带参数的函数表示价值：输入状态时即时算出 Q 值，而不是先枚举所有状态再填表。

若离散动作集合是 $\mathcal A=\{a_1,\ldots,a_m\}$，用参数 $\theta$ 的函数一次输出这一状态下所有动作的估计：

$$Q(s,\cdot;\theta)=\big[Q(s,a_1;\theta),\ldots,Q(s,a_m;\theta)\big]\approx Q^*(s,\cdot)$$
对象表格表示函数逼近表示
记忆内容每个 $(s,a)$ 一个独立数字一组共享参数 $\theta$
读出一行按 state ID 查表前向计算 $Q(s,\cdot;\theta)$
没见过的状态没有对应经验就没有信息依据已学参数产生预测
一次更新影响通常只改一个格子改 $\theta$，其他状态预测也可能变化

参数共享带来 generalization（泛化）：如果网络学到“下降太快且高度较低时，主发动机通常更有价值”，附近的飞船状态可以共享这条规律。可同一份共享也带来耦合：修正一个输入的输出时，另一个输入的 Q 值可能跟着改变。泛化与干扰来自同一个机制。

Insight 01

函数逼近不是把大表压缩成无损文件，而是在相似状态之间下注

网络假设共享参数学到的结构能迁移到邻近输入。这个归纳偏好让未见状态也有预测，却不保证所有共享都正确。

深度动作价值方法获得规模化能力的同一刻，也失去了“只改一格、别处不动”的隔离性。

03输入一个状态，同时给所有离散动作打分

Deep Q-Network（DQN，深度 Q 网络）用深度神经网络近似最优动作价值函数；在常见离散动作实现中，一次前向传播输出整行动作价值。

STATE$s_t\in\mathbb R^8$位置、速度、姿态、接触
→
SHARED PARAMETERS$Q(\cdot,\cdot;\theta)$MLP / CNN 特征与非线性
→
ACTION VALUES$[q_0,q_1,q_2,q_3]$不喷、左喷、主发动机、右喷

沿箭头观察“一次输入、多个输出”：网络没有直接输出动作概率，而是先给每个离散动作估计长期回报；选择动作仍发生在输出之后。

例如某个 LunarLander 状态经过网络得到：

$$Q(s_t,\cdot;\theta)=[-0.4,\ 0.8,\ 2.1,\ 0.5]$$

纯贪心选择会取索引 2 的“主发动机”，因为 $2.1$ 最大。训练时仍可沿用上一章的 $\varepsilon$-greedy behavior policy：以概率 $\varepsilon$ 随机探索，否则取 $\arg\max_aQ(s_t,a;\theta)$。网络替代的是 Q 表，不是探索需要。

一批状态输入网络后，输出形状是 $B\times|\mathcal A|$。但每条经验只执行了一个动作 $a_i$，所以 loss 左边只需要取对应列：

$$q_i=Q(s_i,a_i;\theta)$$

代码中的 gather 就做这件事：从每行所有动作分数中，抽出那条 transition 实际执行动作的预测。

Insight 02

DQN 没有抛弃 Q-learning；它把“改一个表格数字”改成了“训练一个预测函数”

动作选择仍比较 Q 值，学习信号仍来自一步 TD error。变化发生在表示和优化：一个格子的增量更新变成对共享参数的梯度下降。

先认出不变的 Bellman/TD 骨架，再看新增的网络、数据和稳定化结构，DQN 就不会成为一串陌生模块。
