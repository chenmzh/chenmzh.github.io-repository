04有了 state，还要描述：动作之后会到哪里？

状态解决“现在是什么局面”。下一步要解决的是世界本身的规律：在这个局面执行这个动作，之后可能发生什么？

最简单的环境是确定性（deterministic）的：给定当前状态和动作，下一状态唯一确定。例如一个没有随机打滑的棋盘世界，站在 $(1,1)$ 向右走，就一定到 $(1,2)$。

但很多环境是随机性（stochastic）的。同样在 $(1,1)$ 选择“向右”，地面可能打滑：80% 正常到右边，10% 偏到上边，10% 偏到下边。这时动作不再对应一个结果，而对应一个下一状态的概率分布。

这个规律用 transition probability（状态转移概率）表示：

$$P(s'\mid s,a)=P(S_{t+1}=s'\mid S_t=s,A_t=a)$$

公式逐个翻译：

量含义在打滑棋盘里
$s$当前 state 的一个具体值当前位置 $(1,1)$
$a$当前 action 的一个具体值选择“向右”
$s'$某个候选下一 state例如 $(1,2)$
$P(s'\mid s,a)$已知当前 state 和 action 时，到达 $s'$ 的概率$P((1,2)\mid(1,1),\rightarrow)=0.8$

所以在这个具体数字里：

$$P((1,2)\mid(1,1),\rightarrow)=0.8,\quad P((0,1)\mid(1,1),\rightarrow)=0.1,\quad P((2,1)\mid(1,1),\rightarrow)=0.1$$

三个概率加起来是 1。注意：$P$ 不是在预测“这一回一定发生什么”，而是在描述重复许多次同样的 state–action 条件时，各种后果会以什么频率出现。

容易想错

“既然动作是 agent 选的，下一状态也应该由 agent 决定。” 不对。Agent 控制的是 action，不是 outcome。动作进入环境以后，真正的后果由环境动力学决定；随机环境里，同一个 action 甚至会有多个可能结果。

Insight 03

Action 是干预，transition 才是世界对干预的回答

Policy 决定“我要做什么”；$P(s'\mid s,a)$ 决定“世界收到这个动作后可能变成什么”。这两者不能混成一个函数。

后面很多 RL 公式看起来复杂，实际上始终在交替处理这两个来源：agent 的选择规律，以及 environment 的后果规律。

05互动实验：动作不是结果，而是一份结果分布

下面固定同一个当前 state，只改变动作和“打滑概率”。先看理论分布，再真的从这个分布采样 100 次。

Slippery Grid · Transition Microscope

黑框是当前 state；标着概率的格子是下一步可能到达的位置。

Interpretation

Limitation

为什么这个区分后面很重要？

假设某个动作平均来说很好，但有 5% 概率掉进陷阱。一个只看“最可能结果”的算法会把这 5% 完全丢掉；而价值计算必须把所有可能后果按概率加权。后面 Bellman equation（贝尔曼方程）里出现的 expectation（期望），正是从这里来的。

06把“世界会怎样”和“我们想要什么”分开

Transition 只负责描述后果；它并没有说哪种后果值得追求。要把任务目标加入环境，还需要 reward。

reward function（奖励函数）描述某个 transition 发生时环境给多少即时反馈。为了把“同一个动作到不同下一状态时奖励可能不同”写清楚，本章用三参数形式：

$$R(s,a,s')=\mathbb{E}[r_t\mid S_t=s,A_t=a,S_{t+1}=s']$$

它读作：已经知道“从 $s$ 做了 $a$ 并到了 $s'$”以后，这一步 reward 的期望是多少。很多环境里 reward 是确定值，此时这个期望就等于那一个固定分数。

Insight 04

MDP 把“事实”和“偏好”拆开了

$P$ 是关于世界的陈述：动作会造成什么后果；$R$ 是关于任务的陈述：哪些后果值得追求。改变 reward 不需要改变物理规律。

这个分离会一路延伸到现代对齐：模型能力和环境规则是一回事，“什么样的回答应该得高分”是另一回事。Reward design 不是动力学问题，而是目标规格问题。

即时 reward 还不够：我们关心的是未来一整串后果

Chapter 01 已经见过 return（回报）：从当前时刻开始，未来 reward 的折扣和。现在把它放回完整的序贯决策里：

$$G_t=r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots=\sum_{k=0}^{\infty}\gamma^k r_{t+k}$$

discount factor（折扣因子） $\gamma\in[0,1]$ 控制未来 reward 的权重。若任务会在有限步自然结束，求和实际上在终止处停止。

一个具体数值例子：路线 A 立刻得到 $+1$ 然后结束；路线 B 先连续三步各付 $-0.1$，第 4 步得到 $+2$。当 $\gamma=0.9$ 时：

$$G_B=-0.1-0.9(0.1)-0.9^2(0.1)+0.9^3(2)\approx1.19$$

于是 B 的长期回报高于 A 的 1.0；但如果 $\gamma=0.5$，同一路线 B 的回报只有约 $0.075$。这说明“哪条路径更好”不仅取决于奖励本身，也取决于我们把问题放在多长的时间尺度上。

容易想错

“Reward function 就是在告诉 agent 正确动作。” 不对。Reward 通常只评价 transition 的结果；agent 仍要自己学会哪些当前动作会通过状态转移带来更大的长期 return。

07现在五个对象终于有理由放到一起

到这里才适合写定义：前面每个符号都已经回答了一个真实问题，不再是一张需要背诵的名词表。

一个 Markov Decision Process 通常写成：

$$\mathcal{M}=(\mathcal{S},\mathcal{A},P,R,\gamma)$$
$\mathcal{S}$State space
所有可能局面的集合
$\mathcal{A}$Action space
agent 可以采取的操作
$P$Transition
动作如何改变世界
$R$Reward
环境怎样评价一步后果
$\gamma$Discount
未来 reward 的时间权重
对象4×4 GridWorldCartPole大语言模型生成
$\mathcal{S}$16 个格子位置位置、速度、角度、角速度当前上下文与任务所需的环境信息
$\mathcal{A}$上 / 下 / 左 / 右向左推 / 向右推下一 token，或更高层的工具调用动作
$P$移动 + 打滑规则物理动力学生成动作后上下文怎样更新、工具/环境怎样响应
$R$Goal +1，Trap −1存活一步 +1偏好模型、规则 verifier 或环境结果给出的分数
$\gamma$未来路径奖励的折扣长期保持平衡的时间尺度长回答或多步 agent 轨迹中未来结果的权重

这里最值得记住的不是五个字母，而是五个问题：现在是什么局面？能做什么？做完世界会怎样？这些后果好不好？未来还算多重要？ 只要能回答这五个问题，你已经开始把一个任务写成 RL 可以处理的形式。

Bandit 原来也是这个框架的一种极端简化

Chapter 02 的两臂老虎机可以看成只有一个 state 的特殊情况：$\mathcal{S}=\{s\}$，无论选 A 还是 B，下一轮都回到同一个 $s$。于是状态转移被压成了一个几乎看不见的自环，问题才退化成“估计每个动作平均 reward”。

这也是为什么课程先讲 bandit 再讲 MDP：不是因为老虎机更“初级”，而是因为删掉 state transition 后，我们能先孤立出 exploration；现在把 transition 加回来，才开始面对真正的长期决策。
