04策略会分叉，环境也会分叉：两层平均缺一不可

Chapter 03 已经把一步概率拆成策略的 $\pi(a\mid s)$ 与环境的 $P(s'\mid s,a)$。现在让它们共同参与当前价值。

在状态 $s$，固定策略有 60% 概率选择“稳妥”，40% 概率选择“冒险”。两个动作的即时奖励都是 1，但它们把 agent 带向不同未来。取 $\gamma=0.9$：

$\pi(\text{稳妥}\mid s)=0.6$ → 必然到安稳区
$V^\pi=5$ $1+0.9(5)=5.5$
$\pi(\text{冒险}\mid s)=0.4$ → 25% 到高价值区 $V^\pi=12$
75% 到困境 $V^\pi=-2$ $1+0.9[0.25(12)+0.75(-2)]=2.35$

先在每个动作内部平均环境后果，再按策略概率平均动作；计算顺序可以重排，但两层概率质量都不能丢。

先在每个动作内部按环境概率平均，再按策略的动作概率平均：

$$V^\pi(s)=0.6(5.5)+0.4(2.35)=4.24$$

这 4.24 没有沿任何一条轨迹真实出现。它是在行动发生之前，对所有可能分支的概率加权结果。只保留“最可能动作”会漏掉冒险分支；只保留“每个动作最可能到达的状态”又会漏掉环境风险。

Insight 03

期望不是挑一条代表性未来，而是保留所有分支的概率质量

一个小概率坏结果不会因为“不最可能”就消失；一个低概率高价值后果也不能被当作必然发生。策略随机性与环境随机性各有一层加权。

这正是 Chapter 03 的 $\pi\times P$ 在价值计算中的落点。

05不看完整棵未来树：先把回报切成“第一步 + 剩余未来”

价值之所以能传播，不是额外假设出来的技巧，而是因为 return 本身就有递归结构。

把 $G_t$ 的第一项单独拿出来：

$$\begin{aligned}G_t&=r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots\\&=r_t+\gamma\underbrace{(r_{t+1}+\gamma r_{t+2}+\cdots)}_{G_{t+1}}\\&=r_t+\gamma G_{t+1}.\end{aligned}$$

再把这个等式放进状态价值的定义。由于随机变量 $S_{t+1}$ 在当前还没取到具体状态，不能直接把随机的 $V^\pi(S_{t+1})$ 当成一个确定数；必须对下一状态也取期望：

定义$V^\pi(s)=\mathbb{E}_\pi[G_t\mid S_t=s]$
拆 return$=\mathbb{E}_\pi[r_t+\gamma G_{t+1}\mid S_t=s]$
用下一状态概括剩余未来$=\mathbb{E}_\pi[r_t+\gamma V^\pi(S_{t+1})\mid S_t=s]$

第三步为什么成立？先对下一状态做一次“内层平均”，再对当前状态下可能出现的下一状态做“外层平均”：

$$\begin{aligned} \mathbb E_\pi[G_{t+1}\mid S_t=s] &=\mathbb E_\pi\!\left[\mathbb E_\pi[G_{t+1}\mid S_t=s,S_{t+1}]\mid S_t=s\right]\\ &=\mathbb E_\pi\!\left[\mathbb E_\pi[G_{t+1}\mid S_{t+1}]\mid S_t=s\right]\\ &=\mathbb E_\pi[V^\pi(S_{t+1})\mid S_t=s]. \end{aligned}$$

第一行是 nested expectation（嵌套期望）：先问“如果下一状态已经知道，剩余回报平均是多少”，再对下一状态取平均。第二行使用 Chapter 03 定义的 Markov state（马尔可夫状态）条件，并要求固定策略只依赖当前状态：给定 $S_{t+1}$ 后，更早的 $S_t$ 不再为后续回报提供额外信息。第三行才代入 $V^\pi$ 的定义。若输入只是一个遗漏关键信息的非 Markov observation，这种压缩就不能原样成立。

把离散动作和下一状态的两层期望完全展开，就得到 Bellman expectation equation（贝尔曼期望方程）：固定策略下，当前价值必须等于“一步即时奖励 + 折扣后的下一状态价值”的期望。

$$V^\pi(s)=\sum_{a\in\mathcal A}\pi(a\mid s)\sum_{s'\in\mathcal S}P(s'\mid s,a)\left[R(s,a,s')+\gamma V^\pi(s')\right]$$

这里 $R(s,a,s')$ 不是假设 reward 与下一状态无关，而是条件 $(S_t=s,A_t=a,S_{t+1}=s')$ 固定以后，即时奖励 $r_t$ 的期望：

$$R(s,a,s')=\mathbb E[r_t\mid S_t=s,A_t=a,S_{t+1}=s']$$
从里到外在做什么来源
$R(s,a,s')+\gamma V^\pi(s')$评价一个具体的一步后果眼前奖励 + 剩余未来
$\sum_{s'}P(s'\mid s,a)$对动作 $a$ 的所有环境后果取平均environment
$\sum_a\pi(a\mid s)$对固定策略可能选择的动作取平均agent policy
一个关键的概率细节

不能写 $V^\pi(s)=r_t+\gamma V^\pi(S_{t+1})$ 就结束。 当动作或转移有随机性时，$r_t$ 与 $S_{t+1}$ 在行动前都不确定；正确等式必须对它们取条件期望，或像上式那样按 $\pi$ 与 $P$ 完整展开。

Insight 04

贝尔曼方程不是近似：它是 value 定义必须满足的自洽关系

真正的 $V^\pi$ 同时出现在等式两边，因为下一状态的价值已经概括了从那里开始的全部未来。

近似发生在我们还不知道真值、只拿当前估计去构造新目标时；不是发生在贝尔曼等式本身。

Bellman backup（贝尔曼备份）是把这条方程右侧当作当前状态的新目标：读取下一状态的旧估计，反过来更新当前状态。下面不换策略、不比较动作，只观察固定策略下的一步备份怎样传播信息。

06互动实验：终点奖励一次能回写到多早？

固定策略永远向右。初始价值全是 0；每次点击都让所有状态只读取上一轮的旧表，同时做一次备份。

Rightward Corridor · Bellman Propagation

进入终点 G 得到 +1；此前奖励为 0；终止以后 $V(G)=0$。

Question
终点的 $+1$ 能否在一次 Bellman backup 中立刻影响走廊里的所有状态？
Prediction
不能。同步备份只读取上一轮价值表，因此一轮最多沿转移边回写到一个更早状态。
Experiment
保持“永远向右”的策略，调整 $\gamma$，然后逐次点击备份；比较每轮前后的四个状态值。
Observation
第 0 轮所有估计都是 0。先预测：第一次备份会从哪个状态开始出现非零值？
Interpretation
贝尔曼右侧把下一状态的旧估计搬回当前状态；反复应用后，远期奖励才会逐层影响更早的状态。
Limitation
这是确定性走廊、固定策略且环境模型完全已知的演示；它没有比较策略，也没有说明只拿到采样经验时该怎样估计价值。
