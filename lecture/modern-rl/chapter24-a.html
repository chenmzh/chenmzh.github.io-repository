Chapter 24 · Vision changes what reward must verify

答案对了，模型真的看图了吗？

上一章把模型放进屏幕环境：它既要读懂像素，也要执行可能不可逆的点击。本章先把“行动”按住，只研究更基础的一层——当问题同时包含图像与文字时，RL 怎样区分答对了、格式可用和视觉证据真的支持答案。

本章核心问题：同一道看图计数题，两个 rollout 都回答“3”，一个准确标出了三处圆形，另一个没看图只是猜中。若 outcome reward 都给 1，训练如何知道该强化谁？

01文本题只要核对答案；看图题还要问答案从哪里来

图像让问题多了一条因果链：像素必须先影响内部表征，再影响生成的证据与答案。只核对终点，无法观察这条链有没有真正工作。

Vision-Language Model（VLM，视觉语言模型）是同时以图像和语言为条件、再生成语言或结构化输出的模型。直觉上，它像“能看图的语言模型”；但在 RL 中，关键变化不只是输入多了图片，而是奖励必须能分辨模型是否利用了图片。

只看最后一行，两条 rollout 完全相同；加入证据区域与换图对照后，模型是否依赖视觉输入才变成可观察差异。

Chapter 16 的 outcome verifier（结果验证器）已经解决“最终结果是否正确”：例如把最后答案与标准答案比较。本章只把它当作已知部件，不重新展开 RLVR 或 GRPO。新的困难是：最终结果正确，并不蕴含视觉依据正确。

容易想错

“看图题答对了，就证明视觉模块学会了。” 不一定。数据偏置、题型先验或碰巧猜中，都能产生正确答案。必须把图像改变时的响应、证据位置或跨模态一致性也纳入评估。

02先把五个对象分开：图像是 observation，不是 action

多模态不会自动改写 RL 的基本语法；它先改变模型看到了什么，再迫使我们重新规定输出、轨迹和核验接口。

设图片为 $I$、文字问题为 $q$。对一个单轮视觉问答任务，可以把初始 observation（观察）写成：

$$o_0=(I,q)$$

视觉编码器把 $I$ 变成视觉 token，文字 tokenizer 把 $q$ 变成文本 token；两者共同作为条件送进语言模型。模型真正逐步采样的 action（动作）仍是响应 token：

$$a_t=y_t\sim\pi_\theta(\cdot\mid I,q,y_{<t})$$

若输出要求 JSON、边界框或 <evidence> 字段，这叫 structured action（结构化动作）：语义上它是一条可解析的动作记录，生成时通常仍被序列化为 token。图片的 patch token 是输入条件，不是模型这次采样出来的动作。

对象本章记号几何计数例子谁产生它
视觉 observation$I$含圆形、方形和三角形的画布数据集或环境
文字 observation$q$“蓝色圆形有几个？”数据集或环境
文本 / 结构化 action$y_{1:T}$证据 ID、推理字段、答案字段策略采样
trajectory$\tau$图像、问题与整段响应的联合记录rollout 过程
reward$R(\tau)$格式、答案与视觉定位分数验证器

因此单轮 trajectory（轨迹）可以写成：

$$\tau=(I,q,y_1,y_2,\ldots,y_T)$$

它虽然没有像机器人那样走很多环境步，却仍是一条 token 级决策序列。若允许模型调用 crop(x_1,y_1,x_2,y_2) 放大局部区域，轨迹才会变成交错的“生成工具动作 → 得到新图像 observation → 继续生成”。

Insight 01

多模态首先改变条件信息，不一定改变动作空间

视觉 token 进入策略的条件；响应 token 才是被采样并由 policy loss 直接计分的动作。只有当模型调用裁剪、框选或外部工具时，结构化命令才额外成为环境层面的动作。

先问“谁是 observation、谁是 action”，再谈 rollout 与 reward，许多多模态概念就不会混在一起。

03同图同问采样一组响应：rollout 变长，比较对象也变丰富

视觉输入增加了条件 token 和显存开销；更重要的是，同一个最终答案之下，现在还能比较证据区域、结构格式与跨模态一致性。

图像先被编码成条件 token，策略再逐 token 生成响应；验证器需要回看原图与结构化输出，才能判断“证据是否支持答案”。

若对同一个 $(I,q)$ 采样 $G$ 条响应，Chapter 16 已学过的组内相对优势仍可复用：

$$A_i=\frac{R_i-\bar R}{\sigma_R+\varepsilon},\qquad i=1,\ldots,G$$

$R_i$ 是第 $i$ 条响应的总奖励，$\bar R$ 与 $\sigma_R$ 是这一组的均值和标准差。这里的新问题不在归一化公式，而在$R_i$ 应该测什么。若四条响应都碰巧答对“3”，纯答案奖励让 $\sigma_R=0$；奖励无法告诉策略哪条证据更可信。

若输入图像缩放为 $448\times448$，视觉编码器以 $14\times14$ patch 切分，那么合并前最多有 $(448/14)^2=1024$ 个 patch 位置。实际模型可能继续合并、压缩或动态分辨率编码；这个数值例子只说明：视觉条件会显著挤占序列长度和显存，但它仍不是 1024 个被策略采样的 action。
