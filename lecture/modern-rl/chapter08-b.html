05Critic：用一步事实和下一状态估计，训练这把动态标尺

Critic 的任务是让 $V_\phi(s_t)$ 靠近当前策略的真实 $V^{\pi_\theta}(s_t)$。最常见的早期 Actor–Critic 用一步 TD target 来提供监督。

采到 transition $(s_t,a_t,r_t,s_{t+1})$ 后，定义终止标记 $d_t\in\{0,1\}$：若这一步真正终止，$d_t=1$，否则为 0。一步 Critic target 是：

$$y_t=r_t+\gamma(1-d_t)V_\phi(s_{t+1})$$

$1-d_t$ 很重要：终止以后没有“下一状态继续得分”，所以终止 transition 的 target 必须退化为 $y_t=r_t$。实现时，右侧 target 通常停止梯度，只让当前预测向这个临时目标移动。

Critic 的平方损失可以写成：

$$L_{\text{critic}}(\phi)=\frac12\left[V_\phi(s_t)-\operatorname{stopgrad}(y_t)\right]^2$$

target 与当前预测的差，就是 Chapter 05 已经学过的 temporal-difference error（TD error，时序差分误差）：

$$\delta_t=y_t-V_\phi(s_t)=r_t+\gamma(1-d_t)V_\phi(s_{t+1})-V_\phi(s_t)$$

为什么同一个 $\delta_t$ 又能近似 advantage？若 Critic 恰好等于真实 $V^\pi$，在固定 $(s,a)$ 后对奖励与下一状态的随机性取期望：

$$\begin{aligned} \mathbb E_\pi[\delta_t\mid S_t=s,A_t=a] &=\mathbb E_\pi[r_t+\gamma V^\pi(S_{t+1})\mid s,a]-V^\pi(s)\\ &=Q^\pi(s,a)-V^\pi(s)\\ &=A^\pi(s,a). \end{aligned}$$

第二行正是 $Q^\pi$ 的一步贝尔曼展开。但现实中使用的是 $V_\phi$，不是已知真值；因此更准确的说法是：$\delta_t$ 是一个可立即计算的单步 advantage estimator（优势估计器），而不是每个样本上都等于真实 $A^\pi$。

同一个 $\delta_t$对 Critic对 Actor
数值含义当前价值预测离 TD target 多远这次动作相对当前基线有多好
使用方式通过 $\delta_t^2/2$ 更新 $\phi$作为停止梯度的权重更新 $\theta$
风险自举会把下一状态估计误差带进 target错误的 Critic 可能暂时鼓励或抑制错动作

06Actor：正 advantage 增加概率，负 advantage 降低概率

Actor 不去回归一个“正确动作标签”。它仍做策略梯度，只是把原来的绝对回报权重换成了中心化的 advantage estimate。

用 $\widehat A_t$ 表示任意选定的优势估计器，Actor 的梯度方向写成：

$$\widehat{\nabla_\theta J}=\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\,\widehat A_t$$

深度学习框架默认做梯度下降，因此常把它改写成要最小化的 actor loss：

$$L_{\text{actor}}(\theta)=-\frac1T\sum_{t=0}^{T-1}\log\pi_\theta(a_t\mid s_t)\,\operatorname{stopgrad}(\widehat A_t)$$
$\widehat A_t>0$提高已采样动作概率

梯度下降让 $\log\pi(a_t\mid s_t)$ 增大，也就是让该动作更常被选。

$\widehat A_t\approx0$几乎不改变该动作

这次结果与基线一致，没有理由仅凭它明显改变动作概率。

$\widehat A_t<0$降低已采样动作概率

负权重翻转更新方向，让该动作在相同状态下更少出现。

三个框真正要看的是 advantage 的符号怎样改变所选动作的更新方向；actor loss 的数值本身不要求始终为正，也不必像监督学习 loss 那样单调下降。

一个完整的数值例

假设 Actor 在 $s_t$ 采样动作“向右”，概率为 $\pi_\theta(a_t\mid s_t)=0.4$；Critic 给出 $V_\phi(s_t)=2.5$、$V_\phi(s_{t+1})=1.0$。环境返回 $r_t=0$，未终止，$\gamma=0.9$。

Critic target$y_t=0+0.9(1.0)=0.9$
TD error / advantage estimate$\delta_t=0.9-2.5=-1.6$
log probability$\log\pi_\theta(a_t\mid s_t)=\log0.4\approx-0.916$
Actor loss$L_{\mathrm{actor}}=-(-0.916)(-1.6)\approx-1.466$
Critic loss$L_{\mathrm{critic}}=\tfrac12(-1.6)^2=1.28$

Actor loss 为负不是故障。真正重要的是 $\delta_t<0$：梯度下降会降低“向右”的概率。Critic 同时把 2.5 向 target 0.9 拉近。

梯度边界

Actor 使用 Critic 给出的数值，不等于 Actor loss 要穿过 $\delta_t$ 更新 Critic。 $\operatorname{stopgrad}(\widehat A_t)$ 把 advantage 当作权重；Critic 应由自己的价值损失训练。即使两者共享前面的特征网络，两条损失的职责也要保持清楚。

Insight 03

同一个 TD error 可以传递两种含义，但不能混成一条梯度

对 Critic，它是预测残差；对 Actor，它是相对好坏的权重。数值相同，优化对象和梯度路径不同。

Actor 消费 detached advantage；Critic 用 value loss 学会产生更好的 advantage。

07一次联合更新：行为改变数据，数据又改变两张网络

把公式按真实发生顺序排好，Actor–Critic 就是一条很短的闭环。

  1. 1
    Actor 采样$a_t\sim\pi_\theta(\cdot\mid s_t)$，同时保存 $\log\pi_\theta(a_t\mid s_t)$。
  2. 2
    环境推进得到 $r_t$、$s_{t+1}$ 与终止标记 $d_t$。
  3. 3
    Critic 评价计算 $V_\phi(s_t)$ 与 $V_\phi(s_{t+1})$，构造 $y_t$ 和 $\delta_t$。
  4. 4
    更新 Critic最小化 $\tfrac12[V_\phi(s_t)-y_t]^2$，让基线更接近当前策略的回报。
  5. 5
    更新 Actor最小化 $-\log\pi_\theta(a_t\mid s_t)\operatorname{stopgrad}(\widehat A_t)$。

按箭头顺序观察因果链：Actor 决定采到什么数据；Critic 用这些数据学习标尺；标尺再决定 Actor 下一次更新哪些动作。

“单步 target 可计算”不等于实现必须每个 environment step 都调用一次优化器。实际 A2C（Advantage Actor–Critic，优势演员—评论家）常让多个并行环境先各收集一小段 rollout，再把这些 transition 放在一个 batch 中更新。数学信号仍来自每一步，工程上则通过批量平均减少噪声、提高吞吐。

08互动实验：同一条 trajectory，return、value 与 advantage 在说什么？

固定三步轨迹，只改变终点奖励、折扣或 Critic 的三项估计。每一行同时计算完整回报优势与一步 TD advantage。

Question
同一条已发生的轨迹里，$G_t$、$V_\phi(s_t)$、$G_t-V_\phi(s_t)$ 与 $\delta_t$ 各自评价什么？为什么后两者可能给同一步不同符号？
Prediction
终点奖励会反向改变所有 MC return；单步 $\delta_t$ 只直接读取本步奖励和下一状态估计。Critic 若尚未自洽，两种 advantage estimate 可能暂时异号。
Experiment
先看默认第 1 行（$t=1$）；再把 $V_\phi(s_2)$ 从 1 调高，或把终点奖励从 4 调低，观察 MC 与 TD 两列谁先改变。
Observation
正在计算同一轨迹的四种量。
Interpretation
MC advantage 看到了实际完整尾部，方差较高；单步 TD advantage 提前用 Critic 对下一状态的估计收尾，方差通常较低，但会继承 Critic 的误差。
Limitation
这是一条确定的短轨迹，只展示估计器如何使用信息；它不能证明某种估计器在任意环境中方差一定更小，也不展示参数更新后的长期收敛。

Insight 04

MC advantage 与 TD error 异号，不代表其中一个公式写错

前者用已经发生的完整未来，后者用一步事实加一份当前预测。Critic 还没把终点信息传播到 $s_2$ 时，二者自然可能给出不同的短期判断。

估计器的差别，本质上是“在哪一步停止使用事实，开始使用预测”。
