07Conservative value：先在证据内改进，再决定要离数据多远

离线策略不能靠部署前试错纠正自己，因此价值最大化需要同时回答两个问题：这个动作估值有多高？这个估值又有多少数据支持？

conservative value estimation（保守价值估计）的核心不是把所有价值一律减小，而是让数据外动作比数据内动作承担更大的不确定性成本。常见方法可以从两个位置介入：

ROUTE A · 限制策略或候选动作

只在 behavior support 附近找更好动作

一种做法从学到的行为分布生成候选动作，只允许小幅扰动；另一种做法在提高 Q 的同时，直接惩罚策略偏离日志动作。

$$\max_\pi\;\mathbb E_{s\sim\mathcal D,a\sim\pi}[\hat Q(s,a)]\quad\text{s.t.}\quad D(\pi\|\pi_\beta)\le\varepsilon$$
ROUTE B · 改造价值学习

让 OOD 动作难以靠虚高估值获胜

一种做法显式压低广泛候选动作相对于数据动作的 Q；另一种做法只从数据动作提取偏向高值的基线，避免在 target 中显式查询数据外动作的最大 Q。

$$\text{Bellman fit}\; +\; \alpha\times\text{support-aware pessimism}$$

两条路线控制的是同一条因果链的不同位置：左侧减少策略进入低支撑区域，右侧减少低支撑动作凭虚高 Q 吸引策略。实际算法常把两种约束组合使用。

方法它在什么位置保守一句话直觉
行为附近选动作候选动作只在行为数据附近挑动作
广泛候选价值惩罚Q 函数压低广泛候选动作，相对抬住数据动作
数据内偏高基线价值 target只依赖数据动作，并用偏向较高回报样本的加权回归学习 $V$，避开显式的数据外最大值
价值提高与动作复现Actor 损失提高 Q，同时别离日志动作太远

保守强度也不是越大越好。过弱时会相信外推；过强时会把真正优于行为策略、但覆盖较少的动作也压掉，最终退化成近似复现日志动作。因此离线 RL 的核心权衡可以写成：

$$\text{policy improvement}\quad\longleftrightarrow\quad\text{stay close enough to evidence}.$$
Insight 04

离线保守性不是胆小，而是把证据强度纳入优化

在线 agent 可以用探索购买新证据；纯离线 agent 没有这个选项。它若离开 support，承担的不是“可能试错一次”，而是“永远无法在训练中核验”。

保守项不是取消策略改进，而是要求改进幅度与数据能支撑的可信度相匹配。

08保守 Q 学习：为什么一项 logsumexp 能形成“一压一拉”？

Conservative Q-Learning（CQL，保守 Q 学习）保留 Bellman 拟合，同时加入一个相对惩罚：广泛动作的高 Q 要付费，日志里真实动作的 Q 则被托住。

在离散动作的教学版本中，CQL critic loss 可以写成：

$$\mathcal L_{\mathrm{CQL}}(Q)=\mathcal L_{\mathrm{Bellman}}(Q)+\alpha\left(\mathbb E_{s\sim\mathcal D}\left[\log\sum_a e^{Q(s,a)}\right]-\mathbb E_{(s,a)\sim\mathcal D}[Q(s,a)]\right).$$

按作用拆开：

  1. $\log\sum_a e^{Q(s,a)}$ 对所有候选动作做 soft maximum。 某个动作 Q 越高，它对这一项的贡献越大；最小化 loss 会把高输出向下压。
  2. $-\mathbb E_{(s,a)\sim\mathcal D}Q(s,a)$ 把数据动作往上拉。 数据中实际出现的动作同时进入负项，不会和 OOD 候选受到完全相同的净下压力。
  3. $\alpha$ 决定这条 gap 有多强。 $\alpha=0$ 退回普通 Bellman 拟合；过大则可能过度悲观。

两动作的梯度直觉

仍设数据动作“直行”的 $Q=5$，零样本动作“强右”的 $Q=9$。保守括号为：

$$\log(e^5+e^9)-5\approx9.018-5=4.018.$$

softmax 权重分别约为 $0.018$ 与 $0.982$，所以括号对两个 Q 的导数是：

$$\frac{\partial}{\partial Q_{\mathrm{data}}}\approx0.018-1=-0.982,\qquad \frac{\partial}{\partial Q_{\mathrm{ood}}}\approx0.982.$$

梯度下降会沿导数反方向移动：把数据动作往上拉，把 OOD 高值往下压。这就是“一压一拉”的数学来源。连续动作无法枚举所有 $a$，实际实现会从随机分布与当前策略采样候选动作来近似。

边界提醒

这项正则不能凭空恢复 OOD 动作的真实价值；它只阻止缺少证据的高值过早主导策略。离线评估本身也受 support 限制，因此超参数不能只凭训练 loss 决定，还需要独立的仿真、安全评测或可靠 holdout protocol。

09Sequence modeling：如果不做 $\max Q$，能否直接预测动作？

保守 Q 方法仍在修补 Bellman 学习。另一条路线干脆把固定轨迹排成序列，将“想要多少回报”作为条件，用监督学习预测日志动作。

Decision Transformer（DT，决策 Transformer）先为轨迹中每个位置计算 return-to-go（RTG，剩余回报）：

$$\widehat R_t=\sum_{k=t}^{T}r_k.$$

若接下来三步奖励为 $2,1,3$，三个位置的 RTG 分别是 $6,4,3$。DT 把轨迹改排成：

$\widehat R_1$目标余量→$s_1$当前状态→$a_1$监督动作→$\widehat R_2$→$s_2$→$a_2$

真正要观察的是条件方向：传统价值学习从 $(s,a)$ 预测未来回报；DT 把目标剩余回报放进上下文，从“我还想拿多少分、现在在哪里、之前做了什么”预测下一动作。

使用因果注意力时，模型在预测 $a_t$ 前只能看到当前与过去的信息：

$$\pi_\theta(a_t\mid\widehat R_{1:t},s_{1:t},a_{1:t-1})=\operatorname{Transformer}(\widehat R_{1:t},s_{1:t},a_{1:t-1}).$$

连续动作可直接使用均方误差训练：

$$\mathcal L_{\mathrm{DT}}=\mathbb E_{\tau\sim\mathcal D}\left[\sum_t\|\hat a_t-a_t\|^2\right].$$

训练没有 Bellman target，也没有 $\max_aQ$。部署时给一个数据中合理的目标 RTG，每执行一步拿到 $r_t$，就更新 $\widehat R_{t+1}=\widehat R_t-r_t$，再预测下一动作。

序列路线建模对象推理方式
Decision Transformer给定 RTG 的条件动作分布逐步自回归动作
Trajectory Transformer离散化的完整轨迹联合分布beam search 搜索轨迹
Diffuser整条连续轨迹的生成分布从噪声迭代去噪

序列建模避开了“在 OOD 动作上取最大 Q”这条故障路径，却没有消灭数据边界。若目标 RTG 高于数据中所有轨迹，或者当前状态附近从未出现高回报动作，Transformer 仍然只能外推。它更像是在学习：

$$\pi_\theta(a\mid s,\widehat R)\approx\pi_\beta(a\mid s,\text{return}\approx\widehat R).$$
Insight 05

换掉 Bellman 方程，不等于换掉数据支撑的上限

DT 不会被 $\max Q$ 直接诱入虚高动作，但它仍依赖固定轨迹中“状态—目标回报—动作”的共现关系。

离线 RL 可以换目标函数、换模型架构，却不能从没有证据的地方无条件创造可靠决策知识。

11检查你的理解：你能沿着证据边界诊断失败吗？

先不要背算法名。对每个问题依次回答：数据由谁采、覆盖哪里、哪里发生最大化、错误如何被纠正。

1. 为什么使用 replay buffer 的 TD3 通常仍不是 offline RL？
因为普通 TD3 会继续用当前或带噪策略与环境交互，把新 transition 加入 buffer。它可以是 off-policy，却仍有在线数据回流；离线 RL 的 behavior dataset 在训练开始前就冻结。
2. 一个动作是 OOD，能否推出它在环境里一定危险或回报低？
不能。OOD 只表示给定状态下行为数据对该动作缺少覆盖，因而当前估值证据不足。它的真实回报可能高也可能低；纯离线训练的问题是无法通过新交互核验。
3. 若 Q 网络在 OOD 区域的误差正负对称，为什么 $\arg\max$ 仍会产生系统性风险？
因为最大化会从许多带噪估值中挑最高者，被选中的动作更可能携带较大的正误差。OOD 区域不确定性更大时，虚高值尤其容易胜出并进入 Bellman target。
4. $\gamma=0.99$ 时“误差约放大 100 倍”应该怎样准确理解？
若多层 backup 持续注入近似同方向、大小为 $\epsilon$ 的误差，几何和是 $\epsilon/(1-\gamma)=100\epsilon$。它是长时域累积的示意，不表示任何单次随机误差都必然精确变成一百倍。
5. CQL 正则中的 logsumexp 与负的数据动作均值分别做什么？
logsumexp 对广泛候选动作形成 soft maximum，最小化它会压低高 Q；减去数据动作的 Q 均值会相对抬住日志动作。两者共同制造数据外与数据内估值的保守 gap。
6. 为什么保守系数并非越大越安全、越好？
过弱会让 OOD 虚高值控制策略；过强则可能把覆盖较少但真实优质的动作也压掉，使策略只能复制 behavior policy。它调节的是改进幅度与证据可信度之间的权衡。
7. Decision Transformer 不使用 $\max Q$，为什么仍可能在离线数据上失败？
它仍只学到 behavior dataset 中状态、目标 RTG 与动作的条件关系。若目标 RTG 超出训练范围，或相应状态附近没有高回报动作轨迹，序列模型仍在做缺少证据的外推。

固定日志训练期间没有新交互$\mathcal D$
→
有限支撑部分状态动作缺少证据OOD
→
价值最大化挑中乐观外推$\max\hat Q$
→
离线修正约束、悲观或序列建模CQL / DT

离线 RL 的困难不是文件不够大，而是策略优化会改变数据分布，却没有新的环境反馈验证改变后的选择。保守估值把证据强度带进优化；序列建模避开 Bellman 最大化，但两者都不能突破固定数据本身的覆盖边界。
