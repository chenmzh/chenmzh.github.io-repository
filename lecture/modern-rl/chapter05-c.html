07DP、MC、TD 不是“慢、中、快”的简单排名

一步更新早，不代表最终一定更快学准；等待更多真实奖励，也不代表每次更新就更可靠。要把计算条件、偏差与方差放在一起看。

常见概括是：MC target 在固定策略下对 $V^\pi$ 的期望没有自举偏差，但方差往往较高；一步 TD target 依赖 $\hat V$，可能有偏，却通常比完整回报波动小。这里的“偏”与“方差”是对采样分布而言，不是说每一条具体 MC target 都接近真值，或每一条 TD target 都一定更稳定。

一个容易漏掉的细节：即使把真值 $V^\pi$ 代入 TD error，随机环境里单次 $\delta_t$ 也不必等于 0。Bellman equation 保证的是在给定 $S_t=s$ 后，按策略与环境取条件期望时 $\mathbb E_\pi[\delta_t\mid S_t=s]=0$。

DP 与 TD 都连接了相邻状态的估计，因此后继状态的信息能沿 transition 回写到当前状态，并继续传向更早前驱；MC 则让完整结果直接监督每个访问位置。更一般的方法可以在“等几步真实奖励以后再自举”之间连续插值，但这条轴线留给后面讨论多步回报和优势估计时再展开。

08从“这个状态值多少”到“这个动作该不该做”

前面一直做策略评价：固定 $\pi$，估计 $V^\pi$。控制问题还要一边评价，一边把策略改得更好。

现在定义 optimal state-value function（最优状态价值函数） 与 optimal action-value function（最优动作价值函数）：

$$V^*(s)=\max_\pi V^\pi(s),\qquad Q^*(s,a)=\max_\pi Q^\pi(s,a)$$

$V^*(s)$ 是从 $s$ 出发能达到的最大期望回报；$Q^*(s,a)$ 则先固定当前动作 $a$，再取后续能够达到的最大期望回报。控制时 $\hat Q(s,a)$ 特别有用，因为不需要另有模型就能直接比较当前动作：

$$\pi_{\mathrm{greedy}}(s)\in\arg\max_a\hat Q(s,a)$$

把 state-value 的一步 TD 更新换成 action-value，只剩一个关键问题：下一状态的尾部，到底接哪个下一动作？

FOLLOW WHAT HAPPENED

接上实际会执行的 $a_{t+1}$

更新目标是 $r_t+\gamma\hat Q(s_{t+1},a_{t+1})$。如果下一步为了探索选了次优动作，这个探索后果也进入当前估计。

FOLLOW THE GREEDY TARGET

09谁下场采数据，谁在更新后变得更好？

“一条 transition 从哪里来”与“更新公式在评价哪套行为”必须分开命名。这样，同一份一步数据为什么会有两种 continuation 才会清楚。

behavior policy（行为策略） $\mu$ 是实际与环境交互、产生 $(s_t,a_t,r_t,s_{t+1})$ 的策略；target policy（目标策略） $\pi$ 是我们希望评价或改进的策略。这里的 target policy 是“一套策略”，不要和前文的 update target（更新目标数值）混为一谈。

DATA$a_t\sim\mu(\cdot\mid s_t)$谁实际走出这条轨迹？
LEARNING$Q^\pi$ 或 $Q^*$这份数据被用来学习谁？

若行为策略和目标策略是同一套，叫 on-policy learning（同策略学习）；若两者不同，叫 off-policy learning（异策略学习）。这组词只回答“数据策略和学习对象是否一致”，不回答数据是不是刚采的。

online learning（在线学习）指训练期间仍可继续与环境交互采新数据；offline learning（离线学习）指只使用已经固定的数据集。它们构成另一条独立的轴：

概念轴问题两个端点
策略关系谁采数据，谁被评价/优化？on-policy / off-policy
采集时机训练期间还能不能继续与环境交互？online（在线）/ offline（离线）

因此 off-policy 不等于 offline。一个在线 agent 可以持续用带探索的 $\mu$ 采新数据，同时学习贪心目标策略；一个固定数据集也可能恰好由要评价的策略自己产生。异策略学习也不表示任意旧数据都够用：若行为数据没有覆盖重要的 state–action pair，更新公式无法凭空补出这些经验。

接实际下一动作：探索后果也进入 continuation

State–Action–Reward–State–Action（SARSA，萨尔萨）是一种同策略时序差分控制算法；它的名字正好列出更新需要的五项。到了 $s_{t+1}$ 后，先按当前行为策略实际选择 $a_{t+1}$，再构造：

$$\begin{aligned} \text{target}_{\mathrm{SARSA}}&=r_t+\gamma\hat Q(s_{t+1},a_{t+1}),\\ \hat Q(s_t,a_t)&\leftarrow\hat Q(s_t,a_t)+\alpha\,[\text{target}_{\mathrm{SARSA}}-\hat Q(s_t,a_t)]. \end{aligned}$$

这里的 $a_{t+1}$ 不是更新时重新算出的贪心动作；在回合继续的正常 transition 中，它就是 agent 接下来真的会执行的动作。若本步仅因时间上限截断，可以从同一策略采样 $a_{t+1}$ 来保留 continuation，但当前 episode 仍须 reset。若当前策略是 $\varepsilon$-greedy，偶尔探索的风险也会进入学到的 $Q^\pi$。

接贪心下一价值：采样动作不决定 continuation

Q-learning（Q 学习）是一种无模型、异策略的时序差分控制算法。它不把某个实际下一动作塞进更新目标，而是直接使用下一状态中最大的动作价值估计：

$$\begin{aligned} \text{target}_{Q}&=r_t+\gamma\max_{a'}\hat Q(s_{t+1},a'),\\ \hat Q(s_t,a_t)&\leftarrow\hat Q(s_t,a_t)+\alpha\,[\text{target}_{Q}-\hat Q(s_t,a_t)]. \end{aligned}$$

行为策略可以继续 $\varepsilon$-greedy 地探索，目标策略却是对当前 $\hat Q$ 贪心的策略，因此这是典型的 off-policy 控制。当 transition 进入真正终止状态时，两式都只保留 $r_t$；截断时则通常仍保留下一状态项。

容易想错

“SARSA 比 Q-learning 多看了一步环境。” 不是。两者都从同一个一步 transition 更新；差别是下一状态的 continuation 接“实际策略选中的动作”，还是接“当前估计下最好的动作”。

Insight 05

on/off-policy 是数据归属关系，不是算法是否实时运行

“online/offline”沿时间轴问还能不能采新数据；“on/off-policy”沿策略轴问采数据的人和被学习的人是不是同一个。

把两条轴分开以后，经验复用、探索策略和固定数据集不再被挤进一个含混的“是不是离线”问题。

10传播奖励更快，不等于奖励写对了

DP、MC、TD 解决“怎样把奖励信息写回价值估计”。它们不会检查这个数字是否忠实表达了真正任务。

同一张网格、同一套动作与转移，只改每步奖励，最优行为就可能改变。先取 $\gamma=1$：

规则每次 transition终点额外奖励8 步路线20 步路线
A · 只奖励成功0+11.001.00
B · 时间有成本−0.01+10.920.80
C · 走路就加分+0.02+11.161.40

表里的路线回报按“8 或 20 次 transition 的逐步奖励，再加终点 bonus”计算。规则 A 的目标干净，但成功前几乎没有学习信号，这叫 sparse reward（稀疏奖励）。规则 B 明确表达“越快越好”。规则 C 看似反馈更密，却鼓励拖延；没有步数限制时，agent 甚至可以绕圈无限加分。

reward design（奖励设计）是在把人的任务意图翻译成每一步的标量奖励；算法真正最大化的是这些奖励累积成的期望回报。增加中间反馈可能缓解 delayed credit assignment（延迟信用分配），也可能悄悄改变任务。学习方法只会忠实传播写下来的 $r_t$；代理奖励与真实目标有缝隙时，优化得更强反而可能更擅长利用缝隙。

Insight 06

学习算法决定信号怎样传播，奖励函数决定传播的究竟是什么

TD 可以让一个有用的终点信号沿 transition 更快回写到前驱状态，也可以让一个错误的代理奖励更快支配行为。算法稳定收敛，并不证明任务定义正确。

调试 RL 时要把两类失败分开：估计没有学准，还是估计准确地学会了一个写错的目标。

上游 4×4 网格世界的实现正是这个骨架：用 $\varepsilon$-greedy 产生动作，保存表格 $\hat Q$，再用 reward + gamma * max(next_q) 更新。它能处理 16 个状态，却暴露了下一章的计算瓶颈：如果状态是图像、连续物理量或长文本上下文，根本列不出这张表。

12检查你的理解：你能从信息条件推出更新式吗？

如果只记住三个缩写，很快会混淆。试着先遮住答案，用“知道什么、等多久、借不借估计”完整回答。

1. DP、MC、TD 都在做什么共同动作？真正不同的是什么？
它们都维护价值估计，并让当前估计沿“更新目标减当前估计”的方向移动。不同的是更新目标的证据来源：DP 用模型枚举并加权全部分支，MC 用已完成轨迹的完整回报，TD 用一步真实奖励加下一状态当前估计。
2. 为什么一次完整的 $G_t$ 仍不能直接等同于 $V^\pi(s)$？
$G_t$ 是一条具体随机轨迹的真实回报，$V^\pi(s)$ 是从 $s$ 出发按 $\pi$ 行动时所有可能轨迹回报的条件期望。需要多次采样平均，单条幸运或倒霉轨迹会偏离期望。
3. 哪些方法自举？自举究竟是什么意思？
DP 与 TD 自举，MC 不自举。自举指用当前价值估计构造另一个价值估计的更新目标：DP 对模型里所有下一状态的旧估计加权，TD 使用实际到达的下一状态估计；MC 等到结局后用完整样本回报。
4. 为什么真实终止与时间上限截断不能都把 continuation 设成 0？
真正终止以后任务没有未来，最后奖励保留而 continuation 为 0；截断只是停止采样，物理或任务过程仍可能继续。若截断也清零，就会把尚未兑现的未来回报错当作不存在。
5. $\delta_t>0$ 能否证明刚才动作“正确”？
不能。正误差只表示这一步更新目标高于当前估计，可能来自正奖励，也可能来自高估的下一状态。它是预测修正信号，不是动作正确性的标签；随机环境中即使价值是真值，单个 TD error 也可能非零。
6. SARSA 与 Q-learning 的一步数据相同，公式边界在哪里？
边界在下一状态的 continuation。SARSA 接策略实际选中的 $a_{t+1}$，所以探索动作的后果进入更新；Q-learning 接 $\max_{a'}\hat Q(s_{t+1},a')$，学习贪心目标策略，而行为策略仍可以探索。
7. off-policy 为什么不等于 offline？
off-policy 比较行为策略与目标策略是否不同；offline 说明训练期间不再从环境采新数据。在线 agent 可以不断用探索策略采新数据，却学习另一个贪心策略，因此同时是 online 与 off-policy。
8. 一个 TD agent 稳定地学会绕圈刷分，应该先查学习率还是奖励？
若它确实在最大化环境给出的累计奖励，绕圈比到终点得分更高，那么核心是奖励错位，而非价值估计失败。先手算不同路线的 return，检查代理奖励是否把“手段”变成了“目的”，再讨论学习率等优化参数。
