Chapter 01 · First contact with RL

让一根杆子站起来：从“预测答案”到“通过行动学习”

你已经学过机器学习导论，所以这一章不从“什么是神经网络”讲起。我们只做一个关键转换：从固定数据集上的预测，走到一个会因为你的动作而改变的世界。

本章核心问题：如果没有老师告诉模型“这一刻应该向左还是向右”，只有杆子最终倒没倒、撑了多久，它怎样学会连续做对几百次决定？
预计阅读 45–70 min 先修：ML 导论 数学：概率 + 向量直觉 实验：纯浏览器 CartPole

01先把你熟悉的机器学习放在桌上

强化学习最容易被讲复杂的地方，是一上来就定义 MDP。我们先看它到底改变了哪条机器学习假设。

监督学习

输入 $x$
→
预测 $\hat y$
  • 训练数据通常先收集好：$\{(x_i,y_i)\}$。
  • 每个样本有比较明确的目标 $y_i$。
  • 一次预测通常不会改变下一条训练样本。
  • 损失函数直接告诉你“错了多少”。

强化学习

状态 $s_t$
→
动作 $a_t$
  • 数据不是先给你的，而是 agent 自己行动产生的。
  • 环境通常不告诉你“正确动作标签”。
  • 今天的动作会改变明天看到的状态。
  • 奖励可能延迟，甚至只有任务最后才知道好坏。

这意味着一个很深的变化：在监督学习里，你大多是在一个固定的数据分布上学习；在 RL 里，你正在学习的策略会改变自己的数据分布。你越喜欢往右走，未来就越常看到“右边的世界”。所以“收集数据”和“更新模型”不再是完全分开的两个阶段。

一个值得记住的反直觉点

RL 不是“监督学习 + 一个叫 reward 的标签”。Reward 通常只评价结果，并不直接给出每一步的正确动作。真正困难的是：从结果反推哪些早期决策值得增加概率，哪些应该减少——这就是后面会不断出现的 credit assignment（信用分配）。

02RL 的最小闭环：观察 → 行动 → 后果

先不要管算法名。只要一个问题能被写成下面这个闭环，我们就已经开始用强化学习的语言思考。

Agent–Environment Loop

一切现代 RL——包括 LLM agent——都可以先从这个循环看。

这里最重要的不是箭头，而是闭环：agent 的动作改变环境，改变后的环境又成为下一次决策的输入。

STATE / OBSERVATION

状态：我现在处在什么局面？

CartPole 用 4 个连续数描述局面：小车位置、速度、杆角度、杆角速度。它们不是“特征工程表格”，而是下一次动作的决策依据。

ACTION

动作：我此刻能改变什么？

动作空间只有两个离散动作：向左施力 $a=0$，或向右施力 $a=1$。没有“不动”，也不能自己选力度。

REWARD

奖励：环境给了什么反馈？

每存活一步得到 $+1$。它没有告诉你“刚才往右是正确答案”，只是说：做完这一步以后，任务还活着。

为什么必须同时知道角度和角速度？

假设两个时刻杆子都向右倾 $5^\circ$。只看截图，它们完全一样；但第一个时刻杆子正在快速向右倒，第二个时刻正在从右侧回正。这两种局面的合理动作可能相反。所以 CartPole 的观测不是一张“静态照片”，它还必须包含运动趋势。

$$s_t = [x_t,\ \dot{x}_t,\ \theta_t,\ \dot{\theta}_t]$$
量直觉为什么有用
$x$小车在哪避免把车推出轨道中心太远
$\dot{x}$小车正往哪跑、多快同一位置，不同速度需要不同制动
$\theta$杆子往哪倾最直接的失衡信号
$\dot{\theta}$杆子正在往哪转、多快告诉你倾倒是在恶化还是恢复

03CartPole 看着简单，真正难在哪？

它只有 4 个观测、2 个动作，却已经包含了强化学习里几乎所有关键麻烦的缩影。

动作有延迟后果

往右推并不会“直接把杆子向左掰”。你先改变小车加速度，再通过转轴改变杆子的动力学。一次动作的影响会延续到后面很多步。

奖励信息非常贫乏

几乎每一步都是 $+1$。一个糟糕动作可能做完以后仍然得到 $+1$，只是它让十几步后的失败更可能发生。

好动作取决于上下文

“杆向右倾就向右推”不是完整规则。角速度、小车速度与位置都会改变判断。策略学习的是条件关系，而不是固定动作。

训练数据由策略自己制造

随机策略大多很快失败，只能看到失败附近的状态；更好的策略活得更久，会进入随机策略几乎见不到的新状态。

和分类问题做个对照

如果这是分类，你可能想收集很多状态，然后标注“左 / 右”。但谁来给这些标签？而且某个动作是否好，常常要看几十步之后才知道。RL 的任务不是拟合一张现成答案表，而是通过交互发现一套能长期获得高回报的决策规则。
