08策略步幅稳住了，优势标签本身仍可能摇摆

PPO 决定“拿到优势后怎样安全更新”，却不会自动让 $\hat A_t$ 变准确。优势估计太短会依赖 Critic，太长会把整条随机未来带回来。

Chapter 08 定义了 advantage function（优势函数）$A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)$：某个动作比当前策略在该状态的平均水平好多少。真实的 $Q^\pi$ 与 $V^\pi$ 不可直接获得，rollout 里只能构造估计。最短的选择是一阶 TD residual（TD 残差）：

$$\delta_t=r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t).$$

这里 $V_\phi$ 是 Critic 的当前估计。若 transition 真正终止，下一状态没有任务内未来，应把 continuation 设为 0；正常 transition 才使用 $V_\phi(s_{t+1})$。$\delta_t$ 只引入一步环境随机性，通常方差较低；但若 Critic 不准，它的误差会直接进入优势。

另一端是等到 episode 结束，计算完整样本回报：

$$\hat A_t^{\mathrm{MC}}=G_t-V_\phi(s_t),\qquad G_t=\sum_{k=0}^{T-t-1}\gamma^k r_{t+k}.$$

它不借用中间状态的 Critic 估计，减少了 bootstrapping（自举）误差，却把从 $t$ 到终点的全部动作与环境随机性都装进一条样本，通常方差更高。

用同一条五步轨迹看两端。取 $\gamma=1$，奖励为 $(0,0,0,0,1)$，Critic 依次预测 $(0.1,0.2,0.3,0.5,0.8)$，终止后的 value 为 0：

短回看 · 更多自举

低轨迹方差，依赖 Critic

若 $V_\phi=V^\pi$，一步残差在条件期望下就能给出正确优势；现实中 Critic 近似误差会造成偏差。

长回看 · 更少自举

少依赖中间 Critic，高轨迹方差

完整 return 使用真实发生的长尾，避免中间 value 误差，却会随每次幸运或倒霉结局大幅波动。

“TD 一定有偏、MC 一定无偏”过于粗糙：偏差还取决于 Critic 是否准确、rollout 是否完整、终止处理与函数近似。更可靠的说法是比较它们依赖哪一类误差源。

09GAE 不是凭空加权：先把每个 n-step advantage 写成 TD 残差和

Generalized Advantage Estimation（GAE，广义优势估计）用 $\lambda$ 连续调节“回看多少步”。它可以从多步自举目标一步步推出。

先定义一个 $n$ 步优势估计：前 $n$ 步使用真实奖励，第 $n$ 步以后用 Critic 收尾，再减去当前状态基线：

$$\hat A_t^{(n)}= \underbrace{\sum_{l=0}^{n-1}\gamma^l r_{t+l}+\gamma^nV_\phi(s_{t+n})}_{n\text{-step target}} -V_\phi(s_t).$$

以 $n=3$ 为例，把三个 TD 残差加起来：

$$\begin{aligned} \delta_t+\gamma\delta_{t+1}+\gamma^2\delta_{t+2} =&\,[r_t+\gamma V_{t+1}-V_t]\\ &+\gamma[r_{t+1}+\gamma V_{t+2}-V_{t+1}]\\ &+\gamma^2[r_{t+2}+\gamma V_{t+3}-V_{t+2}]\\ =&\,r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\gamma^3V_{t+3}-V_t\\ =&\,\hat A_t^{(3)}. \end{aligned}$$

中间的 $+\gamma V_{t+1}$ 与 $-\gamma V_{t+1}$、$+\gamma^2V_{t+2}$ 与 $-\gamma^2V_{t+2}$ 两两抵消。这种首尾保留、中间消去的结构叫 telescoping sum（望远镜求和）。一般地：

$$\hat A_t^{(n)}=\sum_{l=0}^{n-1}\gamma^l\delta_{t+l}.$$

现在让短目标权重大、长目标权重按几何速度衰减。对所有 $n$ 步优势做归一化的 $\lambda$ 加权：

$$\hat A_t^{\mathrm{GAE}(\gamma,\lambda)} =(1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}\hat A_t^{(n)}, \qquad 0\leq\lambda<1.$$

这条归一化无限混合式严格写在 $0\leq\lambda<1$ 上；$\lambda=1$ 是由下面的有限轨迹递推式（也可视作 $\lambda\uparrow1$ 的端点）定义，不能把 1 直接代进 $(1-\lambda)$ 的无限和。对有限 episode，可以把真正终止后的状态看成 value 与后续残差都为 0 的吸收状态；等价地，有限 $\lambda$-return 让最长步目标承接剩余权重，因此理论混合与代码里的终止 mask 并不矛盾。

把 $\hat A_t^{(n)}$ 换成残差和，并收集同一个 $\delta_{t+l}$ 的系数。它会出现在所有 $n\ge l+1$ 的多步估计中：

$$\begin{aligned} \text{coefficient of }\gamma^l\delta_{t+l} &=(1-\lambda)\sum_{n=l+1}^{\infty}\lambda^{n-1}\\ &=(1-\lambda)\lambda^l\sum_{j=0}^{\infty}\lambda^j\\ &=(1-\lambda)\lambda^l\frac{1}{1-\lambda}=\lambda^l. \end{aligned}$$

于是得到熟悉的 GAE 公式：

$$\hat A_t^{\mathrm{GAE}(\gamma,\lambda)} =\sum_{l=0}^{\infty}(\gamma\lambda)^l\delta_{t+l}.$$

这条几何级数还能改写成从后往前的一步递推。令 $m_t=0$ 表示本步后发生真正终止，$m_t=1$ 表示轨迹仍连续：

$$\hat A_t=\delta_t+\gamma\lambda m_t\hat A_{t+1}.$$

它把直接求和的 $O(T^2)$ 计算降为一次反向扫描的 $O(T)$。终止 mask 阻止下一局的优势越过 reset 泄漏回来；若只是采样窗口在非终止状态截断，$\delta_t$ 仍应使用最后状态的 bootstrap value，而不是把物理未来误当成 0。

两个端点与一个容易忽略的条件

$\lambda$GAE 变成什么主要依赖
0$\hat A_t=\delta_t$一步奖励与下一状态 Critic
$0<\lambda<1$按 $(\gamma\lambda)^l$ 聚合多步残差Critic 与实际后续共同决定
1$\sum_l\gamma^l\delta_{t+l}$在真实终止的完整 episode 中望远镜化为 $G_t-V_\phi(s_t)$

只有残差链一直加到真正终止的完整 episode，且终止后的 value 为 0 时，$\lambda=1$ 才望远镜化为样本 Monte Carlo return 减基线：$G_t-V_\phi(s_t)$。若 rollout 在仍可继续的 $s_H$ 截断，正确结果是：

$$\hat A_t^{\lambda=1,\,H} =\sum_{l=0}^{H-t-1}\gamma^l r_{t+l} +\gamma^{H-t}V_\phi(s_H)-V_\phi(s_t).$$

这是“截断的多步回报 + 尾部 Critic bootstrap”，不是已经观察到真实未来的 MC return。保留 $V_\phi(s_H)$ 是为了不把仍存在的未来误当成 0；只有继续采到真正终止，或尾部 value 恰好等于该条轨迹之后实际发生的折扣回报时，两种形式才重合。

回到上一节五步数据，取 $\gamma=1,\lambda=0.5$，从后往前算：

$$\begin{aligned} \hat A_4&=0.2,\\ \hat A_3&=0.3+0.5(0.2)=0.4,\\ \hat A_2&=0.2+0.5(0.4)=0.4,\\ \hat A_1&=0.1+0.5(0.4)=0.3,\\ \hat A_0&=0.1+0.5(0.3)=0.25. \end{aligned}$$

它确实落在一步 TD 的 0.1 与完整轨迹的 0.9 之间。若改成 $\lambda=0.95$，$\hat A_0\approx0.796$，远端残差会更完整地传回起点。

Insight 05

$\gamma$ 决定任务怎样看未来，$\lambda$ 决定估计器怎样使用未来证据

$\gamma$ 是 return 定义的一部分；$\lambda$ 不改环境奖励，也不改优化目标，只改变 TD 残差向前聚合的长度。

把 $\lambda$ 调大不是“让 agent 更重视未来奖励”，而是让优势估计更少依赖短程自举、更多吸收已采到的后续随机结果。

11把公式落到训练循环：先固定标签，再让 Actor 多看几遍同一批数据

上游从零实现的代码把 PPO 拆成四个清晰阶段。真正需要冻结的对象、反向扫描的边界和重新计算的概率都能逐一对应。

01 · COLLECT用当前策略采 rollout保存 states、actions、old_logprobs、values
→
02 · LABEL反向计算 GAE得到固定的 advantages 与 Critic targets
→
03 · UPDATE × K重算 new log-probratio → clamp → minimum
→
04 · REFRESH采下一批新数据当前策略成为新的采样快照

数据复用发生在同一 rollout 的有限个 update epoch 内；一轮结束后重新采样，避免无限使用越来越失真的旧状态分布。

# rollout labels: compute once, backwards
gae = 0.0
for t in reversed(range(T)):
    delta = rewards[t] + gamma * next_values[t] - values[t]
    continuation = 0.0 if episode_ends[t] else 1.0
    gae = delta + gamma * lam * continuation * gae
    advantages[t] = gae
returns = advantages + values

# actor update: recompute under the changing policy
new_logprobs, new_values, entropy = model.evaluate(states, actions)
ratio = exp(new_logprobs - old_logprobs)
raw = ratio * advantages
clipped = clamp(ratio, 1 - eps, 1 + eps) * advantages
policy_loss = -minimum(raw, clipped).mean()

value_loss = mse(new_values, returns)
loss = policy_loss + vf_coef * value_loss - ent_coef * entropy.mean()
数学对象上游代码变量关键合同
$\log\pi_{\mathrm{old}}(a_t\mid s_t)$old_logprobs采样时记录，更新阶段不回传梯度
$\log\pi_\theta(a_t\mid s_t)$new_logprobs每个 mini-batch update 都用当前参数重算
$\rho_t$torch.exp(new_logprobs - old_logprobs)同一状态、同一已采动作的新旧概率比
$\delta_t$rewards[t] + gamma * next_values[t] - values[t]真正终止时 next_values[t] = 0
$\hat A_t$gae, advantages从后向前；不能跨 episode reset 传播
$L^{\mathrm{CLIP}}$minimum(raw, clipped)最大化目标在 loss 中取负号
更新过猛指标clip_fraction, approximate KL裁剪是软限制，仍应监控整体偏移

实现里常用 $\hat A_i'=(\hat A_i-\bar A)/(s_A+\varepsilon)$ 把 batch 内优势重新中心化并缩放，以稳定梯度尺度。它保留样本之间的排序，但减去 batch 均值可能改变个别样本相对 0 的符号；标准化后的正负表示“高于或低于本批平均优势”，PPO 裁剪方向由实际送入 Actor loss 的最终 advantage 标签决定。价值损失训练 Critic，熵项避免策略过早塌成近乎确定的动作。它们与裁剪目标共同组成实用 PPO，不能把 Actor 的一条 clip 公式误当作完整训练程序。

PPO 的能力边界

PPO 通常在每批有限复用后仍要重新与环境交互，不能像经验回放那样长期复用任意历史数据；裁剪也不提供严格单调改进保证。它让 Actor–Critic 更易稳定训练，却没有解决连续动作怎样参数化、真实交互为何昂贵、怎样借模型生成额外经验。下一章从这些剩余问题出发。

12检查你的理解：能否把“数据来源、更新距离、优势长度”分成三条轴？

PPO 最容易被背成一个 clip 函数。先遮住答案，试着从问题条件重新推出每个对象的职责。

1. $\pi_{\mathrm{old}}$ 为什么必须冻结？它什么时候刷新？
它表示当前 rollout 的真实采样分布，给概率比提供固定分母。若分母也随梯度改变，比率就无法衡量相对采样时的变化。本批有限个 update epoch 结束并重新采样时，当前策略成为下一批的 old policy。它不是训练全程不变的模型。
2. 为什么 $\rho_t=2$ 不等于“整个新策略是旧策略的两倍”？
$\rho_t$ 只比较同一个状态 $s_t$ 上、同一个已采动作 $a_t$ 的新旧概率。完整策略还包含该状态其他动作以及其他所有状态的动作分布；整体差异需用 KL 等分布级量观察。
3. 代理目标为什么只是一张局部地图？
它冻结旧策略访问的状态和旧 rollout 上估计的优势，在旧参数点的梯度与策略梯度一致。但策略走远后，新的状态访问分布和未来动作会改变，旧数据不再完整代表新策略的行为后果。
4. TRPO 与 PPO-Clip 分别怎样表达“不要更新太远”？
TRPO 对旧状态上的平均 KL 设置显式约束，并求解约束优化；PPO-Clip 不直接解二阶约束，而是让样本概率比沿优势有利方向越过 $1\pm\epsilon$ 后不再获得额外代理收益。
5. 若 $\hat A_t<0$ 且 $\rho_t=0.7$、$\epsilon=0.2$，为什么 min 选择裁剪项？
未裁剪项是 $0.7\hat A_t$，裁剪项是 $0.8\hat A_t$。因为优势为负，乘法会反转大小关系，所以 $0.8\hat A_t$ 更小。最大化目标时它在下界外成为常数，不再奖励继续降低坏动作概率。
6. PPO 的 clip 能否保证每个 ratio 都在区间内，或保证 KL 小于固定阈值？
不能。它裁剪的是代理目标的收益，不是把网络输出硬投影回区间。共享参数更新还会联动许多状态与动作，因此仍需监控 clip fraction、近似 KL，必要时减小学习率或提前停止。
7. 怎样从三步 TD 残差推出三步 advantage？
把 $\delta_t+\gamma\delta_{t+1}+\gamma^2\delta_{t+2}$ 展开后，中间的 $V(s_{t+1})$ 与 $V(s_{t+2})$ 正负抵消，只剩三步真实奖励、$\gamma^3V(s_{t+3})$ 和 $-V(s_t)$，正好是三步自举 target 减当前 value。
8. $\gamma$ 与 $\lambda$ 都出现在 $(\gamma\lambda)^l$，为什么不能互换？
$\gamma$ 定义任务回报中未来奖励的权重，改变它会改变优化问题；$\lambda$ 只控制优势估计聚合多少步 TD 残差，改变的是对 Critic 偏差与轨迹方差的取舍。$\lambda=1$ 在完整、真正终止的 episode 中变成 MC return 减基线；在非终止 rollout 截断处则是带尾部 Critic bootstrap 的截断回报，不能叫作已经观察到真实未来的 MC。

第九章建立起来的三层稳定性

数据层冻结采样时的 old policy知道经验从哪里来
→
更新层ratio + KL / clip限制旧数据被信到多远
→
估计层GAE 的 $\lambda$ 递推平衡 Critic 误差与轨迹噪声

重要性采样让旧 rollout 能服务于附近的新策略；TRPO 用分布级 KL 定义信任域，PPO 用方向性的裁剪代理目标换取一阶优化的简洁；GAE 再决定优势标签从多长的未来中吸收证据。三者解决的是不同层面的不稳定，不能互相替代。
