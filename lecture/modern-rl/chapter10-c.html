07复用真实经验还不够：能否学习一台环境模拟器？

DDPG、TD3 与 SAC 都是 model-free reinforcement learning（无模型强化学习）：它们学习价值或策略，却不显式训练一个“给定状态与动作，下一步会发生什么”的预测器。

model-based reinforcement learning（基于模型的强化学习）显式学习近似环境：

$$\hat p_\psi(s_{t+1},r_t\mid s_t,a_t).$$

$\psi$ 是模型参数，帽子表示它只是对真实环境 $p$ 的近似。模型可以直接预测下一状态与奖励，也可以在 latent state（隐状态）中预测与决策相关的未来。本文把这种学习环境动力学、供预测、规划或想象训练使用的模型称为 world model（世界模型）。

REAL DATA

少量真实 transition

真实环境提供 $(s_t,a_t,r_t,s_{t+1})$，既训练世界模型，也校正它没见过的新区域。

→
LEARNED DYNAMICS

$\hat p_\psi(s',r\mid s,a)$

学习动作如何改变状态以及会产生什么奖励；模型质量决定想象数据有多可信。

→
USE THE MODEL

生成、规划或想象

生成短轨迹训练策略，比较候选动作序列，或在隐空间中训练 Actor–Critic。

样本效率提升来自中间这一层：一次真实 transition 不只更新策略，还改进可重复调用的动力学模型；代价是后续学习开始依赖模型是否说真话。

世界模型有三种常见用法

规划路线的典型方法包括 Probabilistic Ensembles with Trajectory Sampling（PETS，概率集成轨迹采样）与 Model Predictive Control（MPC，模型预测控制）：前者用多个概率模型表达预测分歧，后者每次比较未来动作序列、只执行第一步后重新规划。

用法模型在循环里做什么代表思路主要代价
数据增强从真实状态出发生成短 rollout，再训练策略Dyna、短程模型 rollout模型偏差会污染训练数据
在线规划预测多条动作序列，只执行第一步后重新规划PETS、MPC每个真实动作前要做大量模型计算
隐空间想象编码历史，在 learned latent dynamics 内训练 Actor–CriticDreamer表示、动力学与价值必须共同稳定

三行共享同一个学习动力学，却把模型放在不同位置：作为数据生成器、决策时规划器或策略训练场。不要把“有世界模型”误等同于“部署时一定搜索”。

模型通常先最小化一步预测误差。以确定性下一状态模型为例：

$$\mathcal L_{\mathrm{dyn}}(\psi)= \mathbb E_{(s,a,r,s')\sim\mathcal D}\left[ \|\hat f_\psi(s,a)-s'\|_2^2 +\lambda\big(\hat r_\psi(s,a)-r\big)^2 \right].$$

第一项训练动力学 $\hat f_\psi$，第二项训练奖励预测；$\lambda$ 平衡两个尺度。但“一步平均误差小”不保证“策略会信任的多步区域也准确”。策略会主动寻找模型里看起来高回报的位置，甚至可能利用模型尚未学好的漏洞。

Insight 05

世界模型把真实样本成本换成了模型偏差与计算成本

模型能反复生成预测，真实环境不必为每次策略更新都重新付费；但策略训练开始依赖一个会犯错的代理世界。

Model-based 不是免费制造真经验，而是购买一台便宜模拟器，并为它设置可验证的使用边界。

08单步只错一点，反复把预测喂回模型会怎样？

世界模型最危险的地方不是一次预测明显错误，而是每次都只偏一点、长 rollout 却逐步离开真实轨迹。

先隔离一个最小问题：预先固定同一条动作序列 $(a_0,\ldots,a_{H-1})$，让真实轨迹和模型轨迹在第 $h$ 步都使用同一个 $a_h$，只分析模型状态误差怎样累积。设真实确定性动力学为 $s_{h+1}=f(s_h,a_h)$，模型为 $\hat s_{h+1}=\hat f(\hat s_h,a_h)$。假设模型在相关区域的单步误差至多为 $\epsilon$：

$$\|\hat f(x,a)-f(x,a)\|\le\epsilon,$$

并假设真实动力学对状态满足 Lipschitz 条件：

$$\|f(x,a)-f(y,a)\|\le L\|x-y\|.$$

记第 $h$ 步状态误差 $e_h=\|\hat s_h-s_h\|$。插入并减去 $f(\hat s_h,a_h)$，再用三角不等式：

$$\begin{aligned} e_{h+1} &=\|\hat f(\hat s_h,a_h)-f(s_h,a_h)\|\\ &\le \underbrace{\|\hat f(\hat s_h,a_h)-f(\hat s_h,a_h)\|}_{\le\epsilon} +\underbrace{\|f(\hat s_h,a_h)-f(s_h,a_h)\|}_{\le Le_h}\\ &\le\epsilon+Le_h. \end{aligned}$$

若 rollout 从真实状态开始，$e_0=0$。逐步展开：

$$e_H\le\epsilon\sum_{i=0}^{H-1}L^i =\begin{cases} H\epsilon,&L=1,\\[4pt] \epsilon\dfrac{L^H-1}{L-1},&L\ne1. \end{cases}$$

这个上界不是一般闭环策略 rollout 的保证。若真实轨迹用 $a_h=\pi(s_h)$、模型轨迹用 $\hat a_h=\pi(\hat s_h)$，状态一旦偏离，动作也可能偏离；递推还需加入动力学对动作的敏感度，并对策略的平滑性或稳定性作额外假设。没有这些条件时，闭环误差可能比下面的固定动作序列诊断增长得更快。

取 $\epsilon=0.01,L=1.1$，上界随想象长度变化：

rollout horizon $H$误差上界相对单步误差该怎样读
10.01001.0×只承担一次模型误差
50.06116.1×短 rollout 尚可能可控
100.159415.9×误差开始明显放大
200.572757.3×预测状态可能显著漂移
5011.63911163.9×上界已失去实用精度

在真实轨迹与模型轨迹共用同一条预定动作序列的前提下，真正要观察的是 horizon 的因果作用：单步误差 $\epsilon$ 没变，只因预测状态被再次当作输入，$L>1$ 时误差上界就从近似线性增长转向快速放大；闭环策略还会多出动作偏差。

这解释了 Model-Based Policy Optimization（MBPO，基于模型的策略优化） 为什么偏爱短 rollout：从 replay 中的真实状态起步，只想象少数几步，就把模型生成的 transition 交给 SAC 等异策略算法。horizon 不是越长越好；它是一笔“对模型连续相信多少步”的预算。模型早期不准时可取 1，模型改善后再逐渐增加。

容易想错

“一步验证集误差很小，所以模型可以无限 rollout。” 不对。训练指标衡量常见输入上的一步平均误差；多步预测会改变自己的输入分布，并把早先偏差带入后续状态。必须单独验证多步 rollout 与策略实际访问区域。

短模型 rollout 的概念代码

# 真实数据只负责落脚和校正模型
real_buffer.add(state, action, reward, next_state, terminated)
world_model.fit(real_buffer.sample())

# 每段想象都从真实访问过的状态起步
sim_state = real_buffer.sample_state()
for _ in range(short_horizon):
    sim_action = policy.sample(sim_state)
    sim_next, sim_reward, sim_terminal = world_model.predict(
        sim_state, sim_action
    )
    model_buffer.add(
        sim_state, sim_action, sim_reward, sim_next, sim_terminal
    )
    if sim_terminal:
        break
    sim_state = sim_next

# 策略使用真实与短程想象的混合 batch
policy.update(mix(real_buffer, model_buffer))

注意循环里保存的是更新前的 sim_state 与模型返回的 sim_next，然后才推进状态；每段从真实 buffer 状态重新开始。代码没有把想象 transition 冒充真实观测，两个 buffer 的来源必须可追踪。

10检查你的理解：你能指出每个稳定性结构在防什么吗？

先遮住答案。不要只报算法名，要沿“动作怎么产生、target 怎么构造、真实数据怎么使用、误差会在哪里反馈”来解释。

1. 连续动作为什么不能直接照搬 DQN 的输出层与逐项 $\arg\max$？
DQN 为每个有限动作输出一个 Q 值，能逐项比较；连续动作有无穷多个候选，多维时组合数更快爆炸。连续控制通常让 Critic 接收 $(s,a)$ 给标量，再训练 Actor 直接从 $s$ 产生可微动作。
2. “随机策略”是否意味着 on-policy？请给出本章反例。
不意味着。随机/确定描述策略输出，on/off-policy 描述行为数据与优化目标的关系。SAC 学随机策略，却从 replay buffer 复用旧策略产生的数据，因此是 off-policy。
3. DDPG 的 Actor 为什么能从标量 $Q(s,a)$ 得到参数更新方向？
链式法则把 Critic 对动作的斜率 $\nabla_aQ$ 与 Actor 输出对参数的 Jacobian $\nabla_\theta\mu_\theta(s)$ 相乘。前者说动作往哪边价值增加，后者说怎样改参数才能让动作往那边移动。
4. TD3 的三个修正分别改变了哪里？
Twin critics 在 target 数值上取较小估计，policy delay 降低 Actor 跟随 Critic 的频率，target policy smoothing 在目标动作附近加截断噪声、压平孤立 Q 尖峰。三者共同削弱错误乐观的正反馈。
5. SAC target 中为什么是 $-\alpha\log\pi(a'\mid s')$？
熵满足 $\mathcal H(\pi)=\mathbb E[-\log\pi]$。最大熵目标在奖励外加入 $\alpha\mathcal H$，因此单个采样动作对 soft continuation 的贡献写成 $-\alpha\log\pi(a'\mid s')$。
6. 世界模型一步误差只有 0.01，为什么 50 步想象仍可能失效？
即使真实轨迹和模型轨迹共用同一条预定动作序列，每一步把预测状态再次送入模型时，早先误差仍会先被动力学敏感度 $L$ 放大，再叠加新误差；本章 $L=1.1$ 的固定动作例中，50 步上界约为 11.64。闭环策略还会因状态偏差选出不同动作；没有额外平滑性假设时，这个上界不能直接套用，实际误差可能增长得更快。
7. World model 与部署时搜索是否是同一件事？
不是。学习动力学是共同基础，但模型可作短 rollout 数据生成器、在线规划器或隐空间训练场。MBPO 训练后可直接运行策略；PETS 则在每个真实动作前用模型规划。模型放在决策循环的哪里决定部署成本。

动作不可枚举Actor 直接产生连续动作DDPG
→
Critic 会高估min + delay + smoothingTD3
→

第一条效率来自不再枚举动作并复用旧经验；第二条效率来自让一次真实经验同时训练环境模型，再在可信的短 horizon 内重复使用这个模型。前者受价值估计误差约束，后者还额外受模型误差约束。
