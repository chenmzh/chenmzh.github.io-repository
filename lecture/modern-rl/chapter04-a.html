Chapter 04 · Value compresses possible futures

怎样给未来的局面定价？

上一章把交互拆成 state、action、transition、reward 与 return。可一到真正决策，未来会不断分叉：策略可能选不同动作，环境也可能给不同结果。我们需要一种办法，把整棵未来树压缩成现在可以比较的数字。

本章核心问题：如果两步动作眼前拿到同样的奖励，我们怎样判断哪一个把 agent 带到了更有希望的未来？又怎样不枚举所有完整轨迹，就让未来的好坏反过来影响当前判断？

01眼前同样拿到 0 分，为什么两个动作不该同价？

即时奖励只汇报刚刚发生的一步；动作还会改变下一状态，而下一状态决定后面还有哪些机会。

想象机器人站在岔路口。向左和向右的第一步都得到 $r_t=0$，但左路把它带到离充电站一步的状态，右路把它带到电量将尽、还要绕远路的状态。若只按眼前奖励打分，两步完全一样；若继续看未来，它们显然不同。

ACTION LEFT

眼前 $r_t=0$

岔路口→充电站附近→未来 +8

第一步没有奖励，但它保留了高价值的未来。

ACTION RIGHT

眼前 $r_t=0$

岔路口→低电量远路→未来 −3

第一步同样没有奖励，却进入了更差的后续局面。

真正要比较的不是两张卡片里相同的 $r_t=0$，而是这一步之后还保留了哪些获得未来奖励的机会。

Chapter 03 已经用 return（回报）$G_t$ 把一条轨迹后面的奖励合在一起：

$$G_t=r_t+\gamma r_{t+1}+\gamma^2r_{t+2}+\cdots$$

所以问题并不是“未来要不要算”——$G_t$ 已经把它算进去了。真正的新困难是：做决定时，未来轨迹还没有发生，而且可能有很多条。 我们缺少的是行动之前对这些可能未来的平均评价。

Insight 01

Reward 是局部反馈；value 是把后续机会压回当前

奖励只评价一次 transition。Value 要做的是把这个 transition 改变的所有后续机会，浓缩成当前 state 或 action 的长期分数。

价值并没有替代 reward；它是沿转移关系，把未来 reward 的影响回写到更早状态。

02$G_t$ 是一次成绩单，value 是开跑前的平均预测

一条实际轨迹只有一个回报；同一个状态在固定策略下却可能通向许多轨迹，因此需要对可能的回报取期望。

expected return（期望回报）就是在起点与后续策略固定后，对所有可能轨迹的 $G_t$ 按发生概率求平均。仍从同一个状态 $s$ 出发，仍按同一策略 $\pi$ 行动。第一次的三步奖励可能是 $(2,4,6)$，第二次可能是 $(2,1,-3)$。取 $\gamma=0.9$：

TRAJECTORY A rewards = [2, 4, 6] $G_t^{(A)}=2+0.9(4)+0.9^2(6)=10.46$
TRAJECTORY B rewards = [2, 1, −3] $G_t^{(B)}=2+0.9(1)+0.9^2(-3)=0.47$

两次的第一步奖励都是 2，整条轨迹的回报却相差很大。如果在策略 $\pi$ 下，A 类未来出现的概率是 60%，B 类未来出现的概率是 40%，那么行动前的平均前景是：

$$0.6\times10.46+0.4\times0.47=6.464$$
量什么时候知道它评价什么
$r_t$执行 $a_t$、环境推进一步后这一次 transition 的即时反馈
$G_t$这条未来轨迹展开以后一次实际结果的折扣总回报
value行动之前也希望估计固定条件下，所有可能 $G_t$ 的期望
容易想错

“把一条轨迹的 $G_t$ 算出来，就得到了状态价值。” 一条 $G_t$ 只是一次样本。Value 是在相同起点和相同后续策略下，对可能轨迹的回报取期望；随机策略或随机环境都会让一次结果偏离这个平均值。

03先固定策略，再问一个状态值多少

状态并不天然携带一个唯一分数。同一个局面交给不同策略，未来动作不同，轨迹分布也不同。

state-value function（状态价值函数）记作 $V^\pi(s)$：从状态 $s$ 出发，之后一直按照策略 $\pi$ 行动时，未来回报的期望。

$$V^\pi(s)=\mathbb{E}_\pi\left[G_t\mid S_t=s\right]$$
符号准确含义不要误读成
$S_t=s$现在已经确定站在状态 $s$对所有起点一起平均
$G_t$从现在开始的一条未来轨迹回报只有眼前的 $r_t$
$\mathbb{E}_\pi$对策略选择与环境转移造成的所有可能未来取期望沿一条“最可能”轨迹计算
上标 $\pi$后续动作由哪条固定策略生成状态与生俱来的属性
同一个 CartPole 状态$s=[0, 0, 0.08, 0.15]$
策略 $\pi_{\text{稳}}$及时纠偏 → 较高 $V^{\pi_{\text{稳}}}(s)$
策略 $\pi_{\text{乱}}$随机推车 → 较低 $V^{\pi_{\text{乱}}}(s)$

状态向量完全相同，只有接手它的策略不同；因此价值变化来自后续行为分布，而不是物理状态本身变了。

$V^\pi$ 因而不是“这个状态客观有几分”，而是这条策略从这个状态接手以后平均表现怎样。说“状态 $s$ 的价值”时，如果策略没有由上下文固定，问题其实还没说完整。

Insight 02

Value 评价的是 state 与 policy 的组合

环境决定动作会导致什么，策略决定接下来会做什么。换策略会改变未来轨迹的分布，即使起点 state 完全没变，价值也会变。

上标 $\pi$ 不是装饰：它提醒我们“谁来继续行动”是价值定义的一部分。
