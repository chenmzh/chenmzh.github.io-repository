09层级决策：让高层选择“做什么”，让低层负责“每一步怎么做”

Hierarchical Reinforcement Learning（HRL，层级强化学习）在多个时间尺度上决策。低层仍输出原子动作；高层每隔一段时间选择子目标或时间扩展动作，从而减少高层需要直接比较的决策节点。

想象 DoorKey 需要 120 个原子动作。Flat policy（平坦策略）每一步都在“左转、右转、前进、拿取、开门”之间选择；层级策略可以先选择“找到钥匙”，让低层连续执行 30 步，再选择“去门口”。层级不是让物理时间消失，而是改变哪一层多久做一次决定。

FLAT POLICY · 每步决策

转向 → 前进 → 前进 → 拿取 → 转向 → ……

HIERARCHICAL POLICY · 一段才决策
找到钥匙走到门口打开门到达目标

每个高层选择在内部展开为若干原子动作。

真正要比较的是高层的选择次数：原子时间仍然逐步流逝，奖励仍按实际经过的 primitive steps 折扣；被压缩的是高层决策树的深度。

把一段闭环策略封装成时间扩展动作

Option（时间扩展动作）不是固定动作序列，而是一段能根据中途状态继续反应的策略。一个 option $\omega$ 由三部分组成：

$$\omega=\left(\mathcal I_\omega,\pi_\omega,\beta_\omega\right)$$
组成准确含义“拿到钥匙” option
$\mathcal I_\omega$initiation set（初始集）：允许启动 option 的状态还没拿钥匙，且钥匙可达
$\pi_\omega(a\mid s)$intra-option policy（option 内策略）：执行期间怎样选原子动作根据当前位置持续导航与拿取
$\beta_\omega(s)\in[0,1]$termination function（终止函数）：到状态 $s$ 后结束的概率拿到钥匙后接近 1；失败或超时也可终止

设 option 实际执行了 $T$ 步，期间奖励为 $r_t,\ldots,r_{t+T-1}$。先把这段真实奖励折扣相加：

$$R_t^\omega=\sum_{k=0}^{T-1}\gamma^k r_{t+k}$$

若在 option 层做最优控制，Semi-Markov Decision Process（SMDP，半马尔可夫决策过程）的 backup 是：

$$\text{target}_\omega=R_t^\omega+\gamma^T(1-d_{t+T})\max_{\omega'}Q(s_{t+T},\omega')$$

“半马尔可夫”在这里最直观的含义是：一次高层 transition 可能持续随机的 $T$ 步。因为下一次高层决策发生在 $T$ 个原子步以后，后续 option 价值必须乘 $\gamma^T$，不能只乘一次 $\gamma$。其中 $d_{t+T}=1$ 只表示环境真正终止；option 自己结束并不清空后续价值，外部时间上限造成的截断若保留合法最终观测，也仍可 bootstrap。

一段三步 option 的 target

取 $\gamma=0.9$，某 option 连续三步奖励为 $(0,0,5)$；它在第三步正常结束，但整个 episode 仍继续，下一状态的最佳 option 价值是 2：

$$\begin{aligned} \text{target}_\omega &=0+0.9(0)+0.9^2(5)+0.9^3(2)\\ &=4.05+1.458=5.508. \end{aligned}$$

最后一步得到的 5 已经离 option 起点两步，因此乘 $\gamma^2$；option 结束后的价值离起点三步，因此乘 $\gamma^3$。时间抽象改变动作单位，没有重写折扣的物理时钟。

容易想错

“一个 option 算一个动作，所以不管内部走多久都只折扣一次。” 不对。高层选择次数变少，不代表奖励更早到达；SMDP backup 必须按 option 实际持续的 primitive steps 使用 $\gamma^T$。

Insight 05

Option 压缩决策，不压缩时间

层级可以让高层只在有语义的边界选择“拿钥匙”或“开门”，从而缩短高层的决策链；内部实际经过多少步，仍完整进入奖励与折扣。

判断 HRL 是否有帮助，要看 option 是否稳定到达有用边界，而不是只看高层动作数变少。

10实验：时间抽象究竟压缩了什么，又没有压缩什么？

把总任务长度记为 $H$，固定 option 持续时间记为 $T$。比较高层决策数、正确的 primitive-time 折扣，以及“每个 option 只折扣一次”的错误算法。

Question
增大 option 持续时间，为什么会减少高层决策数，却不应让远端奖励变得更少折扣？
Prediction
高层决策数约从 $H$ 降到 $\lceil H/T\rceil$；正确终点权重仍为 $\gamma^H$，只有错误算法才变成 $\gamma^{\lceil H/T\rceil}$。
Experiment
调节任务长度 $H$、option 时长 $T$ 和折扣 $\gamma$，并排比较三个量。
Observation
页面显示决策压缩倍数、正确终点权重和错误权重；默认设置下，两种折扣相差很大。
Interpretation
HRL 的结构收益来自更少、更有语义的高层选择；SMDP 仍按真实 elapsed time 计算回报。
Limitation
真实 option 时长通常随机，且失败、提前终止与不可达子目标会降低层级收益；这里仅展示固定时长。
FLAT DECISIONS120每个原子步一次
HIGH-LEVEL DECISIONS12压缩 10.0×
CORRECT · $\gamma^H$0.299按真实原子时间
WRONG · $\gamma^{\lceil H/T\rceil}$0.886误把 option 当一瞬间

高层选择减少 10.0×，但正确终点权重仍是 0.299；若每个 option 只折扣一次，会错误放大到 0.886。

真正要观察的是两条曲线没有一起“被压缩”：决策节点按 option 数减少，终点奖励仍按 $H$ 个 primitive steps 折扣。

11把三种结构落到代码：bonus、counterfactual 与 duration

三种方法都可以写成很短的计算，但各自修改的是不同对象：训练奖励、个体学习信号、或高层 transition。

import math

def exploration_reward(ext_reward, visits, eta):
    novelty = 1.0 / math.sqrt(visits + 1)
    return ext_reward + eta * novelty

def difference_reward(team_return, counterfactual_return):
    return team_return - counterfactual_return

def option_target(rewards, gamma, next_option_value, episode_terminated):
    duration = len(rewards)
    option_return = sum(
        gamma ** k * reward for k, reward in enumerate(rewards)
    )
    continuation = 0.0 if episode_terminated else next_option_value
    return option_return + gamma ** duration * continuation

$r_t^{\text{int}}=1/\sqrt{N+1}$novelty探索模块产生的临时训练信号
$\eta$eta外部目标与探索奖金的权衡
$R_{\text{team}}(z^{-i})$counterfactual_return个体信用的 baseline
$T$duration高层一次 transition 经历的原子步数
$R_t^\omega$option_returnoption 内部奖励的逐步折扣和
$d_{t+T}$episode_terminated只在环境真正终止时清空后续价值

12检查你的理解：你改的是奖励、信息，还是时间尺度？

三种扩展最容易被混成一袋“高级技巧”。每题都先定位结构断点，再说明公式为什么放在那里。

观察到的失败优先检查不要过早下结论
所有 rollout 外部奖励都为 0状态覆盖率、新颖度与成功轨迹密度“critic 太小”
团队分上升，但只有一名 agent 在做事个体轨迹、角色行为与 credit baseline“团队已经协作”

1. 为什么稀疏奖励不等同于奖励数值很小？
数值小可以通过缩放处理；稀疏奖励的关键是绝大多数 transition 得到相同、缺乏区分度的反馈。第一条成功轨迹出现以前，策略甚至不知道向哪个方向改变采样。
2. 若 $\eta=0.4$、外部奖励为 0、新状态过去访问 3 次，训练奖励是多少？
访问奖金是 $1/\sqrt{3+1}=0.5$，所以 $r^{\text{train}}=0+0.4(0.5)=0.2$。这只是训练信号，不应当被报告成环境任务得分。
3. 为什么其他 agent 学习会让单个 agent 看到非平稳环境？
agent $i$ 的有效转移要对其他人的联合动作按其策略概率求和。队友或对手的策略更新后，即使底层环境动力学 $P$ 不变，同一 $(s,a_i)$ 的结果分布也会变化。
4. 团队回报为 12，没有 agent B 时团队仍得 9，B 的 difference reward 是多少？它说明什么？
$D_B=12-9=3$。在所选反事实 baseline 下，B 的实际行为使团队回报提高了 3；它不是说 B 独占 3 分，也不保证所有 agent 的 difference reward 加起来等于 12。
5. CTDE 中，为什么集中式 critic 能看联合动作，而部署 actor 不应该看？
训练阶段可以汇总全局日志来降低歧义；部署时每名 agent 可能只有局部观察，也未必能通信。critic 只构造训练信号，actor 必须遵守实际执行的信息边界。
6. 一个 option 执行 4 步后才结束，为什么后续价值乘 $\gamma^4$ 而不是 $\gamma$？
后续 option 价值相对当前高层决策已经过去 4 个原子时间步。Option 压缩高层选择次数，不压缩真实 elapsed time；SMDP backup 因而使用 $\gamma^T$。
7. 什么时候层级结构可能反而伤害学习？
如果 initiation set 不合理、低层无法可靠完成子目标、termination 太早或太晚，或任务本来就很短，option 会限制可选行为并引入额外训练误差。应检查 option 成功率和高层边界是否真的有语义。
