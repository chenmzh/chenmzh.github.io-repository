Chapter 13 · When feedback, agency, and time stop being simple

奖励稀疏、多个 agent、任务很长时，问题结构怎样改变？

上一章说明，示范可以替代一部分试错，任务族可以让 agent 学会更快适应。但示范不一定覆盖未知区域，现实任务也常常不再是“一个 agent、每步有分、几十步结束”。本章把三个假设依次拿掉：奖励可能很久不出现，其他 agent 也在改变世界，一次有意义的决定可能持续很多步。

本章核心问题：当“没有反馈”“不知道该奖励谁”“奖励离动作太远”同时出现时，我们应分别修改奖励信号、训练信息和动作时间尺度中的哪一层？

01不是再换一个优化器：是原问题的三个结构假设失效了

先诊断信号断在哪里。三种困难都会表现成“学不动”，但补错位置，往往只是让 agent 更快地学会无关行为。

FEEDBACK

奖励很久才出现

钥匙、门、终点相隔上百步；随机策略几乎采不到成功轨迹。问题首先是发现，不是更新公式算得慢。

修改层：探索信号
AGENCY

多个策略同时行动

同一时刻的后果取决于联合动作；队友还会边训练边变化。问题首先是谁造成了结果。

修改层：训练信息与信用
TIME

一次任务横跨很长时间

“拿钥匙”被拆成几十次转向和移动，最终奖励离早期选择太远。问题首先是决策粒度。

修改层：动作时间尺度

真正要观察的是三种断点的位置：没有可学习信号、信号无法归因、信号跨越太多原子决策。它们对应不同结构，不能用同一个“加大模型”回答。

后面会用同一个 DoorKey 小任务贯穿本章：一个 agent 要先探索房间、拿到钥匙，再与队友配合开门，最后走到目标。外部环境只在成功时给高奖励。这个小故事同时包含稀疏反馈、联合行为和长程顺序。

02稀疏奖励真正可怕的地方：第一次成功以前，失败轨迹长得都一样

Sparse reward（稀疏奖励）不是“奖励数值小”，而是大多数 transition 都返回同样的无信息反馈。即使价值更新完全正确，也没有证据告诉策略应该向哪里改变。

假设到达目标至少要连续做对 $H$ 个关键选择，每个位置有 $m$ 个看起来同样可能的动作。把各步粗略看成独立且均匀，随机撞出成功路径的概率是：

$$p_{\text{success}}\approx\left(\frac{1}{m}\right)^H$$

例如每个关键点有 4 个动作、连续 20 次都要选对：

$$p_{\text{success}}\approx4^{-20}\approx9.1\times10^{-13}$$

这不是环境的精确成功率，而是一个诊断量级：搜索深度进入指数项后，仅靠无方向的随机动作很难先得到第一条正回报轨迹。Chapter 12 的示范能把 agent 带到已覆盖区域，但当测试迷宫、钥匙位置或可行路线变化时，策略仍需要主动收集新证据。

Insight 01

稀疏奖励首先是数据发现问题，其次才是价值传播问题

TD、GAE 或更大的网络可以更有效地利用已经见过的奖励，却不能从全零轨迹里推断出从未访问过的成功区域。

先问 replay 或 rollout 里有没有成功证据；没有时，需要改变采样分布，而不是只调学习率。

03Intrinsic motivation：在外部奖励到来前，为“获得新信息”付临时工资

Intrinsic motivation（内在动机）把新颖、难预测或尚未掌握的状态变成 intrinsic reward（内在奖励），引导策略访问更有信息量的区域；环境定义的任务分数则叫 extrinsic reward（外部奖励）。

训练时最简单的组合是：

$$r_t^{\text{train}}=r_t^{\text{ext}}+\eta\,r_t^{\text{int}}$$

$r_t^{\text{ext}}$ 来自环境目标，$r_t^{\text{int}}$ 来自探索模块，$\eta\ge0$ 控制“好奇心”在训练信号里的权重。这里用 $\eta$，避免和后面 option 的终止函数 $\beta_\omega$ 混淆。

从可数状态开始：访问越多，奖金越少

若能维护状态访问次数 $N(s)$，一种最小新颖度奖金是：

$$r^{\text{int}}(s)=\frac{1}{\sqrt{N(s)+1}}$$

当前状态过去从未访问，$N=0$，奖金为 1；已经访问 24 次，奖金降到 $1/\sqrt{25}=0.2$。这种 consumable bonus（可耗尽奖金） 很重要：如果同一个位置永远给高分，agent 会在那里刷内在奖励。

高维观测不能逐像素计数：改用可学习的新颖度

PREDICTION-BASED

预测误差

编码状态后，预测执行动作的下一特征；越预测不准，说明动力学越陌生：

$$r_t^{\text{int}}=\frac12\left\|f_\psi(\phi(s_t),a_t)-\phi(s_{t+1})\right\|_2^2$$

Intrinsic Curiosity Module（ICM，内在好奇心模块）会再用逆向动作预测帮助特征保留与 agent 可控的变化。

DISTILLATION-BASED

随机目标拟合误差

Random Network Distillation（RND，随机网络蒸馏）冻结随机目标网络 $\bar f$，只训练预测器 $f_\psi$：

$$r^{\text{int}}(s)=\left\|f_\psi(s)-\bar f(s)\right\|_2^2$$

常见状态被反复拟合后误差下降。它不需要动作标签，但仍需归一化，并检查随机视觉变化是否持续制造“假新颖”。

两条路线真正比较的是“未知”的定义：动力学预测不准，或对固定随机表示还拟合不好。误差大只表示模型陌生，不自动表示状态对外部任务有用。

容易想错

“内在奖励只是加速器，不会改变最优策略。” 一般不成立。只要 $\eta r^{\text{int}}$ 进入优化目标，它就在改变训练回报；若奖金不衰减，策略可能偏爱新奇但无用的区域。评估必须单独报告外部任务成功率。

Insight 02

好奇心的价值来自“会耗尽”，风险也来自“它是一份真实工资”

新状态的奖金应帮助策略跨过无反馈区；学会以后奖金下降，外部任务再接管方向。

训练 reward 可以混合，评估指标不能混淆：最终仍要用 $r^{\text{ext}}$ 或任务成功率判断是否真的完成任务。

04实验：多大的好奇心，才会让 agent 暂时离开熟路？

比较两个动作。熟路立刻带来 0.20 外部奖励，但几乎不新颖；新房间暂时没有外部奖励，却可能提供可耗尽的探索奖金。

Question
内在奖励权重与重复访问次数，怎样共同改变这一步的动作偏好？
Prediction
$\eta$ 较大且新房间访问少时，探索分数更高；反复访问后，新颖度衰减，熟路重新占优。
Experiment
调节好奇心权重 $\eta$ 与新房间过去访问次数 $N$，比较两条路的 $r^{\text{train}}$。
Observation
页面实时显示两条训练奖励、差值与当前贪心选择；默认值下，新房间以很小优势胜出。
Interpretation
内在奖励改变的是采样方向：它让“尚无外部回报但能增加信息”的动作暂时可选。
Limitation
这是一步贪心对照，不代表完整 RL 训练；固定的新颖度也没有模拟表征学习、归一化或跨回合衰减。
熟路 · EXPLOIT

外部 $0.20$ + 内在 $0.10$

0.230 0.20 + 0.30 × 0.10
新房间 · EXPLORE

外部 $0$ + 内在 $1/\sqrt{N+1}$

0.300 0.00 + 0.30 × 1.000

新房间高 0.070；在这一步的贪心比较里，agent 会选择探索。

真正要观察的是决策翻转边界，而不是“内在奖励越大越好”：访问次数上升会耗尽奖金；权重过大则可能让新奇压过任务进展。

默认数值手算

默认 $\eta=0.30,N=0$。熟路分数是 $0.20+0.30(0.10)=0.23$；新房间分数是 $0+0.30(1)=0.30$，所以先探索。若同一房间过去已访问 24 次，新颖度变为 $0.2$，新房间分数降到 $0.06$，熟路以 $0.23$ 胜出。
