06PPO-RLHF：让当前策略在自己生成的回答上继续练习

SFT 只能模仿已有示范，Reward Model 只能打分。经典 RLHF 的第三阶段把两者接回 Proximal Policy Optimization（PPO，近端策略优化）：当前策略生成回答，RM 给奖励，Critic 估计 advantage，PPO 小步更新。

TRAINABLE

Actor · $\pi_\theta$

从 SFT 模型初始化；生成回答，也是最终被更新的语言模型。

FROZEN

Reference · $\pi_{\mathrm{ref}}$

通常冻结一份 SFT 起点；计算 KL 边界，不参与梯度更新。

FROZEN

Reward Model · $r_\phi$

从偏好对学得；读取完整回答并输出序列级分数。

TRAINABLE

Critic · $V_\psi$

估计各 token 前缀的价值，帮助得到低方差 advantage。

四个角色中只有 Actor 是最后要交付的策略；Reference 与 RM 负责只读评分，Critic 是训练期降噪工具。角色分开理解，比把它们统称为“四个 LLM”更准确。

一批 rollout 的六步闭环

  1. 采 prompt从训练 prompt 集取一批 $x$。
  2. 生成Actor 采样 $y\sim\pi_\theta(\cdot\mid x)$。
  3. 评分RM 计算 $r_\phi(x,y)$。
  4. 守边界Reference 对同一段 $y$ 计算 log-prob，形成 KL 代价。
  5. 分功劳Critic 与 GAE 把整段结果变成 token 级 advantage。
  6. 小步更新PPO 用 Chapter 09 的 ratio 与 clipping 更新 Actor 和 Critic。

如果把 Critic、GAE 和 PPO 裁剪先折叠起来，只看“什么目标值得追”，经典 RLHF 常写成带 KL 正则的期望目标：

$$\max_\theta\; \mathbb E_{x\sim\mathcal D,\,y\sim\pi_\theta(\cdot\mid x)} \left[r_\phi(x,y)-\beta D_{\mathrm{KL}}\!\left(\pi_\theta(\cdot\mid x)\,\|\,\pi_{\mathrm{ref}}(\cdot\mid x)\right)\right].$$

$r_\phi$ 提供“往哪里走”的偏好方向；$\beta\ge0$ 决定偏离 SFT 锚点要付多大代价。它们共同形成奖励，不替代 PPO 的 clipped surrogate objective；真正更新时仍需要 old policy ratio 与 advantage。

KL 怎样落到一段实际回答上？

自回归模型对完整回答的概率可分解成 token 条件概率的乘积：

$$\log\pi_\theta(y\mid x) =\sum_{t=1}^{T}\log\pi_\theta(y_t\mid x,y_{<t}).$$

因此，对 Actor 已经采样出的回答 $y$，可以计算序列 log-ratio：

$$\widehat k(x,y)= \log\pi_\theta(y\mid x)-\log\pi_{\mathrm{ref}}(y\mid x) =\sum_{t=1}^{T}\left[\log\pi_\theta(y_t\mid s_t)-\log\pi_{\mathrm{ref}}(y_t\mid s_t)\right].$$

在 $y\sim\pi_\theta$ 下对 $\widehat k$ 求期望，才得到非负的 sequence-level KL。单条样本的 $\widehat k$ 可以为负，所以不要把某个 token 的 log-prob 差单独叫作“完整 KL 散度”。

若一段简化回答的 Actor log-prob 为 $-1.2$，Reference log-prob 为 $-1.6$，则 $\widehat k=0.4$。取 $\beta=0.05$，样本 KL 代价为 $0.05\times0.4=0.02$；若 RM 给 $1.3$，用于构造回报的样本值为：

$$\widehat R_{\mathrm{total}}=1.3-0.05(0.4)=1.28.$$

这还不是策略梯度的最终正负标签。Critic 会把 reward 与基线比较得到 advantage，PPO 再根据 advantage 和概率比决定每个 token 的更新。

07Reference policy 与 old policy：都“旧”，时间尺度完全不同

沿时间轴真正要看的是：old policy 随 batch 向前移动，而 reference 仍停在训练起点。一个限制局部更新步幅，一个限制全程语义漂移。

Insight 03

PPO clip 与 reference KL 是两个不同尺度的安全带

clip 问“这一个 batch 的策略概率改了多少”；reference KL 问“整个 RLHF 过程离原来的 SFT 助手有多远”。

即使新策略紧贴 old policy，小步累积很多次仍可能离 SFT 很远；因此局部裁剪不能替代长期锚点。

08互动实验：换掉反馈来源，训练信号在哪一层发生变化？

用一个受控的小例子追踪“候选回答 → 偏好标签 → RM 一步更新 → PPO 奖励”。这里的人类多数票与 AI judge 都是教学设定，不代表所有真实标注者都会这样判断。

Feedback Signal Tracer

Question
“反馈由谁产生”会直接改变 PPO 公式吗？显式自然语言原则怎样通过偏好标签间接改变 Actor 收到的奖励？
Prediction
只要 chosen/rejected 标签相同，人类与 AI 来源会产生相同的这一步 RM loss 和更新；在本例中，AI judge 缺少“允许低风险科普”的规则时会把偏好翻转，进而把回答 A 的 RM 梯度从上推变成下压。
Experiment
切换 Human / AI；在 AI 模式勾选或取消比例原则；调节 RM 学习率 $\eta$ 与 KL 系数 $\beta$，观察四段数据流和数值。
Observation
正在计算当前设定下的反馈路径。
Interpretation
反馈来源首先决定偏好数据怎样产生；RM 把标签压成分数，PPO 只读取 RM 分数与 KL。若两个来源交付完全相同的数据，下游算法不能凭空知道标签是谁给的。
Limitation
实验只做一个偏好对上的一次理想化梯度步，固定了候选回答和初始 RM 分数；真实系统有大量样本、标注分歧、模型泛化、Critic 与 token-level PPO 更新。
