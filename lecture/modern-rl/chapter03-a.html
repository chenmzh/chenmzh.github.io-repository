Chapter 03 · Sequential decisions need state

动作之后，世界变了：把交互写成一个数学问题

上一章里，多臂老虎机故意让每一轮都回到同一种决策局面。这样我们可以专心研究探索与利用。但 CartPole、游戏、机器人和语言模型都多了一件关键的事：你刚才做了什么，会改变下一刻你面对的局面。

本章核心问题：如果动作不仅影响眼前奖励，还会改变未来状态，我们需要保存哪些信息，才能把“现在做什么会导致以后怎样”写成一个可以推理、计算和学习的问题？

回到 CartPole。假设当前杆子向右微倾，你向右推车。这个动作的价值不能只用“这一刻有没有拿到 +1”评价，因为它还会改变小车速度、杆角度和角速度。下一步你面对的是一个由刚才动作造成的新局面。

于是，一个时间步至少要写成：

$$s_t \xrightarrow{\ a_t\ } (r_t,\ s_{t+1})$$

这里 $s_t$ 是当前状态，$a_t$ 是当前动作，$r_t$ 是执行动作后得到的即时奖励，$s_{t+1}$ 是下一状态。我们继续沿用前两章的索引习惯：$r_t$ 表示动作 $a_t$ 之后环境返回的奖励。有些教材会把同一份奖励写成 $R_{t+1}$；只是下标习惯不同，不要把它误解成两种奖励。

现在真正的问题出现了：如果我们想研究“动作如何改变未来”，就必须先回答什么叫当前状态，以及动作之后的变化规律怎样表示。

这套标准形式叫 Markov Decision Process（MDP，马尔可夫决策过程）：一种用状态、动作、状态转移、奖励和长期目标来描述序贯决策问题的数学框架。先别背五元组；本章会让它的每一项都从一个已经出现的问题里长出来。

Insight 01

从 bandit 到 MDP，真正新增的不是“更多符号”，而是一个因果链

Bandit 里动作主要决定当前 reward；MDP 里动作还决定你接下来会看到什么，而接下来看到什么又会影响以后能做什么。

因此一个动作可能“眼前吃亏、未来赚回来”。只要这个链条存在，单步平均奖励就不再足够，我们最终必须学会给未来状态定价。

02State 不是“传感器读数”，而是对未来足够有用的信息

Chapter 01 已经见过 CartPole 的四维状态。现在把问题问得更严格一点：为什么这些量能叫 state？少一个会怎样？

先看一个更小的玩具世界。一个小车在一条直线上，当前位置都是 $x=2$。只看这一帧，两种情况完全一样：

如果下一步都选择“不给额外加速度”，左边的小车会继续向左，右边的小车会继续向右。也就是说，相同的 $x=2$ 加上相同动作，并不能确定甚至不能稳定预测下一状态；更早的历史还藏着有用信息。

这就是为什么 state 不能简单理解成“当前能看到的任何数字”。一个好的状态表示，应该把预测未来所需的信息压缩进当前表示里。对这个玩具世界，$[x,v]$ 比单独的 $x$ 更接近合格的 state；对 CartPole，$[x,\dot x,\theta,\dot\theta]$ 比一张只给位置和角度的静态截图更有用。

把“历史不再额外有用”写成条件概率

当状态表示足够完整时，我们希望预测下一状态只需要当前状态和当前动作。这个性质叫 Markov property（马尔可夫性）：

$$P(S_{t+1}\mid S_t,A_t,S_{t-1},A_{t-1},\ldots)=P(S_{t+1}\mid S_t,A_t)$$
符号它在问什么直觉
$S_t$当前状态随机变量现在我们认为“足够描述局面”的信息
$A_t$当前动作agent 现在施加的选择或控制
$S_{t+1}$下一状态世界推进一步以后会变成什么
左边条件当前 + 完整历史都知道时的预测把过去全部翻出来
右边条件只知道当前 state 与 action 时的预测如果 state 够好，过去不再增加预测信息

注意这个定义的重点不是“过去不存在”，也不是“系统没有记忆”。它说的是：过去对未来有用的影响，已经被当前 state 吸收了。 一个 state 完全可以包含历史摘要、速度、计数器、记忆向量，甚至整个对话上下文。

容易想错

“Markov 就是无记忆。” 更准确的说法是：一旦给定当前 state 与 action，更早历史不再为下一步提供额外预测信息。state 自己可以携带大量“过去留下来的记忆”。

Insight 02

马尔可夫性不是世界天然贴着的标签，它依赖你怎样表示世界

同一套物理系统，用 $x$ 表示时可能不是 Markov；加入速度 $v$ 后就可能变成 Markov。问题不是动力学突然变了，而是我们的表示是否丢掉了预测未来所需的信息。

这也是为什么“换一个更大的神经网络”不能自动修复缺失信息：网络可以学习复杂函数，却不能凭空恢复从 observation 中被删掉的变量。

03互动实验：当前信息到底够不够？

我们固定两个真实局面：位置都相同，但速度相反。然后用同一个动作推进一步，看不同的“状态表示”会不会把它们错误地混在一起。

State Sufficiency Lab

同样显示 $x=2$，背后可能是两个完全不同的动力学局面。

Question
只记录位置 $x$，能不能让“当前 state + action”足以预测下一步？
Prediction
如果速度被隐藏，同一个表示 $x=2$ 和同一个动作会对应不同下一状态；加入速度以后，两种局面会被当前 state 区分开。
Experiment
切换状态表示，并选择相同的加速度动作；页面同时推进“向左运动”和“向右运动”的两个真实局面。
Observation
比较页面显示给 agent 的当前 state，以及两个世界实际得到的 $s_{t+1}$。
Interpretation
如果两个真实局面被压成同一个 state，却产生不同未来，那么更早历史仍含预测信息，当前表示并不充分。
Limitation
这个实验只能证明这个玩具动力学里“位置 alone 不够”；它不能证明任意真实系统加入速度后就一定完整 Markov。

Interpretation 两个世界对 agent 看起来都是 [2]，同一个动作却得到不同下一位置。位置 alone 发生了 state aliasing：不同真实局面被压成同一个表示。

这里真正要看的是“当前表示是否把会影响未来的差异保留下来”。Markov property 首先是一个表示问题，然后才是一个公式。
