04有限交互预算，下一场应该分给谁？

均匀抽样把每个对手当成同样有教学价值；真正的训练系统还要决定，有限交互预算应该优先放在哪些尚未掌握的匹配上。

self-play curriculum（自博弈课程）是根据当前能力，动态安排对手、任务或难度的规则。一个透明的教学规则是：当前对某个对手的成功率越低，下轮抽到它的权重越高。若 $s_k^{(t)}\in[0,1]$ 表示第 $t$ 轮对对手 $k$ 的成功率，可写成：

$$\mu_t(k)=\frac{\exp[-\beta s_k^{(t)}]}{\sum_j\exp[-\beta s_j^{(t)}]}.$$

$\beta\ge0$ 是课程聚焦强度。$\beta=0$ 时退化为均匀分布；$\beta$ 越大，越集中到当前薄弱对手。这里的负号很关键：分数低，指数值反而大。

MOTIVATION把更多训练回合分给尚未掌握的匹配，而不是继续刷已经接近满分的对手。
SYMBOLS$s_k^{(t)}$ 是逐对手成功率，$\mu_t(k)$ 是下一轮训练权重，$\beta$ 控制“补短板”有多激进。
NUMERIC EXAMPLE取 $s=(0.8,0.5,0.2),\beta=2$，未归一化权重约为 $(0.202,0.368,0.670)$，归一化后约为 $(0.163,0.297,0.540)$。
PROGRAM MAPPINGraw = scores.map(s => Math.exp(-beta * s))，再除以 sum(raw) 得到抽样权重。

上例中最弱的第三项获得约 54% 预算。但“最难”不一定“最有教学价值”：如果第三个任务目前不可解，它会长期吸走样本却始终返回零奖励。实际课程需要最低／最高权重、可学习进度或外部难度分层，并用消融实验检查聚焦规则是否真的优于均匀池。

05实验：训练分数升高时，跨对手能力会怎样变化？

下面不假装浏览器在训练一个真实神经网络，而用一套完全明示的教学动力学，隔离“训练分配”和“未练习能力遗忘”两个效应。

设 $s_{k,t}$ 是第 $t$ 轮对第 $k$ 类对手的成功率，$\mu_{k,t}$ 是该轮分给它的训练比例，$\eta$ 是学习速率，$d$ 是未练习能力的遗忘率。页面逐项更新：

$$s_{k,t+1}=\operatorname{clip}_{[0,1]}\!\left[ s_{k,t}+\eta\mu_{k,t}(1-s_{k,t})-d(1-\mu_{k,t})s_{k,t} \right].$$

第二项表示把训练预算投入尚未掌握的部分，第三项表示某类对手长期不被练习时发生遗忘。固定对手使用 $\mu=(1,0,0)$；自适应池使用上一节的 softmax 权重。

MOTIVATION同一训练预算下，固定对手能否把一列刷满，却让另外两列退化？
SYMBOLS$s$ 是逐对手能力，$\eta$ 是学习率，$d$ 是遗忘率，$\mu$ 是训练分配；三者都由页面直接显示。
NUMERIC EXAMPLE初始 $s=(0.55,0.45,0.35)$、$\eta=0.25,d=0.06$。固定第一类对手一步后为 $(0.6625,0.4230,0.3290)$。
PROGRAM MAPPINGsimulate('fixed') 令权重为 [1,0,0]；simulate('pool') 每轮由 curriculumWeights 重算 $\mu$。
Question
同样训练轮数下，固定对手的表面胜率、独立对手池均值与最差匹配，和自适应对手池相比会怎样变化？
Prediction
固定对手会让已见对手分数快速接近 1；遗忘率大于 0 时，未练习两项下滑，跨对手均值甚至可能下降。对手池提升得较慢，却会使最差项更稳。
Experiment
从同一初始能力 $(0.55,0.45,0.35)$ 出发，分别使用固定权重 $(1,0,0)$ 与 softmax 自适应权重，调节轮数、学习率、遗忘率和课程聚焦强度；“关闭遗忘”按钮执行反事实。
Observation
等待实验加载。
Interpretation
训练对手胜率与策略稳健性不是同一指标。对手池通过持续分配历史匹配来换取覆盖；固定对手的高分只证明局部最佳回应被学到。
Limitation
这是确定性的教学能力模型，不是策略梯度收敛定理，也没有模拟真实轨迹噪声、对手相关性和优化器；结论应在真实环境的跨版本对战矩阵上复测。

Insight 04

最有用的曲线往往不是训练胜率，而是训练分布外的回归线

固定对手上的分数单调上升，恰好可能掩盖历史对手上的持续退化。只有让同一批独立对手贯穿训练，才能看到“进步”和“遗忘”是否同时发生。

凡是对手选择参与了训练，就不能再把同一配对分数当作独立证据；必须保留不用于更新与调参的评测池。
