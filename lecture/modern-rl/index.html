A learning companion for modern reinforcement learning

Modern RL,
from interaction to agents.

给已经学过机器学习导论的读者的一条平滑路线。这里不把强化学习讲成算法名词表，而是从可观察的现象出发：先理解行动怎样改变数据，再建立状态、奖励、回报、价值与策略，最后连接到大模型对齐、可验证奖励和能够连续调用工具的智能体训练。

每章遵循同一个原则：先提出一个真实问题，再引入必要抽象；术语第一次出现时先解释，公式需要能翻译回环境里的量，实验需要能回答一个具体问题。内容参考 walkinglabs/hands-on-modern-rl 的主线，但讲解结构重新组织。

01–13 published
01 让一根杆子站起来从监督学习过渡到交互学习。用 CartPole 建立状态、动作、奖励、轨迹、回报与策略的第一层直觉，并通过浏览器实验观察策略如何改变行为。 READ → 02 探索还是利用？用多臂老虎机把问题压缩到最小：从有限样本误判出发，理解为什么需要探索、怎样保留纠错机会，以及如何衡量为信息付出的机会成本。 READ → 03 把交互写成一个数学问题动作会改变下一状态以后，怎样表示“当前局面”和“世界的变化规律”？从状态充分性与随机转移出发，建立马尔可夫决策过程的完整心智模型。 READ → 04 怎样给未来的局面定价？用 value function（价值函数）把未来回报压缩成当前估计，再理解为什么“一步奖励 + 下一状态价值”可以形成递归关系。 READ → 05 等不到结局，能不能先学？从“更新目标来自哪里”出发，比较完整模型、完整回合和单步经验三种信息条件，再连接到同策略与异策略控制。 READ → 06 让神经网络估计动作价值当状态太多、表格装不下时，怎样用参数化函数近似动作价值，并用打散相关经验、放慢训练目标变化来稳定学习。 READ → 07 不比较每个动作的 Q，能不能直接改策略？从随机动作分布和轨迹概率出发，把整条轨迹的结果变成更新方向，理解怎样提高好动作被再次采样的概率。 READ → 08 谁来告诉策略，这一步比平常好多少？把行动与评价交给两个可学习函数，用相对同状态平常水平的好坏更新策略，并区分完整回报、价值基线与一步估计。 READ → 09 策略更新太猛，为什么会把自己学坏？从数据分布随策略改变的困难出发，一边组合不同长度的评价信号，一边用分布距离和概率比限制每次更新幅度。 READ → 10 动作连续、真实交互昂贵时，怎样学习？比较三种连续控制目标怎样找动作、抑制高估并保留探索，再理解学习环境动力学如何用短程想象改善样本效率。 READ → 11 不能再采新数据时，策略为什么会被自己骗到？当训练只能依赖固定历史数据，数据实际覆盖过哪些行为、分布外动作有多危险，将重新划定可以可靠学习的边界。 READ → 12 没有明确奖励，能否从示范和任务族学习？从照着专家动作做起，观察策略自己的错误怎样累积，再比较持续补充示范、反推目标和跨任务快速适应三条路线。 READ → 13 奖励稀疏、多个智能体、任务很长时怎么办？分别处理主动发现未知区域、团队结果归因给个体，以及把一串底层动作组织成更长时间尺度决策的问题。 READ →
14 怎样把人类或 AI 的反馈变成训练信号？当“好不好”只能通过成对比较、文字原则或另一个模型表达，怎样把反馈变成可学习的奖励，并限制策略不要偏离太远。 NEXT
