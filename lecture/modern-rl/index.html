A learning companion for modern reinforcement learning

Modern RL,
from interaction to agents.

给已经学过机器学习导论的读者的一条平滑路线。这里不把强化学习讲成算法名词表，而是从可观察的现象出发：先理解行动怎样改变数据，再建立状态、奖励、回报、价值与策略，最后连接到大模型对齐、可验证奖励和能够连续调用工具的智能体训练。

每章遵循同一个原则：先提出一个真实问题，再引入必要抽象；术语第一次出现时先解释，公式需要能翻译回环境里的量，实验需要能回答一个具体问题。内容参考 walkinglabs/hands-on-modern-rl 的主线，但讲解结构重新组织。

01 让一根杆子站起来从监督学习过渡到交互学习。用 CartPole 建立状态、动作、奖励、轨迹、回报与策略的第一层直觉，并通过浏览器实验观察策略如何改变行为。 READ → 02 探索还是利用？用多臂老虎机把问题压缩到最小：从有限样本误判出发，理解为什么需要探索、怎样保留纠错机会，以及如何衡量为信息付出的机会成本。 READ → 03 把交互写成一个数学问题动作会改变下一状态以后，怎样表示“当前局面”和“世界的变化规律”？从状态充分性与随机转移出发，建立马尔可夫决策过程的完整心智模型。 READ → 04 怎样给未来的局面定价？用 value function（价值函数）把未来回报压缩成当前估计，再理解为什么“一步奖励 + 下一状态价值”可以形成递归关系。 READ → 05 等不到结局，能不能先学？从“更新目标来自哪里”出发，比较完整模型、完整回合和单步经验三种信息条件，再连接到同策略与异策略控制。 READ → 06 让神经网络估计动作价值当状态太多、表格装不下时，怎样用参数化函数近似动作价值，并用打散相关经验、放慢训练目标变化来稳定学习。 READ → 07 不比较每个动作的 Q，能不能直接改策略？从随机动作分布和轨迹概率出发，把整条轨迹的结果变成更新方向，理解怎样提高好动作被再次采样的概率。 READ → 08 谁来告诉策略，这一步比平常好多少？把行动与评价交给两个可学习函数，用相对同状态平常水平的好坏更新策略，并区分完整回报、价值基线与一步估计。 READ → 09 策略更新太猛，为什么会把自己学坏？从数据分布随策略改变的困难出发，一边组合不同长度的评价信号，一边用分布距离和概率比限制每次更新幅度。 READ → 10 动作连续、真实交互昂贵时，怎样学习？比较三种连续控制目标怎样找动作、抑制高估并保留探索，再理解学习环境动力学如何用短程想象改善样本效率。 READ → 11 不能再采新数据时，策略为什么会被自己骗到？当训练只能依赖固定历史数据，数据实际覆盖过哪些行为、分布外动作有多危险，将重新划定可以可靠学习的边界。 READ → 12 没有明确奖励，能否从示范和任务族学习？从照着专家动作做起，观察策略自己的错误怎样累积，再比较持续补充示范、反推目标和跨任务快速适应三条路线。 READ → 13 奖励稀疏、多个智能体、任务很长时怎么办？分别处理主动发现未知区域、团队结果归因给个体，以及把一串底层动作组织成更长时间尺度决策的问题。 READ → 14 怎样把人类或 AI 的反馈变成训练信号？当“好不好”只能通过成对比较、文字原则或另一个模型表达，怎样把反馈变成可学习的奖励，并限制策略不要偏离太远。 READ → 15 能否不用在线强化学习，直接从偏好对学习？从“回答 A 胜过回答 B”的概率模型出发，把奖励提升与参考模型约束合成一个可直接训练的相对目标。 READ → 16 没有价值网络，怎样用组内结果学习？对同一道题采样一组回答，用组内相对结果代替单独训练的评价网络，并分清可验证结果与过程信用的边界。 READ → 17 为什么增加思考长度和采样次数能改善推理？把推理时计算当作有限预算，比较延长单条推理、多采候选、投票与自适应分配怎样交换质量和成本。 READ → 18 只看最终答案，为什么还不足以选对推理？把评价从终局放回中间步骤，比较不同的步骤聚合方式，再用过程分数决定哪些推理分支值得继续搜索。 READ → 19 算法进入大规模集群后，真正瓶颈在哪里？沿着轨迹生成、评分、训练和权重同步的生产流水线，理解吞吐、等待与过期数据怎样共同决定训练效率。 READ → 20 语言模型怎样学会多轮调用工具？当动作会触发搜索、代码或外部接口并返回新观察，怎样表示轨迹、设计环境，并把长程结果归因到中间工具决策。 READ → 21 怎样把仓库、补丁与测试组成可验证环境？把代码仓库状态、工具动作、补丁轨迹和测试结果组织成可复现环境，并区分“测试通过”与“真正解决任务”。 READ → 22 搜索、阅读与引用如何形成可验证的长轨迹？让浏览器智能体围绕信息缺口行动，把论断绑定到证据，并分开评估答案质量、引用支持、过程与成本。 READ → 23 像素、鼠标与不可逆操作如何训练？当观察退化为屏幕像素、动作变成坐标与按键，怎样在部分可观测环境中加入授权、确认与中止边界。 READ → 24 答案对了，模型真的看图了吗？把图像观察、文本或结构化动作、多步轨迹与分项奖励放进同一框架，检查正确答案是否真的得到视觉证据支持。 READ → 25 声音、身体与生成画面，还是同一种 RL 吗？分别重写音频序列、具身交互和视觉生成中的状态、动作与轨迹，再比较奖励延迟和多目标冲突。 READ → 26 指标变好，为什么行为反而可能变坏？把训练分数与独立任务效用分开，沿得分路径、反馈通道和优化强度定位漏洞，再建立分层发布门禁。 READ → 27 当对手也会学习，能力怎样持续扩展？从固定对手上的脆弱高分出发，用历史快照、版本混合抽样、交叉评测和研究检查表建立可审计的改进循环。 READ →
