课程简介

官方课程介绍将重点放在 LLM 的自我改进方法、验证器与测试时计算扩展，以及搜索、工具、检索、记忆和多模态交互；后半部分延伸到多步推理与规划、agent workflow 的评测和编排，并讨论 coding agents、科研助手与机器人等应用场景。这里把这些方向做成一个可继续填充的阅读工作台。

事实来源：官方课程页面 与 Stanford Bulletin 课程条目。

学习路线：从改进信号到可验证的 agent

下面是根据公开课程简介与日程做的主题归纳，不是官方讲义目录；具体课次和阅读材料请回到官方页面核对。

可视化教程主线

按“先理解闭环，再接入系统，最后评估是否真的变好”的顺序阅读。每页都使用本地确定性模拟，不需要 API，也不把教学数字冒充论文结果。

01 · 闭环、扩展与验证 ↗ 02 · 工具、规划与记忆 ↗ 03 · 长程评估与机器人 ↗
TRACK 01

Inference-time scaling

先观察推理时增加计算、重复采样或搜索如何改变结果质量与成本。

TRACK 02

Verification & feedback

把 verifier、工具执行结果或环境反馈变成可利用的改进信号。

TRACK 03

Search, tools & memory

研究 agent 如何调用工具、检索信息、保存上下文，并在多步任务中持续工作。

TRACK 04

Planning & orchestration

把分解、规划、执行与重试组织成 workflow，同时明确边界条件与失败模式。

TRACK 05

Evaluation & applications

用长时程任务、真实工具链和应用场景检查 agent 是否可靠，而不只看单步 benchmark。

TRACK 06

Research practice

从论文讨论走向可复现实验、项目提案、中期交流和最终研究展示。

建议的阅读方法

不要把“能生成答案”直接等同于“能完成任务”。每次阅读都记录：改进信号是什么、agent 如何获得反馈、评价指标是否覆盖长程失败。
