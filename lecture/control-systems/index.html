How this textbook is built

主结构来自 ETH HS2023：你 Drive 中的 14 份 lecture slides、13 份 annotated slides、13 份 board notes、exercise summaries、problems 和 solutions。exercise summary 决定小节颗粒度，exercise/solution 则主要用来识别最值得练的能力和典型题型。

版权边界：本站不镜像 Moodle 原始 PDF，也不逐字搬运 exercise / solution；定义、推导、数值例题与代码实验均重新组织或自编。

推荐用法：先读“零背景导读” → 看 illustration → 跟着逐步推导 → 遮住 worked example 的解自己算一次 → 跑 Python lab → 最后再做 ETH 对应 Exercise。这样把“看懂”变成“会做”。
