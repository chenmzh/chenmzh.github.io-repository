Control Systems,
from models to feedback.

这是一套围绕 ETH Zürich 227-0103-00L Control Systems 主线重新组织的中文学习笔记。目标不是把控制理论变成公式清单，而是一直追问：系统为什么需要反馈？怎样把“稳定、快速、鲁棒”变成可以计算和设计的对象？

12 个子课程SISO → MIMOFrequency → State spacePID · Loop shaping · LQR · Kalman

Learning path

从“系统会怎样动”到“闭环应该怎样设计”

每一小节都是独立子课程：先从工程问题出发，再给数学表示、设计判断和理解检查。内容依据 ETH 公开课程说明与公开教材重写，不复制 Moodle 受限材料。

01

为什么控制问题从模型开始？

动力系统、状态、输入输出、平衡点与线性化；把真实过程压缩成可设计模型。

↗ 02

同一个系统，为什么要换一种表示？

Laplace 变换、传递函数、极点零点，以及一二阶系统的瞬态直觉。

↗ 03

反馈究竟改变了什么？

闭环、跟踪、扰动抑制、灵敏度函数与稳态误差。

↗ 04

PID 为什么如此常用？

P/I/D 三种作用、积分抗偏差、微分塑形、Ziegler–Nichols 与 anti-windup。

↗ 05

怎样判断闭环会不会发散？

特征方程、Routh–Hurwitz、根轨迹，以及稳定裕度背后的几何图景。

↗ 06

为什么频率响应能指导设计？

Bode 图、Nyquist 判据、增益/相位裕度与 bandwidth。

↗ 07

Loop shaping 到底在“塑”什么？

灵敏度、互补灵敏度、低频跟踪、高频噪声与鲁棒性的权衡。

↗ 08

一个反馈环不够时怎么办？

前馈、两自由度、cascade、IMC 与执行器饱和。

↗ 09

多个输入输出为什么会互相“打架”？

MIMO、传递矩阵、耦合、Relative Gain Array 与 decoupling。

↗ 10

能直接安排闭环极点吗？

可控性、状态反馈、canonical form 与 pole placement。

↗ 11

看不到全部状态时怎么办？

可观性、Luenberger observer、对偶性与 separation principle。

↗ 12

“最优控制”和“最优估计”如何相遇？

LQR、Riccati 方程、Kalman filter，以及从代价与噪声模型得到控制器。
