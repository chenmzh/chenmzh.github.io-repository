Study notes · Autumn 2026

Control Systems,
learn it by designing the loop.

这一版不再把课程做成“知识点目录”，而是按真正学习一门 6 ECTS 控制课的方式来写：每个子课程都有学习目标、概念推导、公式解释、完整例题、设计判断、常见坑、练习题与答案提示。主线跟随 ETH 227-0103-00L 的公开 syllabus，并用 ETH 历年公开录像与 Åström–Murray《Feedback Systems》补足推导与例子。

12 个深度子课程建议 30–60 min / unitSISO → MIMOClassical → State space例题 + 自测

Learning path

从“系统为什么这样动”一路学到 LQG

建议顺序学习。01–03 建立模型与反馈语言；04–08 是 ETH 课程的经典控制设计核心；09 进入多变量；10–12 转入状态空间、observer、LQR 与 Kalman filter。

01

建模、状态与线性化

从物理守恒律写 ODE；状态的含义；平衡点；Jacobian 线性化；状态空间解与模型边界。

↗ 02

传递函数、极点与零点

Laplace、state-space → transfer function、一阶/二阶响应、主导极点、RHP zero 与 pole-zero cancellation。

↗ 03

反馈、灵敏度与稳态误差

把 reference、disturbance、noise 分成不同通道；S/T；system type；反馈为什么能鲁棒，也为什么会付出代价。

↗ 04

PID：从作用机理到可实现控制器

P/PI/PD/PID、Ziegler–Nichols、filtered derivative、set-point kick、anti-windup 与数字实现。

↗ 05

稳定性、Routh–Hurwitz 与 Root Locus

闭环极点、内部稳定、Routh 表、根轨迹规则，以及怎样从极点位置读出速度和阻尼。

↗ 06

Bode、Nyquist 与 Stability Margins

频率响应的物理意义、渐近 Bode、gain/phase margin、Nyquist 判据、延迟为何危险。

↗ 07

Loop Shaping 与鲁棒性能

把时间域要求翻译成频域约束；lead/lag；crossover；S/T/KS；模型不确定性与带宽权衡。

↗ 08

2-DOF、Feedforward、Cascade 与 IMC

一个反馈环解决不了所有目标：前馈、预滤波、串级控制、internal model control 与饱和处理。

↗ 09

MIMO、耦合、RGA 与 Decoupling

为什么多个 SISO 环会互相打架；transfer matrix、pairing、relative gain array、解耦与鲁棒性。

↗ 10

Controllability 与 State Feedback

可控性矩阵、PBH test、pole placement、Ackermann、积分状态扩展，以及“极点放多快”这个工程问题。

↗ 11

Observability、Observer 与 Separation

看不见状态时如何重建；Luenberger observer；误差动力学；对偶性；observer-based control。

↗ 12

LQR、Kalman Filter 与 LQG

从 cost function 而不是“猜极点”开始设计；Riccati；Q/R；噪声协方差；Kalman gain 与 LQG。
