How this textbook is built

主结构来自 ETH HS2023：你 Drive 中的 14 份 lecture slides、13 份 annotated slides、13 份 board notes、exercise summaries、problems 和 solutions。尤其是 exercise summary 的 R1.x–R13.x 结构被用来决定本版“小节”的颗粒度。

版权边界：本站不镜像 Moodle 原始 PDF，也不逐字搬运 exercise / solution；定义、推导、例子和练习均重新组织或自编，用来帮助你学习原课件。

推荐用法：先读本站对应小节 → 自己推一遍公式 → 做本站检查题 → 再做 ETH 对应 Exercise → 最后用 solution 对答案。这样比先读 solution 更接近真正学习。
