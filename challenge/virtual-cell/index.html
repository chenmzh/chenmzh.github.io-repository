01 / Project overview

项目概览

本页说明项目是什么；详细学习计划和持续进度位于独立子页面。

科学问题仅凭未扰动细胞状态，预测未见细胞系在单基因 CRISPRi 敲低后的下游转录组响应。
比赛规模每轮 3 个匿名 contexts、每个 context 300 个 perturbations，每个组合生成 400 个单细胞。
成功标准同时兼顾表达误差、扰动区分、DEG 集合、响应方向与效应量，而不是只优化单一指标。

03 / Working thesis

当前方法主线

先统计，后深度：建立跨细胞系扰动 signature 基线，通过目标 control 状态做 context-weighted transfer，再生成保留异质性的单细胞原始 counts；预训练模型主要用于残差修正与保守集成。
