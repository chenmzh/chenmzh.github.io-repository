Week 01 / Foundations before models

环境与数据语义.

第一周把路线图中的环境准备和最低限度生物学合并起来：从干净环境出发，读懂 AnnData、raw counts、实验分组和 QC，最终完成一次稀疏安全的 pseudobulk 分析。

01 / Setup

从这里开始

推荐 Python 3.11 或 3.12；依赖由 uv 和 pyproject.toml 固定。

目标：从一个空目录运行一条安装命令，自动生成 toy Perturb-seq 数据、QC 表、pseudobulk 文件，并通过测试。

unzip virtual-cell-week01-starter.zip
cd virtual-cell-week01-starter
bash setup.sh
uv run jupyter lab
Expand-Archive virtual-cell-week01-starter.zip
cd virtual-cell-week01-starter
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
uv run jupyter lab

安装脚本会创建隔离环境、检查关键包、安装 vcc-cli、生成数据、运行四个分析脚本并执行 pytest。教学数据是合成数据，不是官方比赛数据。

02 / Learning objectives

学完后你应该能做到

重建环境报告 Python、包版本和随机种子，并从 fresh environment 重跑。
解释实验说明 cell、gene、RNA、control、CRISPRi、perturbation 的含义。
读懂 AnnData正确定位 X、obs、var、layers、obsm，并完成安全切片。
检查 counts判断非负、整数和稀疏属性，不把完整矩阵转 dense。
完成 QC计算 library size、detected genes、mitochondrial fraction 并解释分布。
正确聚合按 donor × cell type × condition 求和，并设计 group-aware split。
03 / Five-day class

五天教学安排

每天约 2 小时；每节都按“问题 → 代码 → 一句话解释”推进。

Day 1

环境、任务地图与最少细胞生物学

讲课：DNA→RNA→表达；CRISPRi 如何改变细胞状态；control 为什么必要；比赛的输入、干预和预测目标。

  • 实践：运行环境检查并生成 toy 数据。
  • 产出：版本报告和“实验单位—观测单位—预测目标”示意图。
  • Exit ticket：用三句话解释 expression、control 和预测目标。
Day 2

AnnData、raw counts 与 sparse matrix

讲课：X 只是位置，不保证语义；adata.raw 也不必然是 raw counts；稀疏 0 不是缺失值。

  • 实践：检查 shape、dtype、nnz、layers、obs 和 var。
  • 产出：数据审计表。
  • Exit ticket：解释为什么不能对比赛矩阵直接 .toarray()。
Day 3

实验设计与基础 QC

讲课：细胞是观测单位，donor/replicate 才通常是独立推断单位；QC 阈值必须由分布和任务支持。

  • 实践：按 perturbation、cell type、batch 比较 total counts、detected genes 和 pct_mito。
  • 产出：QC CSV、三幅分布图和过滤理由。
  • Exit ticket：解释过度 QC 如何删除真实扰动响应。
Day 4

Pseudobulk 初步体验

讲课：在正确实验分组内对 raw counts 求和；pseudobulk 缓解伪重复，但会损失单细胞异质性。

  • 实践：按 donor × cell type × target_gene 聚合。
  • 产出：24 个 pseudobulk 样本及 metadata。
  • Exit ticket：证明聚合前后每个基因总 counts 守恒。
Day 5

端到端小项目与验收

讲课：从 fresh kernel 顺序完成数据读取、审计、QC、pseudobulk、control 对比和防泄漏划分。

  • 实践：独立完成学生 notebook，再对照教师版。
  • 产出：可重跑 notebook、结果摘要和 validation split。
  • Exit ticket：指出 donor_3 与 batch_2 的混杂及其限制。
04 / Teaching dataset

教学数据里有什么

生成脚本创建 2,400 cells × 500 genes：1 个 control、3 个 perturbations、2 个 cell types、3 个 donors 和 2 个 batches。Counts 使用 Gamma–Poisson 产生过度离散，并包含 cell-type-specific 下游响应。

  • X 和 layers["counts"]：CSR 稀疏、非负整数 raw counts；
  • obs：target_gene、guide_id、cell_type、donor、replicate、batch 和 QC 字段；
  • var：gene_id、is_mito、is_target_gene、is_true_response；
  • uns：固定 seed、数据契约和教学 ground truth。

透明陷阱：donor_3 与 batch_2 完全混杂；约 3% 细胞具有低 library size 和升高的线粒体比例。你的任务是发现并正确解释，而不是默默“清洗掉”。

06 / Assessment

作业与通过标准

建议总分 ≥80%，且五条硬性要求全部通过。

20%环境与数据审计
30%QC 小报告
30%Pseudobulk 分析
20%概念与复现

硬性要求

  1. 不混淆 raw counts 与 normalized/log 数据；
  2. 不把细胞当作独立生物重复；
  3. 不对完整稀疏矩阵调用 .toarray()；
  4. notebook 能从 fresh kernel 顺序运行；
  5. 能够提出 donor、cell type 或 perturbation aware 的验证划分。
