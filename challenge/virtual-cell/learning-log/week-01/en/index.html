Week 01 / Foundations before models

Environment & Data Semantics.

Week 1 combines environment preparation with minimum viable biology: start from a clean environment, understand AnnData, raw counts, experimental groups, and QC, then finish one sparse-safe pseudobulk analysis.

01 / Setup

Start here

Python 3.11 or 3.12 is recommended; uv and pyproject.toml lock the environment.

Goal: start from an empty directory, run one setup command, generate toy Perturb-seq data, produce QC and pseudobulk artifacts, and pass the tests.

unzip virtual-cell-week01-starter.zip
cd virtual-cell-week01-starter
bash setup.sh
uv run jupyter lab
Expand-Archive virtual-cell-week01-starter.zip
cd virtual-cell-week01-starter
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
uv run jupyter lab

The setup script creates an isolated environment, checks packages, installs vcc-cli, generates data, runs four analysis scripts, and executes pytest. The teaching dataset is synthetic and is not official challenge data.

02 / Learning objectives

What you should be able to do

Rebuild the environmentReport Python, package versions, and the seed, then rerun from a fresh environment.
Explain the experimentDefine cell, gene, RNA, control, CRISPRi, and perturbation.
Read AnnDataLocate X, obs, var, layers, and obsm, and slice safely.
Audit countsCheck non-negativity, integrality, and sparsity without densifying the full matrix.
Perform QCCompute and interpret library size, detected genes, and mitochondrial fraction.
Aggregate correctlySum by donor × cell type × condition and design a group-aware split.
03 / Five-day class

Five-day teaching plan

About two hours per day; each lesson follows question → code → one-sentence interpretation.

Day 1

Environment, task map, and minimum biology

Teach: DNA→RNA→expression; how CRISPRi changes cell state; why controls matter; challenge input, intervention, and target.

  • Practice: run the environment check and generate toy data.
  • Deliverable: version report and an experimental unit → observation → target diagram.
  • Exit ticket: explain expression, control, and prediction target in three sentences.
Day 2

AnnData, raw counts, and sparse matrices

Teach: X is a location, not guaranteed semantics; adata.raw is not guaranteed raw counts; a sparse zero is not missing.

  • Practice: inspect shape, dtype, nnz, layers, obs, and var.
  • Deliverable: data-audit table.
  • Exit ticket: explain why full-matrix .toarray() is unsafe.
Day 3

Experimental design and basic QC

Teach: cells are observations; donor/replicate usually defines independent inference. QC thresholds need distribution- and task-based justification.

  • Practice: compare total counts, detected genes, and pct_mito by perturbation, cell type, and batch.
  • Deliverable: QC CSV, three plots, and filtering rationale.
  • Exit ticket: explain how over-QC can remove true responses.
Day 4

First pseudobulk analysis

Teach: sum raw counts inside correct experimental groups. Pseudobulk reduces pseudoreplication but loses single-cell heterogeneity.

  • Practice: aggregate by donor × cell type × target_gene.
  • Deliverable: 24 pseudobulk samples with metadata.
  • Exit ticket: prove per-gene count conservation.
Day 5

End-to-end mini-project

Teach: from a fresh kernel, complete reading, audit, QC, pseudobulk, control comparison, and leakage-aware splitting.

  • Practice: finish the student notebook, then compare with the teacher version.
  • Deliverable: rerunnable notebook, interpretation, and validation split.
  • Exit ticket: identify donor_3–batch_2 confounding and its limitation.
04 / Teaching dataset

Inside the teaching data

The generator creates 2,400 cells × 500 genes with one control, three perturbations, two cell types, three donors, and two batches. Counts use Gamma–Poisson sampling for overdispersion and include cell-type-specific downstream responses.

  • X and layers["counts"]: CSR sparse, non-negative integer raw counts;
  • obs: target_gene, guide_id, cell_type, donor, replicate, batch, and QC fields;
  • var: gene_id, is_mito, is_target_gene, and is_true_response;
  • uns: fixed seed, data contract, and teaching ground truth.

Transparent traps: donor_3 is perfectly confounded with batch_2; about 3% of cells have low library size and elevated mitochondrial fractions. Discover and interpret them—do not silently “clean them away.”

06 / Assessment

Assignments and passing criteria

Suggested total ≥80%, with all five hard requirements satisfied.

20%Environment and data audit
30%QC mini-report
30%Pseudobulk analysis
20%Concepts and reproducibility

Hard requirements

  1. Do not confuse raw counts with normalized/log data.
  2. Do not treat cells as independent biological replicates.
  3. Do not call .toarray() on the complete sparse matrix.
  4. Run the notebook in order from a fresh kernel.
  5. Propose donor-, cell-type-, or perturbation-aware validation.
