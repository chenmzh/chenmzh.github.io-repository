01 / Understand the task

比赛到底要求什么

官网当前对应 2026 届；旧版 H1、150/50/100 划分和三指标属于 2025。

输入匿名细胞系的 18,400 个 non-targeting control 细胞，以及当轮 300 个待敲低基因。
输出每个 context × perturbation 恰好 400 个细胞、18,533 个基因的非负整数原始 counts。
泛化验证使用 A/B/C，最终使用新的 D/E/F；本届没有挑战专用扰动训练集。

关键认识

  • 扰动基因自身从六项评分中排除；PDS 还会排除当轮全部 300 个 target genes，所以必须预测真正的下游响应。
  • 分析和训练可使用 CPM、log1p、pseudobulk；最终提交必须恢复为 raw integer counts。
  • 不能把一条 pseudobulk 向量复制 400 次，否则方差过低会破坏 Wilcoxon 检验和显著 DEG 集合。
PDS cosine扰动响应能否与其他扰动区分。
Expression MSE采样噪声校正后的总体表达误差。
Direction fidelity预测响应基因的上调/下调方向。
Direction reach高置信排序中方向正确性可保持多深。
DEG Jaccard预测与真实显著响应基因集合的重合。
LFC NMAE真实显著基因上的 log2 fold-change 幅度。
02 / Eight-week roadmap

八周项目制学习计划

默认每周 10–12 小时：25% 阅读、60% 编程、15% 实验记录。

  1. Week 0

    环境与数据结构

    搭建 Python 3.11、Jupyter、AnnData、Scanpy、SciPy、scikit-learn、cell-eval2 和 vcc-cli；读取一个小型 .h5ad，识别 X、obs、var、layers、raw 和 sparse matrix。

  2. Week 1

    最低限度的细胞生物学

    理解 DNA→RNA→蛋白质、UMI、library size、dropout、batch effect、CRISPRi、non-targeting guide、Perturb-seq，以及上调与下调。

  3. Week 2

    Pseudobulk 与差异表达

    从 raw counts 计算 control/perturbation pseudobulk、log2FC、Wilcoxon rank-sum、BH-FDR 和 DEG；注意分析数据与提交数据的尺度不同。

  4. Week 3

    三个统计基线

    实现 control bootstrap、全局平均扰动响应和同基因跨细胞系迁移；对低表达 target 与跨 context 不稳定响应进行收缩。

  5. Week 4

    正确的验证协议

    建立 leave-one-cell-line-out 和 perturbation holdout；禁止随机按细胞划分。固定 splits，并用相同六指标比较所有实验。

  6. Week 5

    Context-weighted transfer

    从 control pseudobulk/PCA embedding 描述目标 context，按相似度加权 source signatures；比较 Ridge、ElasticNet 和小型 MLP residual。

  7. Week 6

    恢复单细胞分布

    从目标 control 抽取 scaffold，按预测 logFC 调整均值，并使用 Poisson/Negative Binomial 采样；检查 library size、零值、方差和 DEG 数量。

  8. Week 7

    预训练模型与生物先验

    评估 ESM-2、STRING/GO、STATE、Stack、X-Cell 或 PRiMeFlow；优先把其输出作为统计主干的残差或 ensemble 成员，而非从头训练巨型模型。

  9. Week 8

    比赛级流水线

    完成配置化推理、六指标报告、稀疏整数 counts、格式检查、.vcc 打包和可复现候选提交；固定代码、配置、种子与数据版本。

05 / Working protocol

实验工作协议

  1. 每次实验只改变一个主要因素，并保存配置、Git commit、随机种子和数据版本。
  2. 先在固定的跨细胞系 splits 上运行，再考虑使用排行榜反馈。
  3. 同时报告六项指标、不同 context、强弱扰动和数据覆盖情况，而不是只看 Overall。
  4. 提交前检查三个 context、精确细胞数、完整基因集、整数性、非负性、稀疏度以及 context 标签。
