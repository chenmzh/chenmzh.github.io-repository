01 / Understand the task

What the challenge asks for

The current site describes the 2026 challenge. The H1 150/50/100 split and three metrics belong to 2025.

Input18,400 non-targeting control cells from each anonymous cell line, plus 300 knockdown targets for the current round.
OutputExactly 400 cells for every context × perturbation, with non-negative integer raw counts over 18,533 genes.
GeneralizationValidation uses A/B/C and the final uses new D/E/F contexts; there is no challenge-specific perturbation training set.

Key implications

  • The perturbed gene itself is excluded from all six metrics. PDS also excludes all 300 target genes in the panel, so the model must predict genuine downstream responses.
  • CPM, log1p, and pseudobulk are useful for analysis and training, but the final submission must contain raw integer counts.
  • Repeating one pseudobulk vector 400 times produces unrealistically low variance and damages Wilcoxon tests and significant-DEG calls.
PDS cosineWhether each response is distinguishable from other perturbations.

02 / Eight-week roadmap

Eight-week project plan

Assumes 10–12 hours per week: 25% reading, 60% coding, and 15% experiment logging.

  1. Week 0

    Environment and data structures

    Set up Python 3.11, Jupyter, AnnData, Scanpy, SciPy, scikit-learn, cell-eval2, and vcc-cli. Read a small .h5ad and identify X, obs, var, layers, raw, and sparse matrices.

  2. Week 1

    Minimum viable cell biology

    Understand DNA→RNA→protein, UMIs, library size, dropout, batch effects, CRISPRi, non-targeting guides, Perturb-seq, and up/down regulation.

  3. Week 2

    Pseudobulk and differential expression

    Compute control/perturbation pseudobulk, log2FC, Wilcoxon rank-sum, BH-FDR, and DEG calls from raw counts. Keep analysis and submission scales separate.

  4. Week 3

    Three statistical baselines

    Implement control bootstrap, global mean response, and same-gene cross-context transfer. Shrink low-expression targets and unstable cross-context responses.

  5. Week 4

    Correct validation

    Build leave-one-cell-line-out and perturbation-holdout protocols. Never randomly split cells. Freeze the splits and compare every model on the same six metrics.

  6. Week 5

    Context-weighted transfer

    Represent target context with control pseudobulk/PCA embeddings and weight source signatures by similarity. Compare Ridge, ElasticNet, and a small residual MLP.

  7. Week 6

    Recover single-cell distributions

    Sample target-control scaffolds, modify means using predicted logFC, and sample with Poisson/Negative Binomial models. Check library size, zeros, variance, and DEG counts.

  8. Week 7

    Pretrained models and biological priors

    Evaluate ESM-2, STRING/GO, STATE, Stack, X-Cell, or PRiMeFlow. Prefer residual or ensemble use over training a huge model from scratch.

  9. Week 8

    Competition-grade pipeline

    Finish configured inference, six-metric reports, sparse integer counts, format validation, .vcc packaging, and reproducible candidate submissions with fixed code, config, seeds, and data versions.

05 / Working protocol

Experiment protocol

  1. Change one major factor per experiment and save the configuration, Git commit, random seed, and data version.
  2. Run on fixed cross-context splits before considering leaderboard feedback.
  3. Report all six metrics by context, perturbation strength, and data coverage—not only Overall.
  4. Before submission, verify three contexts, exact cell counts, full gene set, integral non-negative counts, sparsity, and context labels.
