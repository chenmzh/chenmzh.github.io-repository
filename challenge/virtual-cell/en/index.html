01 / Project overview

Project overview

This page defines the project. The detailed roadmap and live progress log now live on a dedicated subpage.

Scientific questionPredict downstream transcriptomic responses to single-gene CRISPRi in unseen cell lines using only their unperturbed state.
Challenge scaleThree anonymous contexts per round, 300 perturbations per context, and 400 generated single cells for every combination.
Success criteriaBalance expression error, perturbation discrimination, DEG sets, response direction, and effect magnitude—not one metric alone.

03 / Working thesis

Current working thesis

Statistics first, deep learning second: establish cross-context perturbation-signature baselines, perform context-weighted transfer from target controls, and generate heterogeneous raw single-cell counts. Use pretrained models mainly for residual correction and conservative ensembling.
