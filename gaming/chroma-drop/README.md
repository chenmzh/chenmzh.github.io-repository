# Chroma Drop

An original 3D liquid-metal tilt maze for desktop and mobile browsers. The game uses a locally bundled WebGL runtime, so it remains fully offline.

## Play

Open `index.html` in a modern browser.

- Tilt: Arrow keys or WASD
- Pause: P or Space
- Restart chamber: R
- Touch: Use the on-screen directional pad

Activate all three charge nodes, preserve at least 65% mass, and move most of the droplet into the open drain.
