# GARGANTUA — Schwarzschild Black Hole Raytracer

Fullscreen WebGL2 null-geodesic raytracer, deployed as a subpage of the Gaming Lab:

https://chenmzh.github.io/chenmzh.github.io-repository/gaming/gargantua/

- Real-time Schwarzschild geodesic integration (RK4), no fake black sphere / ring / textures
- Event horizon, photon ring, multi-pass accretion-disk crossings, gravitational lensing
- Doppler beaming, gravitational redshift, dynamic disk turbulence
- HDR Bloom, ACES, chromatic dispersion, vignette, film grain
- OrbitControls, 4 camera presets, HUD, 23 parameters, 0–9 debug views
- Standard / High / Cinematic, mobile, Retina, persistence, WebGL recovery, URL screenshots

Controls: drag to orbit, wheel to zoom, `H` parameters, `F1–F4` presets,
`0–9` debug views, `C` cinematic loop, `Q` quality, `M` music, `S` screenshot, `R` reset.

Full source repository: https://github.com/chenmzh/gargantua-schwarzschild-raytracer
