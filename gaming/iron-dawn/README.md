# 钢铁黎明：零号战区 / Iron Dawn: Zero Sector

一款原创、离线、单人 HTML5 即时战略游戏（RTS）。战场采用明亮冷色科幻俯视风格，支持陆空联合作战：单位移动、开火、采矿和建筑运转会以差分动画反馈战况。选中框、弹道、爆炸、道路与界面效果由浏览器实时生成，不需要安装游戏引擎，也不会联网下载素材。

- 地图 2400×1500，导航网格 40px，地图边缘保留 64px 安全距离；玩家（北境同盟）驻守西侧，敌人（赤砂军团）驻守东侧。
- 胜利：摧毁敌方指挥核心。失败：我方指挥核心被毁，或 720 秒行动超时。
- 初始资金 1200，人口上限 60；完整指挥核心每 5 秒产出 +25 资金。
- 7 个对称晶矿点，单点基础容量 9000（容量缩放 1 / 0.85 / 1 / 0.85 / 0.75 / 1.3 / 0.9），全图初始矿量 59,850；矿尽后显示枯竭矿坑。
- 电力不足时，生产速度与炮塔射速降至 50%。
- 6 种单位（突击步兵 / 反装甲兵 / 猎犬侦察车 / 堡垒主战坦克 / 晶矿采集车 / 曙光截击机）与 7 种建筑（指挥核心 / 裂变电厂 / 晶矿精炼站 / 前线兵营 / 战车工厂 / 天穹空军基地 / 哨戒机炮塔）。
- AI 三档难度（新兵 / 指挥官 / 老兵）：持续采矿、扩建兵营/工厂/机场/炮塔、约 90 秒后部署截击机，并周期性发动攻击波。

## 在 Mac 上开始游戏

最简单的方法：双击 `Start Game.command`。脚本会进入游戏目录，优先用 python3 在 `http://127.0.0.1:8765/` 起一个本地小服务器并自动打开浏览器（关闭该终端窗口即停止服务）；python3 不可用或端口被占用时，自动回退为直接用默认浏览器打开 `index.html`。

也可以直接双击 `index.html`——游戏全部资源通过 `<img>`/Canvas 本地加载，不使用 fetch，`file://` 协议下可完整运行。推荐使用当前版本的 Safari 或 Chrome。首次双击 `.command` 若被 macOS 阻止，可按住 Control 点击文件，选择“打开”。

## ZIP 用法

先双击 ZIP 解压，保留解压目录中的文件层级，再进入解压后的文件夹，双击 `Start Game.command` 或 `index.html` 启动。不要只把 `index.html` 单独拖出来，否则浏览器找不到脚本和美术资源。

## 语言

游戏支持简体中文与 English。开场简报右上角和战斗 HUD 顶部均有 `中 / EN` 切换按钮；切换会立即更新界面、单位与建筑名称、历史战术日志及 Canvas 浮字，不会重置当前战局。选择会保存在浏览器本地（localStorage），重新打开时自动恢复；本地存储不可用时仍可在当前页面正常切换。

## 任务目标

保护北境同盟的指挥核心，开发丰沛的晶矿藏，发展电力与晶矿经济，生产步兵、战车和曙光截击机，摧毁地图东侧赤砂军团的指挥核心。机场可部署空军；飞行单位能越过地面单位和建筑快速机动。敌人会使用资源、扩建基地并周期性发动增强攻势。

## 操作

- 左键：选择单位或建筑；按住拖动可框选多个单位；双击会选择当前屏幕内的全部同类实体。
- Shift + 左键：追加或移除选择。
- 右键：移动；点到敌人时集中攻击。按住 Shift 下令会追加到最多 16 条的指令队列。
- 手机 / iPad：轻点选择，默认直接单指拖动战场来移动视野；先点底部命令，再点战场指定位置或目标。双击同类单位可批量选择。
- 触控底栏：高亮的 `视野` 表示拖动会平移镜头；点一下关闭后，拖动恢复框选。`生产` 打开建筑与单位抽屉，`地图` 打开战术小地图，`聚焦` 回到当前选择（未选择时回基地）。
- 触控板：也可以点底部命令按钮，再用左键指定位置。
- 方向键、屏幕边缘或小地图：移动镜头（不使用 WASD）。
- M：移动；A：攻击移动；S：停止并清空队列。
- P：巡逻；H：原地防守；R：为兵营、战车工厂或机场设置集结点。
- B：镜头立即返回我方指挥核心；空格：镜头回到当前选择。
- Control/Command + 1–9：保存或清除编队；1–9：召回编队；350ms 内连续按同一数字两次可聚焦镜头。
- HUD 的九格编队栏也可点击召回、双击聚焦，适用于 Safari 占用 Command + 数字的情况。编队会自动清除阵亡成员，且单位与建筑不混存。
- Esc：取消部署或命令模式；没有活动模式时暂停或继续。`/`：打开操作手册。
- 点击左下小地图：快速移动镜头。
- 快捷键在输入框、下拉框与可编辑区域中不会触发。

## 战术提示

- 采集车会自动在晶矿与精炼站之间往返（容量 240、采矿 2.5 秒、卸载 0.8 秒）。完整矿点基础储量 9,000，地图初始总储量 59,850；晶矿仍会耗尽，保护采集线依然重要。
- 电力为负时，生产速度会降至一半，防御塔也会失去效率。
- 步兵适合反步兵；反装甲兵克制坦克和建筑；侦察车速度快；主战坦克擅长正面推进。
- 建造天穹空军基地后可以生产曙光截击机。截击机飞行于 24px 空中层、忽略地面碰撞，能攻击空中与地面目标，适合快速支援、侧翼打击和拦截敌机。
- 建筑只能部署在己方完整设施附近。炮塔能守住入口，但主动争夺中央富矿通常更有效。

## 技术说明

- 纯 HTML5 Canvas、CSS 和原生 JavaScript；无第三方库、无外部字体、无网络请求。
- `js/i18n.js` 提供中英文词典、复数/插值、页面绑定和安全的本地语言偏好保存，两种语言键集合完全一致。
- 19 张新版明亮科幻基础 PNG 与 13 张差分动画图集位于 `assets/art/v2/`；原有 19 张素材作为兼容备用，共 51 张 PNG。降级链为 v2 → 旧版 → 程序化 Canvas，任何单张资源载入失败时只降级对应实体，不中断整帧渲染。
- 启动界面按资源清单实际数量显示进度；基础资源加载完成（或 8 秒超时降级）即可开始，动画图集加载失败不会阻塞游戏。
- 主战场使用固定视口容器 + ResizeObserver，Canvas CSS 尺寸 100%，DPR 上限 2、单边 ≤8192、总像素 ≤32MP，避免 Retina 反馈循环。
- 1024px 及以下采用全屏战场与可折叠触控控制台；默认启用带 7px 防抖阈值的直接拖动视野，并可切换回框选。支持动态视口高度、安全区内边距和 Pointer Events，PWA 横竖屏均可运行。
- 地面单位使用 40px 八邻域 A*（禁斜穿夹角、按碰撞半径膨胀静态障碍、视线平滑、直线通畅时不跑 A*），非法目标自动投影到最近可达点，0.75 秒无净进展触发重寻路；动态单位采用软分离、确定性侧向让行与实体 ID 分离。逻辑碰撞体与视觉半径分离，通道更顺畅但视觉大小不变。飞行单位不走地面 A*。
- 所有出生点（开局、生产、重启）都会做合法性校验：不得落在任何建筑、活跃矿堆或其他单位碰撞体内，且距地图边缘 ≥64px；非法时自动纠偏投影到最近合法位置。单位若因任何原因（例如旧存档坐标）处于障碍物内部，会在下一帧被推出到最近合法位置，不会永久卡死。

## 渲染诊断

需要排查显示问题时，可在浏览器开发者控制台运行：

- `__IRON_DAWN__.diagnostics()`：查看相机、视口、可见实体、寻路恢复数量、晶矿余量、精灵/备用图绘制数量和资源状态。
- `__IRON_DAWN__.probeFrame()`：按需检查主战场 HQ 区域与小地图的颜色像素，不会在每一帧读取画布。
- `__IRON_DAWN__.language()`：查看当前界面语言。
- `__IRON_DAWN__.setLanguage('en')` / `setLanguage('zh-CN')`：从控制台切换语言，便于自动化验收。

## 已知限制

- 游戏无存档/读档功能；刷新页面即重新开始（出生合法性校验对任何注入/恢复的单位坐标同样生效）。
- 多人对战、战役关卡与地图编辑器不在本版本范围内，仅提供单张遭遇战地图对抗 AI。
- 音效由 WebAudio 实时合成，首次点击“开始游戏”后才会启用（浏览器自动播放策略）；系统静音或音频设备被占用时静默降级，不影响游戏。
- 手机横屏为了保留战场高度会隐藏九格编队栏；编队保存快捷键仍属于桌面高级操作，其他选择、命令、生产、地图与聚焦功能均可触控完成。
- `prefers-reduced-motion` 下循环动画半速播放（开火/受击反馈保留），暂停时动画完全冻结。
