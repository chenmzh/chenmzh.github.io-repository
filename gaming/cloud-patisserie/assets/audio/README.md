# 云朵甜品店稀有度开盒音效

这里包含四段原创合成的开盒揭晓音效。全部声音都由振荡器、确定性滤波噪声、包络和多抽头混响生成，没有使用外部采样或网络素材。

## 音效设计

| 稀有度 | 文件 | 时长 | 设计语言 | 峰值 / RMS |
|---|---|---:|---|---:|
| 日常款 | `reveal-common.wav` | 0.720 s | 轻软包装“啵”声，接 C6–E6–G6 三音糖果木琴；短、小、亲切 | -2.20 / -14.95 dBFS |
| 珍藏款 | `reveal-rare.wav` | 1.020 s | 水晶敲击起音，接 E5–G♯5–B5–E6 四音玻璃铃上行琶音；更明亮、尾音更长 | -1.80 / -14.33 dBFS |
| 史诗款 | `reveal-epic.wav` | 1.420 s | 低频云门由 62 Hz 升至 124 Hz，叠加 D5–A5–D6–F6–A6 闪烁琶音、高频星屑和宽混响 | -1.40 / -14.84 dBFS |
| 隐藏款 | `reveal-hidden.wav` | 1.840 s | 深层云门与下坠魔法层，接 C5–E♭5–G5–B♭5–D6 五音主题、双层高音魔法铃和最长混响尾音 | -1.00 / -13.05 dBFS |

四档不仅时长不同，也分别使用了不同的音高走向、起音材料、谐波层数、频率覆盖和空间尾音，因此在短促游戏反馈里仍能立即区分。

## 文件规格

- WAV / PCM signed 16-bit little-endian
- 44,100 Hz
- 单声道
- 确定性三角概率密度抖动（TPDF dither）
- 所有峰值均低于 0 dBFS，没有削波

## 生成方式

生成脚本是 `generate_reveal_sounds.py`，仅使用 Python 标准库：

```sh
python3 assets/audio/generate_reveal_sounds.py
```

脚本会固定随机种子，以相同参数重新生成四个 WAV。核心声音来源包括：

- 相位连续的指数音高滑音，用于包装“啵”声与云门开启；
- 木琴式谐波和极短噪声起音，用于日常款三音标记；
- 轻微 FM 调制的不协和泛音，用于玻璃铃和魔法铃；
- 一阶低通与高通组合的带限噪声，用于空气、星屑和门体质感；
- 前馈多抽头混响，用于逐档增加空间与尾音；
- 写入前去除直流偏移、尾部淡出、按稀有度归一化并加入 TPDF 抖动。

## 验证

使用 `ffprobe` 检查文件头，并用 FFmpeg `astats` 检查电平。当前结果：

| 文件 | 采样数 | 格式 | DC offset | 峰值 |
|---|---:|---|---:|---:|
| `reveal-common.wav` | 31,752 | 44.1 kHz / s16 / mono | -0.000004 | -2.200099 dBFS |
| `reveal-rare.wav` | 44,982 | 44.1 kHz / s16 / mono | 0.000000 | -1.800006 dBFS |
| `reveal-epic.wav` | 62,622 | 44.1 kHz / s16 / mono | -0.000001 | -1.400075 dBFS |
| `reveal-hidden.wav` | 81,144 | 44.1 kHz / s16 / mono | -0.000001 | -0.999887 dBFS |

因为四个文件的实测峰值都严格低于 0 dBFS，所以没有满刻度削波样本。
