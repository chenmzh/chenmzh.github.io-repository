# 云朵甜品店

原创潮玩主题的网页盲盒小游戏。第一期《云层下班以后》包含 24 位常规甜心店员和 1 位隐藏店长。核心体验不是点击随机抽卡，而是从一整箱 12 个福袋里挑一袋、摇出模糊线索、撕开得到 1-5 个盲盒，再逐个拆开，把角色放进可互动橱窗。

## 开始游玩

直接用现代浏览器打开 [`index.html`](./index.html) 即可，无需安装依赖或启动服务器。

初始拥有 600 枚云朵币，刚好可以体验两次开袋：

- 每个福袋消耗 300 枚云朵币，撕开后袋内的所有盲盒免费逐个拆开
- 每个福袋随机装有 1-5 个盲盒，数量与具体内容在整箱生成时已经确定，选择后不会重新随机
- 盲盒可以单独点开；同一福袋内允许开出重复角色，重复会触发升级
- 12% 的整箱会由隐藏店长随机藏在某一只盲盒里
- 撕开福袋前最多摇出两条关于“可能藏着哪位店员”的声音/重心模糊线索，但不会告诉你装了几个
- “刷新未拆货架”会替换尚未撕开的福袋，已撕开的福袋及其盲盒、收藏和云朵币保持不变
- 第二次获得同一角色会解锁专属店章，第三次会解锁像素爱心庆祝动画，之后继续提升星级

## 像素角色资产

25 位角色现在都使用独立的原创透明像素立绘，以及各自专属的四帧差分动画。每张动画条都是 `2048 × 512` RGBA PNG，由四幅真正重绘的 `512 × 512` 姿态组成：表情、手臂、轮廓和主题道具会随角色动作变化。浏览器只离散切换精灵图的 `background-position`，不会对角色本体做拉伸、旋转、缩放或位移来伪造动作。

草莓泡芙会“爱心招手”，焦糖布丁会“布丁摇铃”，薄荷苏打会喷出气泡，星星马卡龙会表演星星魔术；其余角色也各有独立动作。完整的 25 套动作与生成规格记录在 `docs/plans/2026-08-31-differential-sprite-animation-design.md`。动画文件按稳定角色 ID 命名为 `assets/characters/animations/<character-id>-sheet.png`。

美术规范与共同样张分别位于 `assets/characters/style-bible.md` 和 `assets/characters/style-anchor.png`，正式角色图片以稳定角色 ID 命名为 `assets/characters/<character-id>.png`。

## 主动赚钱

页面下方现在是七路线“赚钱中心”，所有路线都不会倒扣已有云朵币：

- **听单打包：**20 秒内按订单点击草莓云塔、薄荷苏打或曲奇礼盒。每单从 5 枚小费起，答错清空连击并扣 2.5 秒；橱窗人气开局奖励最多 10 枚，单班总收益硬性封顶 45 枚。
- **数学挑战：**每轮从 52 道心算、比例、概率与逻辑题中随机抽 5 道，连续答对提高奖励，满分最高 175 枚。
- **常识问答：**每轮从 52 道稳定的科学、历史、地理、艺术和计算机基础题中随机抽 5 道，满分最高 140 枚。
- **RL 研修：**每轮从 64 道强化学习题中随机抽 5 道，覆盖 Bellman、DQN、REINFORCE、Actor-Critic、PPO、GRPO、RLVR 与 Agentic RL，满分最高 220 枚。
- **云端跑堂：**不限时的原创横版平台关卡，包含台阶、沟壑、收集物、巡逻障碍、检查点和终点；抵达终点或 3 条生命耗尽才结算，游戏得分与云朵币入账均不封顶。
- **方糖堆叠：**不限时的 10×20 原创甜品落块关卡，支持旋转、软降、硬降、消行和等级；只有方块堆出顶部才结束，游戏得分与云朵币入账均不封顶。
- **星夜飞行：**不限时的 2D 自动射击弹幕关卡，波次会持续递增、每 5 波出现 Boss；只有 3 条生命耗尽才返航，游戏得分与云朵币入账均不封顶。配有 **X 导弹**（导弹匣随时间回弹）与 **Z 护罩**（都会进入冷却）；击落敌人有几率掉出升级，攒满后可按 1 / 2 / 3 强化——扩充导弹弹匣、强化基础弹药、或补充导弹并给护罩充能。

三款街机关卡分别配有独立原创循环像素配乐：平台关是明亮跳跃旋律，落块关是较慢的机械琶音，射击关是高速脉冲旋律。配乐使用 Web Audio 实时合成，会跟随总声音开关，并在切换路线、放弃、结算或页面进入后台时停止。

每道题选择后会立即锁定答案、标出正误并显示解析。每轮的正确答案位置都会重新编排，并保证 A、B、C、D 四个位置都实际出现。RL 题库依据 [Hands-On Modern RL](https://github.com/walkinglabs/hands-on-modern-rl) 课程编写，各题带有对应章节链接；原课程采用 CC BY-NC-SA 4.0 许可。

四档稀有度使用不同的揭晓灯光、文字、环境色和收藏能力：日常款为哑光纸张，稀有款为粉色灯牌，闪耀款为青绿色星光，隐藏款为深色金边秘密舞台。

开盒揭晓也使用四个独立原创音效，分别位于 `assets/audio/reveal-common.wav`、`reveal-rare.wav`、`reveal-epic.wav` 和 `reveal-hidden.wav`。从日常款的轻软糖果木琴，到隐藏款的深层云门、魔法铃与长尾混响，稀有度越高，音阶层次、低频重量和尾音长度越明显。

游戏使用版本化的 `cloud-patisserie-case-v3` 本地存档，保存在当前浏览器的 `localStorage` 中。陈列箱旁和页脚都有“重新开一局／刷新整场游戏”入口；确认后会清空橱窗、整箱与货币进度。它与“刷新未拆货架”是两个不同操作。

## 验证

运行规则测试：

```bash
node --test game-logic.test.js
```

运行 JavaScript 语法检查：

```bash
node --check game-logic.js
node --check quiz-data.js
node --check script.js
```

## 文件结构

- `index.html`：页面语义结构与所有游戏舞台
- `styles.css`：视觉系统、四帧离散换帧、稀有度特效与响应式动画
- `quiz-data.js`：数学、常识与强化学习题库、路线奖励配置和 RL 章节来源
- `drafts/`：三类题库的扩充题目脚本
- `arcade/`：平台跳跃、甜品落块与 2D 弹幕三个独立 Canvas 引擎，以及循环像素配乐音序器
- `game-logic.js`：角色数据、整箱生成、线索、开盒、重复升级、打包与答题计分规则
- `script.js`：页面渲染、交互、音效与本地存档
- `game-logic.test.js`：关键玩法合同测试
- `assets/characters/`：25 张静态角色立绘、25 张四帧差分动画条、统一样张与美术规范
- `assets/audio/`：四档稀有度揭晓音效、可复现合成脚本与验证说明
- `docs/plans/`：游戏设计与实施计划
