# 第一章 · 青溪夜渡

目标体验为约 10–15 分钟的箱庭小章：玩家亲自走访渡口，串起妹妹的消息，做一件会带来成长的小事，完成桥头切磋，再承担信件去向的后果。剧情与角色数据位于 `chapter-content.js`；任务状态、数值奖励和存档由章节实现负责。

## 一条主线与一件顺路的人情

陆行舟循妹妹陆听雨的半枚铜钱来到青溪渡。渡夫沈青竹指向茶摊；阿蘅留下“旧碑的雨字下面”的口信，并提到妹妹曾替孩子付药钱。玩家到旧碑找到能与铜钱相合的刻痕，确认信件在裴照手里、妹妹已往鹤州。茶摊口信与碑刻证据共同打开桥头会面，避免一入地图就能跳过调查。

药庐是一条与主线人物命运相连的可选支线。顾药师请玩家去江畔采青露草，孩子的药因此续上。作为回报，他给玩家伤药，纠正吐纳，使经验或成长奖励有叙事原因；他的“气急先守，息定再出剑”也自然预告战斗的防守、蓄力与重击反制。草药是一次性任务物，交付与成长只能结算一次。木匣提供一份自助行路补给，鼓励玩家留意主路旁的角落。

## 箱庭中的人物

| 人物 | 记忆点 | 互动作用 |
| --- | --- | --- |
| 沈青竹 | 认得陆行舟握剑时伸不直的小指；腰间仍留旧闸钥匙 | 初始指路、休息恢复、承认开闸责任 |
| 阿蘅 | 记得每笔茶钱，嘴上取笑兄妹，心里惦记孩子 | 传递主线口信，引导药庐支线 |
| 顾药师 | 一边嫌雨水滴进药臼，一边熬着孩子们的药 | 采药委托、成长教学、补给奖励 |
| 裴照 | 刀重但以刀背应战；把孩子的乳名记得比官印牢 | 桥头门槛、非致死战斗、道德分歧 |

普通互动控制在 2–4 句，战前与战后最多 5 句。重复交谈提供有角色语气的提醒，不再次发放奖励。休息是明确可重复的整备动作。战败保留调查与成长，让玩家回渡口休息后再试，不以删档惩罚探索。

## 战斗后的闭环

裴照以切磋确认陆行舟能收住剑，胜利后交出信件：正面是去年决堤的开闸令，背面是十七名幸存孩子的现住址。沈青竹承认自己奉命开闸，愿随原信去认罪；裴照指出巡按随员中也有当年督堤的人，名单提交会暴露孩子。官印透纸，刮去背面会损伤凭据，抄本无法替代原件。两条结局都说明具体得失，不设暗藏的完美选项。

- **灯在江上**：保留原件，案件受理，沈青竹候审。十六个孩子已转移，最后一人在搜查前独自离开。陆行舟带着回执前往鹤州，继续寻妹与寻人。
- **人过青溪**：烧信护送，十七个孩子全部脱险；缺乏原始证物，自首状被退回。裴照答应同行，二人去鹤州寻找发令者，为翻案另寻证人。

青溪渡的调查、切磋和当夜抉择在本章全部结束。妹妹去向从模糊变得明确，鹤州长线留待后续章节。结尾应展示章节完成、所选后果及探索/成长成果，并允许回看札记或重新开始。

## 数据约定

- 导出 `CHAPTER_TITLE`、`INTRO`、`DIALOGUES`、`ENDING_CHOICES`、`JOURNAL_TEXT` 和 `NPCS`。
- 所有对白行统一为 `{ speaker, text }`；结局选项统一为 `{ id, label, detail }`。
- `DIALOGUES` 含首访、重复交谈、物件调查、交付、桥头门槛、战败、战胜、休息及两条结局。
- 具体经验、等级与补给数目应由游戏 UI 展示，文案不重复维护数值。
- `JOURNAL_TEXT` 记录已完成的重要步骤；待办目标需由任务状态另外生成，避免未做支线却出现完成描述。

## 实际验收清单

以下是交付前需要执行的验收项，不代表已通过。规则以当前 `chapter-model.js` 为依据；界面和地图行为须在浏览器中验证，不能仅用模型测试代替。10–15 分钟是体验目标，实际时长需要完整读对白并游玩后记录。

| 验收项 | 操作与应有结果 | 所需证据 |
| --- | --- | --- |
| 箱庭探索 | 点地面、点地点寻路、方向键移动均能到达茶摊、药师、渡夫、旧碑、草药、旧木箱、驿亭、石桥；人物动画与地形位置对应，不穿房屋花坛 | 桌面实玩、路径与碰撞检查 |
| 手机操作 | 窄屏可查看完整地图并移动，摇杆、地点按钮、交谈和关闭面板可用；对白与结局选项可读，没有被裁掉的必要控件 | 320/390 像素竖屏与横屏浏览器实玩 |
| 主线门槛 | 无线索、只有茶摊或只有旧碑时均不能开战；收齐两者才能看到战前准备选项 | 模型测试，加一次浏览器流程 |
| 交互状态 | 同一 NPC 首访与再访文本正确；先到草药处会提示问药师；先查碑再问茶也能接上主线 | 状态测试与对白巡检 |
| 采药闭环 | 领委托→采青露草→行囊显示待交→回药庐→草药不再待交→金疮药 +1、阅历 +25，札记记载完成；重复交付不重复奖励 | 模型测试及实际 UI 前后状态 |
| 寻物收获 | 木匣首次给金疮药 +1、阅历 +10；再次调查只显示已取过文本 | 模型测试与一次界面检查 |
| 成长可用 | 茶摊 +15、旧碑 +20、采药交付 +25 后达 60 阅历，升至 2 级并得 1 修习点；进入修习主动选择剑招 +5 或气血上限 +25，点数扣除，不能重复学 | 状态数值与修习面板实玩 |
| 成长带入战斗 | 以 2 级及已修习状态入桥头战，气血/真气上限、药品和剑招伤害加成与探索角色一致 | 战斗初始化测试及浏览器战斗数值 |
| 非致死退路 | 战败或退回后仍有至少 1 气血，线索与修习不丢；驿亭可恢复气血和真气，已消耗药品不自动增加；再次到桥头可挑战 | 模型测试及浏览器退回、休息、重入 |
| 战后衔接 | 战胜立即回探索叙事，获阅历 +60，出现信件正反两面的解释与两个明确后果选项；未决定时再次找裴照可继续选 | 结果桥接测试及实际获胜流程 |
| 双结局闭环 | 两条结局分别写入正确札记，展示完成状态、等级/阅历/见闻；原信选择一旦确认不能随重复互动改变。妹妹鹤州线索保留 | 两分支模型检查、至少一次完整浏览器结局 |
| 满级与收集 | 全收集加战胜共 130 阅历，达本章 3 级；总计 2 个修习点，见闻 4/4；每项奖励仅一次 | 完整状态路径测试 |
| 存档恢复 | 重新打开后位置、任务、物品、成长和结局一致；战斗中刷新回到交锋前，仍可再开战；不可用/损坏存档有明确提示 | 恢复测试及浏览器刷新 |
| 文案统一 | 草药统一“青露草”，渡口统一“青溪渡”，导航称“旧碑/石桥/药庐/驿亭”；休息只指向驿亭，札记不提前声称已做支线 | 搜索与界面巡检 |
| 发布可玩 | 既有 GitHub Pages 地址默认进入第一章；独立演武场仍可进入；公开页面全部新增地图、肖像与模块加载成功 | 实际发布地址网络/控制台和手机页面检查 |

数值验收不要求玩家必须完成可选任务才能通关；为了展示成长概念，完整试玩路径应至少实际交付一次采药任务、分配一次修习点，再进入战斗。主线最短路径与探索全收集路径都必须成立。
