# GPT Explain homepage entry

## Decision

The homepage already has an `Archive & tools` catalog, so GPT Explain should be added there rather than introducing a duplicate section or a new repository. The new item reuses the existing entry component and forest accent, links to the public source repository, and mentions the downloadable macOS package in its description.

The catalog counter changes from 09 to 10. No new JavaScript, stylesheet, asset, or deployment dependency is required. Verification covers HTML structure, the external repository URL, responsive screenshots, and the published GitHub Pages URL after the commit reaches `master`.
