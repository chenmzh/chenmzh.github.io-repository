# 古筝工坊 · Guzheng Studio

拖拽式的可视化古筝音乐生成系统，随 [Music 页面](../) 发布。

在线入口：`https://chenmzh.github.io/chenmzh.github.io-repository/music/studio/`

## 功能

- **音色**：两种古筝音色可选
  - `实录古筝`：CC0 实录 A3 单音经变调扩展（默认，音色最接近真实）
  - `合成古筝`：Karplus-Strong 拨弦合成（无需采样，加载采样失败时自动兜底）
- **调式世界**（五声调式 + 自由十二音）
  - 宫 / 商 / 角 / 徵 / 羽 五种五声调式，所有动机与和声都以「音级」编码，随主音/调式实时转调
  - `自由十二音`：可自由挑选，含两套流行和声（I–V–vi–IV、卡农进行）
- **10 个动机**（可试听、可拖拽）：
  流水下滩、拾级登高、刮奏上行/下行、琶音骨架、问答呼应、切分推进、摇指同音、跳进回落、倚音描花
- **8 种和声进行**，可分配到**任意声部**：
  静夜回环、徵·大回环、羽·空谷、商·行舟、角·山色、宫·五音漫步、流行 I–V–vi–IV、卡农进行
- **4 种织体**：柱式和弦 / 分解琶音 / 低音根音 / 根音+琶音
- **多声部时间轴**：默认 4 条声部（可改音色/音量/声像/静音/独奏）
- **拖拽编辑**：从素材卡拖入声部、拖动移动块、左右手柄改长度、复制、删除
- **播放/循环**：BPM 40–200、循环区设置、实时播放头
- **导出**：录制为 WAV、导出 MIDI
- **持久化**：工程序列化到网址 hash + localStorage，刷新/分享不丢

## 架构

| 文件 | 职责 |
|---|---|
| `index.html` | 页面外壳（复用站点 `site-shell.css`） |
| `style.css` | 工坊样式 |
| `lib/theory.js` | 五声调式音高模型（音级↔半音↔MIDI、和弦转位） |
| `lib/content.js` | 素材库：10 动机、8 和声、织体、音色、乐器抽象 |
| `lib/audio.js` | 浏览器音频引擎：采样/合成声部、混响、压缩、试听、录制 |
| `lib/midi.js` | MIDI 文件生成与下载 |
| `lib/app.js` | 主程序：状态、时间轴渲染、拖拽、播放调度、属性面板、持久化 |
| `vendor/tone.js` | Tone.js 14（本地 vendor，仅用 Transport/Loop） |
| `audio/guzheng-a3.wav` | CC0 古筝采样（裁剪 5.6s 尾韵，缩小体积） |
| `test/logic.test.js` | 纯逻辑单元测试（node test/logic.test.js） |

## 开发提示

- 素材都在 `lib/content.js`：要加动机/和声/织体，改一个对象数组即可。
- 新增音色：在 `lib/audio.js` 的 `trigger` 里加一个 `timbre` 分支，并在 `content.js` 的 `TIMBRES` 登记。
- 部署：静态页面，随 GitHub Pages 站点自动发布（push 到 master 触发）。

## 采样许可

`audio/guzheng-a3.wav` 源自站点音乐页的 CC0 古筝实录参考音（A3）裁剪而来，
详见 [../assets/LICENSES.md](../assets/LICENSES.md)。

## 验收

- 页面无浏览器控制台报错（Chrome/Firefox）。
- 首次交互（点击「进入古筝工坊」）之前不发声，满足自动播放策略。
- 拖动机划到声部、两种动机分轨播放、独奏/静音各自独立。
- 切调式/主音/BPM 实时生效，安全模式下所有音都在所选五声调式内。
