# 霓汽残像 · Neon Steam Afterimage — 创作记录

## 1. 创作边界

本曲只复用现有项目的古筝采样、离线渲染器与网页发布机制，不复用《月下流水》《松间月》《纸鸢》的五声音阶写法、自然景物意象或旋律轮廓。旧曲开头分别偏向五声音阶的回落或级进；本曲核心动机是 **D4–E♭4–A4–A♭4（MIDI 62–63–69–68）**，由小二度、增四度与再次下行小二度构成，主动制造机械感与不稳定感。

## 2. 结构

| 小节 | 层次 | 作用 |
|---|---|---|
| 1–4 | 动机独奏 | 四音单元在留白中重复，像霓虹启动与蒸汽泄压 |
| 5–8 | 动机衍生的上方旋律 + 和声 | 高八度变形、错位节奏和大七/九和弦形成蒸汽波的朦胧色彩 |
| 9–16 | 上方旋律 + 下方旋律 + 和声 | 三层同时展开，D 持续音与 C♯/E♭产生半音冲突 |
| 17–20 | 多层峰值 | 琶音、摇指、A7(♭9) 与 C♯dim7 叠加形成最大张力 |
| 21–24 | 有限解决 | 回到 Dm(add9)，但保留 E 九音，不作完全传统终止 |

## 3. 和声语言

主要进行与色彩包括：

- Dm(add9) → B♭maj7(♯11) → E♭maj9；
- Gm9 → C♯dim7 → A7(♭9)；
- D pedal 上叠置 C♯、E♭，形成持续半音摩擦；
- 高潮后回到 Dm(add9)，保留开放九音和未完全消失的残像。

这些和声使用借用和弦、减七经过和弦、属七降九、三全音及色彩音，而不是旧曲的纯五声和声床。

- 速度：66 BPM，4/4，24 小节；
- 时长：91.77 秒（含 4.5 秒尾响）；
- 207 个源事件，展开后 228 个音符；
- 音域：MIDI 49–85；
- 最高同时 16 voices，0 次 voice steal；
- WAV：44.1 kHz、立体声、16-bit；另附 192 kbps MP3 与 Type-0 MIDI；
- 音色：CC0 古筝 A3 实录核心 + 确定性混合渲染，随机种子 20260827。
